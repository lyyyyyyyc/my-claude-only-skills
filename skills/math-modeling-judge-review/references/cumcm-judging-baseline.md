# CUMCM 官方评审基线（v2026-02-21）

## 文档元信息
- 基线版本：v2026-02-21
- 最后完整检索日期：2026-02-21
- 来源限定：`mcm.edu.cn` 官方页面与官方附件
- 用途：为 `math-modeling-judge-review` 提供稳定、可复核的评委审核基线

## 使用说明
- 默认按本基线执行审核，不每次联网。
- 仅当用户要求“最新/当届/今年/新规”，或本基线超过一年未更新时，再触发联网更新。
- 所有结论必须映射到下表条款之一，禁止无依据判断。

## 可触发高风险的红线项
1. 匿名信息泄露（学校、姓名、指导教师、可识别标识）。
2. 结果与支撑材料明显不一致（图表数值对不上、结论与结果冲突）。
3. 疑似高相似度且未做合规引用或必要改写。
4. AI 使用披露不完整（工具、用途、关键交互、人工修改缺失）。
5. 引用规范严重缺失或大段照抄。
6. 关键模型结论无法复现或无最小验证证据。

## 结果核查最小清单（强制）
1. 口径一致性：单位、时间粒度、统计口径统一。
2. 数值逻辑：关键指标是否自洽，有无异常跳变。
3. 结论匹配：文字结论是否被表格/图形直接支撑。
4. 稳定性说明：跨天/跨类别波动是否可解释。

## 审核结论必须遵守的证据链格式
`依据来源 -> 对应问题 -> 风险级别 -> 影响 -> 修正建议`

示例：
- 依据来源：论文格式规范（2023修订稿）
- 对应问题：摘要页未给出可复核的核心结果指标
- 风险级别：中风险
- 影响：评委难以快速判断结果正确性，降低说服力
- 修正建议：在摘要补充“核心指标+对比基线+主要结论”三行结构
