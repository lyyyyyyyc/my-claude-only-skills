必须先判断数值列之间是成对观测关系，还是彼此独立的样本组；再判断单变量、双变量、三变量或多变量以及是否有序。

# 数值型数据选图

## 这一部分怎么用

- 本文件处理纯数值型数据；只要类别字段承担了分组、颜色或面板作用，优先同时参阅 `03-mixed.md`。
- “两个变量”不等于“两组样本”：每一行有一对 `x, y` 测量值时，重点通常是关系；两组各自包含多条观测时，重点才可能是分布比较。
- 同一分支内沿用原分类树的优先级，但先检查图型是否满足数据结构、观察目的、样本量和证据条件。
- 仅有汇总值时不能把箱线图或小提琴图表述为真实组内分布；只有一张截图时不能宣称已核对每个原始点。

## 单变量

1. 直方图 `[首选]`：适合看单个连续变量的频数、频率或密度分布。说明分箱规则、纵轴口径和比较范围。
2. 密度图：适合看连续变量的平滑分布形状。样本量不足、变量有明确边界或带宽会主导图形外观时，应优先保留直方图或原始点。
3. ECDF 图：适合比较分布位置和尾部，不需要主观分箱；若当前分类树未列出它，可作为直方图或密度图的补充建议。

## 双变量

### 成对数值观测，无天然顺序

1. 散点图 `[首选]`：适合看两个连续变量的关系、聚集、非线性、异方差和离群点。
2. 散点直方图：适合同时看变量关系与两个边际分布。
3. 二维密度图 / hexbin：适合点严重遮挡、读者更关心密集区域时使用；说明网格或密度估计口径。
4. 气泡图：仅在第三个非负量的大小具有明确含义且面积编码可读时使用。

不要把成对 `x-y` 数据默认画成箱线图，也不要因“无序”把一一对应关系抹掉。

### 成对数值观测，有天然顺序

1. 连通散点图 `[首选]`：适合保留点位，同时表达阶段、路径、剂量或时间顺序。
2. 折线图：适合顺序连续、重点是趋势、拐点和波动的场景。
3. 面积图：适合累计量、库存量或整体量级变化；需要精确读局部变化时不作为首选。

时间轴应按真实间隔定位。缺失观测不默认填零或跨段连接；状态保持型数据可考虑阶梯图，但必须说明前保持或后保持语义。

### 多组独立数值样本

1. 箱线图 `[首选]`：适合先比较多组样本的中位数、四分位范围和离群点。每组应有足以讨论分布的重复观测。
2. 小提琴图：适合比较分布形状；应说明或至少保留带宽、宽度和样本量等影响解释的条件。
3. 直方图 / 密度图：适合并列比较边际分布；各组比较时保持可比较的分箱和范围。
4. 原始点叠加：小样本或需要显示真实离散程度时，与箱线图或小提琴图配合使用。

箱线图的箱体、中位线、须线和离群点定义必须在图注或说明中可追溯。Tukey `1.5 x IQR` 是常见规则而非唯一规则；图示离群点不等于应删除的错误数据。

## 三变量

### 无序

1. 气泡图 `[首选]`：适合两个位置变量加一个大小变量。大小默认映射面积而不是半径，并提供尺寸图例、单位和变换依据。
2. 3D 散点图：只在第三个空间维度本身有意义、遮挡可以控制且二维替代表达不足时使用。
3. 分面散点图：适合第三变量可离散分层，或需要避免气泡、三维遮挡时使用。
4. 二维散点加颜色：适合第三变量是连续强度，但必须提供色标、范围和缺失值显示。

### 有序

1. 堆积面积图 `[首选]`：只适合三个系列同单位、具有合理组成和可加总关系时看总量与构成变化。
2. 折线图：适合比较多个序列随顺序变化；系列过多缠绕时改分面或热图。
3. 面积图：适合单一总体量级变化，不应用来伪造没有加总意义的总量。
4. 流图：适合看相对构成的流动；精确数值判断仍应有折线、表格或直接标注补充。

## 多变量

### 无序

1. 箱线图 `[首选]`：适合对多个数值变量做分布总览；不同量纲时先明确是否标准化。
2. 小提琴图：适合比较多个变量的分布形状；过多变量时注意标签和版面。
3. 峰峦图：适合把多个分布层叠比较；不适合作为需要精确读值的唯一主图。
4. PCA：仅在已有或获授权计算的降维结果存在时，用于观察高维主结构；应报告输入变量、预处理和解释范围。
5. 相关性图：适合看变量间的相关结构；必须说明相关方法、缺失值处理及变量顺序。
6. 热图：适合看“对象或变量 x 指标”的数值矩阵。
7. 树状图：适合展示已有层次聚类结果；不能为美化而自行重排或聚类。

## 数值图的专项判断

### 散点密度与异常点

- 点遮挡时依次考虑减小标记、透明度、分面、二维直方图、hexbin 或二维密度图。不要用固定点数阈值机械切图。
- 标注极值、离群点、阈值或事件时，说明它来自题目约束、已有模型结果或明确的计算规则；不能凭视觉印象标注“最优”。
- 回归线、平滑曲线、聚类椭圆、置信带和预测带属于额外分析。没有数据、方法和授权时，只能说明可考虑，不得加入图中。

### 气泡图与三维图

- 气泡大小需写明编码的是面积、半径还是其他视觉量；若用 matplotlib，`scatter(..., s=...)` 的 `s` 是平方点单位，不能将原数值直接理解成半径。
- 零值、负值、极端值和大小范围压缩必须有可解释的映射，不能静默截断。
- 3D 曲面或 3D 散点优先同时提供二维投影、等高线或分面替代建议。若使用 `plot_surface`，绘图实现必须明确采样或步长，因为默认设置可能对大网格抽稀。

### 热图、相关矩阵与色标

- 色标必须说明数值单位、上下限、中心点和归一化方式。缺失值与有效零值使用可区分表示。
- 直接比较同一指标的多个热图时，尽量共享色标范围；不同指标或不同量纲的图不应为了整齐强行共用色标。
- 相关矩阵只有在确实对称且信息重复时才遮去一半；聚类排序应来自已有结果或用户授权的计算，不能改变标签与单元格对应。

### 分布、尺度与轴

- 直方图比较时说明分箱、范围和纵轴是计数、频率还是密度；密度图说明或保留带宽与边界处理依据。
- 区分“原数值使用对数轴”和“绘制对数变换后的变量”。注明底数、单位和零负值处理，不能为适配对数轴静默删除数据。
- 双 Y 轴只在映射和比较理由明确时使用；两个独立量纲的序列通常优先分面或共享时间轴的上下子图。
- 柱状表示量值时检查零基线与正负方向。需要强调细小差异时优先点图、区间图或明确的局部放大方案；不能用装饰性 3D 柱图制造差异。

## 不要写什么

- 不要把两列成对数据和两组独立样本混成同一个“双变量”分支。
- 不要把相关、回归、因果、聚类和趋势判断混为一谈。
- 不要让气泡面积、色彩或三维透视成为精确比较的唯一依据。
- 不要把分箱、带宽、尺度变换和抽稀当成与结果无关的装饰参数。
