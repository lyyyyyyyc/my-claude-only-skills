# 重绘与交付审计

## 审图或审计咨询

- 只针对用户提供材料中可见的缺字、裁剪、遮挡、标签歧义、轴尺度风险、色标风险、图例风险、语义不一致和可编辑性风险进行报告。
- C/D 级截图只能报告“可见问题”“无法确认的项目”“需要补充的材料”；不得渲染、导出、加载字体、运行字体门禁或把视觉估读写成原始数据核验。
- 审图输出按“可见问题、影响、证据等级、未知项、建议动作”组织。用户未授权重绘时，只给建议，不生成替换图、代码、文件或论文改动。
- 用户转为实际重绘后，重新判定证据等级，再执行本文件其余重绘和交付规则。

## 重绘边界

- 默认任务是“保留数据和计算口径，替换表达层”。
- 可按授权修复缺字、文字裁剪、图例遮挡、版式冲突、颜色可辨识度、线条层级和导出质量。
- 疑似错误的数值、单位、统计标记、类别对应、轴尺度、异常值策略和模型结论必须先提示并定位依据。纠错需要明确授权，且应另存版本、列明差异。
- 更换图型属于图型优化建议，不是默认保真重绘。只有用户明确授权换图型时才执行。

## 输入材料与可验证范围

| 等级 | 常见材料 | 可以确认 | 不能宣称 |
| --- | --- | --- | --- |
| A | 原始数据、代码、模型输出 | 点、变换、系列、统计口径和计算过程 | 未实际运行的结果 |
| B | 表格、SVG、PDF、可编辑图层 | 文本、对象、部分数值、图例和轴 | 未提供的模型过程 |
| C | 清晰 PNG、JPG、截图 | 可见标签、布局、明显点位和表达问题 | 已逐点核验原始数值 |
| D | 低清、裁剪或缺失元素的图 | 可见缺口和不确定性 | 完整数据、准确统计或隐藏图例 |

证据不足时，在交付说明中写“未验证”，不要将视觉相似描述为数值完全一致。

## 改前改后核对

按材料允许的粒度，记录并核对：

1. 图型、子图数量、数据系列、类别、样本点或汇总值。
2. 单位、坐标范围、轴尺度、时间范围、分母和转换口径。
3. 图例、直接标注、误差含义、已有统计标记和参考线。
4. 热图色标、地图底图与投影、网络节点边、流程节点连边等图型特有对象。
5. 跨图中的模型、方案、区域、情景、颜色、线型、标记、名称和排序的一致性。

发现材料不一致或无法确认时，不能自动挑选“看起来更合理”的版本。

## 交付说明结构

每次实际交付按以下结构记录：

1. 图型与表达目的。
2. 输入材料与证据等级。
3. 原图可见问题。
4. 拟改内容与实际修改。
5. 数据、模型和统计保真核查。
6. 字体、配色、轴范围、单位、尺寸、DPI、输出格式与数据来源。
7. 已通过、失败、不适用和未验证的审计项。
8. 输出文件、独立输出目录和未解决事项。

## 图面与内容审计

### 图面审计

- 中文字形和纯英文数字字体是否符合主文件标准，是否出现方框字或 `Glyph missing`。
- 图例、标注、坐标标签、色条和面板标签是否遮挡、裁剪或重叠。
- 白底、灰度和打印条件下，系列是否仍可区分；颜色不应是唯一编码。
- 轴范围、零基线、对数轴、断轴、单位和色标是否会误导读者。
- 在最终论文插入尺寸下检查字号、线宽、色条、图例和标签，不只在放大预览中检查。

### 内容审计

- 系列、类别、点位、流程节点、边和图例是否完整且对应正确。
- 直接标注、阈值、拟合、区间、统计符号和图注是否有数据与方法来源。
- 热图色标、气泡面积、桑基流量、网络布局和地图编码是否与说明一致。
- 图题、图注、正文引用和编号是否与用户模板一致；未获授权时只给建议，不改正文。

## 导出与可编辑性

- 遵守主文件既定的 PNG 600 DPI、SVG/PDF、字体嵌入和精确尺寸规则；不能因外部模板示例改为较低标准。
- 检查实际 PDF/SVG 的文字、路径和必要图层是否保留。一张 PNG 置入 PDF 容器不算可编辑矢量图。
- 混合栅格与矢量内容时，说明哪些部分是栅格，保留绘图源码、数据入口、随机种子、环境和输出参数。
- 原图、原始数据和既有输出目录不得覆盖；重绘结果写入独立目录。

## 不要做什么

- 不要用“看起来一样”代替保真核对。
- 不要以美化名义添加回归、平滑、聚类、误差棒、显著性、置信带或预测带。
- 不要用 `bbox_inches="tight"` 改变要求精确版面尺寸的输出页面。
- 不要把输出扩展名当作字体嵌入、矢量可编辑或元数据合格的证据。
