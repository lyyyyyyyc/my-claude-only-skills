必须先判断数值在类别中的角色：是每类别一个汇总值、每类别多条重复观测，还是多个数值指标。不要把“类别标签唯一”误解成“每类只有一条样本”或反过来。

# 数值型与类别型混合数据选图

## 关键术语

- `每类别一个汇总值`：每个类别对应一个数值，例如方案总得分、区域总量或单次模型输出。不能据此声称存在组内分布。
- `每类别多条观测`：每个类别下有多条独立或配对样本，可以讨论中位数、离散程度、箱线图和小提琴图。
- `多个数值指标`：每个类别有多列指标。先检查指标量纲、方向和是否已经标准化，再选比较图。
- `有序类别`：时间、阶段、等级、剂量、路径等有天然顺序；没有顺序时不能因图面好看而连线。

## 一个数值型与一个类别型

### 每类别一个汇总值

1. 点图 / 棒棒糖图 `[首选]`：适合精确比较类别对应的单个值。
2. 柱状图：适合类别少、需要强调总量或正负方向时使用；柱长表达量值时检查零基线。
3. 热图：适合“类别 x 指标”扩展为矩阵后做整体浏览。
4. 饼图 / 圆环图：仅在数值是构成同一整体的非负份额时使用。
5. 树状图 / 圆堆图：仅在类别已有层级或面积构成关系时使用。

不使用箱线图或小提琴图来表达每类别只有一个汇总值，也不把独立评分强行画成饼图。

### 每类别多条观测

1. 箱线图 `[首选]`：适合比较各类别下数值样本的中位数、四分位范围和离群点。
2. 小提琴图：适合比较各类别下的密度形状；样本少或边界明显时与原始点或箱线图配合。
3. 原始点 / 抖动点：小样本或需要显示真实离散程度时使用；抖动仅改变显示位置。
4. 峰峦图：适合多类别分布的整体比较；不作为精确读值的唯一图。
5. 密度图 / 直方图：适合比较分布形状，需保留可比较的分箱、范围或带宽。

若观测是同一对象的前后测量或配对情景，优先保留配对连线或共同标识；不能按独立样本处理。

## 一个类别型与多个数值型

### 无天然顺序

1. 分组散点图 `[首选]`：适合看类别下多个数值指标的散布、相关或分组结构。
2. 热图：适合“类别 x 指标”的矩阵总览；说明标准化、色标和缺失值口径。
3. 箱线图 / 小提琴图：适合每个指标在类别下都存在多条观测时比较分布。
4. PCA：适合已有或获授权计算的高维降维结果；说明输入、预处理和解释范围。
5. 相关图：适合看多个数值指标的关联结构；不是因果图。

### 一个有序维度

1. 折线图 / 连通散点图 `[首选]`：适合看多个指标在时间、阶段、等级或参数扫描中的变化。
2. 堆积面积图：只在指标具有共同单位、可加总关系且重点是构成与总量变化时使用。
3. 面积图：适合单一总体量级或累计变化，不适合多个独立指标的比较。
4. 流图：适合相对构成的流动；需要精确比较时辅以折线或表格。

### 每类别一个多指标向量

1. 热图 `[首选]`：适合指标较多或需要精确比较“类别 x 指标”矩阵时使用。
2. 分组点图 / 棒棒糖图：适合指标较少、希望直接比较数值时使用。
3. 分组条形图：适合指标和类别都不多、数值同量纲或读者需要柱形比较时使用。
4. 雷达图：只适合三至八个已统一方向和尺度的指标，且多边形数量较少。

雷达图必须说明效益型与成本型指标如何统一方向、各轴范围以及标准化依据。多边形面积不能自动解释为综合优劣。
雷达图径向数值、类别比较值和其他图内直接数据标注统一使用黑色 `#000000` 裸数字，不加白色背景框、`bbox`、底板、阴影或描边。

## 多个类别字段

### 子类

#### 每个主类和子类只有一个汇总值

1. 热图 `[首选]`：适合“主类 x 子类”的值或频数矩阵。
2. 分组条形图：适合子类较少、需要并排比较。
3. 堆叠条形图：适合子类构成主类总量时展示总量和组成。
4. 分组散点图：适合同时存在数值坐标或位置变量时使用。
5. 桑基图：仅在主类到子类有明确方向与流量时使用。

#### 每个主类和子类有多条观测

1. 箱线图 `[首选]`：适合比较嵌套类别下的数值分布。
2. 小提琴图：适合展示分布形状，必要时叠加原始点。
3. 分面图：类别组合过多时优先拆分，避免一张图塞满分组。

### 嵌套

1. 树状图 `[首选]`：适合表达明确父子层级。
2. 旭日图：适合由内到外显示层级路径。
3. 矩形树图：适合显示层级面积构成。
4. 柱状图：适合展开某一层进行精确比较。

层级图应保留父子归属、总量与重复计数口径。若层级下记录的是重复样本分布，而不是可加总组成，改用分布图而非面积构成图。

### 邻接或流向关系

1. 网络图 `[首选]`：适合看多个类别值之间的连接结构。
2. 和弦图：适合较少类别间的双边联系。
3. 弧线图：适合较少的平面连接路径。
4. 桑基图：适合有方向、单位和流量的转移。
5. 热图：适合把邻接或转移强度压成矩阵。

## 分组、堆叠与排序

- 分组用于并列比较独立系列；堆叠用于组成和总量。只有数值同单位且存在合理加总关系时才堆叠。
- 类别可以按数值排序以表达排名；时间、阶段、等级、路径和用户指定顺序不可随意重排。
- 同一对象跨图使用稳定的名称、颜色、线型、标记和顺序；颜色不能成为唯一的系列编码。

## 不要写什么

- 不要把“每类别一个汇总值”和“每类别多条观测”混成一类。
- 不要因为多指标就默认雷达图，也不要因为系列多就默认堆积图。
- 不要把标准化、方向反转、加权汇总或统计检验伪装成图表美化。
- 不要为了省版面把不同量纲、不同分母或不能相加的指标堆叠在一起。
