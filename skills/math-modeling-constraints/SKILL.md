# 数学建模：读题建立约束条件

## 概述
- 目标是把题面与附件中的约束转成可直接写入文档的“文字版约束 + 不等式表达”。
- 必须先调用 `math-modeling-brainstorm` 进行思考与范围澄清。

## 什么时候优先用本 skill
- 用户已经明确要你做“约束条件提取、整理、形式化表达”，而不是先做整题建模路线判断。
- 用户需要把题面、附件、表格字段中的限制转成文字版约束或不等式表达。
- 用户想先把“哪些必须满足、哪些可放宽、哪些属于软约束”理清楚，再进入目标函数或代码阶段。
- 用户已经有题目或材料，但限制条件比较散，需要统一汇总与分级。

## 证据链与逻辑严谨性（必须遵守）
- 对用户任何结论性回答，必须给出完整且可核查的证据链，至少包含：`已知事实/数据来源 -> 分析方法 -> 推理步骤 -> 结论 -> 不确定性与验证建议`。
- 结论必须逐条对应证据，不得跳步推理，不得以主观经验替代证据。
- 若证据不足，必须明确标注“证据不足”，先补充提问或给出可执行核验方案，再输出结论。
- 涉及约束来源、参数边界、不等式写法时，必须说明“为何这样设定”，并解释改动后可能带来的影响。
- 最终建议必须附带可复现检查点（如：题面位置、数据字段、关键符号定义、验证方式）。

## 使用流程（一步一问）
1. **调用思考中枢：** 先调用 `math-modeling-brainstorm`，完成问题拆解与范围界定。
2. **确认约束来源：** 若用户未明确来源，先问清楚（题面 / 附件 / 现有约束文档）。
   - **提问用数字选项（如 1/2/3），让用户只回数字即可。**
3. **读取与标注来源：** 逐条提取约束，标注来源位置（题面/附件/数据表）。
   - 若约束来自前一问的估计、预测或计算结果，必须标明来源问题和结果（result），并区分它是固定值、区间还是概率分布；不得把估计结果静默改写成题面硬约束。
4. **整理输出：** 按本技能定义的固定结构输出（先文字版，再“文字+不等式”）。
5. **核对缺失：** 如参数缺失，用符号替代并标注“待定/灵敏度分析”。
6. **不确定性处理：** 任何不确定或信息不足之处，必须明确说明并向用户提问，直到确认；不得隐含假设。

## 输出格式（结构说明，不依赖外部文件）
### 第一部分：文字版约束整理
- 分节标题由题面决定，不固定名称；常见可按“对象/资源、时间/阶段、空间/容量、规则/逻辑、流程/操作、数据来源”组织。
- 每条约束用自然语言清晰描述，并注明来源。
- 标注约束性质（硬/软）及作用范围（对象/时间/空间/类别等）。
- **按重要性排序**：越重要越靠前（先高后低），并给出优先级标签（高/中/低或必须/重要/可选）。

### 第二部分：文字 + 不等式形式
1) **符号与集合**（对象/时间或阶段/空间或区域/类别/参数与上下限等）  
2) **决策变量**（连续变量、整数变量、0-1变量、模式变量等）  
3) **分章节逐条表达**（与第一部分章节顺序一致，先文字解释，后公式）  
- 文字与数学表达分开，但顺序一致。
- 若某约束适合作为软约束，注明可做惩罚项。
- 不等式表达也需按相同优先级顺序排列。
- **MPE 中公式行首不要直接写 `-`，用 `\;-\;` 或 `aligned` 前置 `&`。**

### 输出交付
- 推荐输出为 **Markdown 文档内容**（可直接保存为 `.md`）。

## 约束优先级规则（通用）
- 优先级应反映“不可违反程度”与“问题成败影响程度”。
- 输出时严格按优先级从高到低排列，越重要越放在前面。
- 一般顺序：**硬约束/物理或安全可行性** > **资源容量/时空边界** > **时序或逻辑规则** > **软约束/偏好与优化倾向**。
- 若题面给出明确“必须/禁止/仅当/至少/至多”等措辞，默认优先级更高。

## 小范围问题也要严谨拆解
- 即使用户只问单条/小范围约束，也要像大问题一样完整思考与澄清。
- 只控制输出范围，不降低推理强度。

## 数据读取与规模处理
- 逐表逐列核对字段含义、单位与阶段/周期/批次字段，不跳字段。
- 大数据分块读取，建立覆盖清单（表名/行数/列数/关键字段）。
- 若无法完整读取，说明限制、已覆盖范围与潜在遗漏，并给出补读方案。

## 常见风险提示
- 类别/对象/阶段映射容易混淆，必须显式核对。
- 表格中分期/阶段/批次字段需统一映射规则。
- 区间参数（如范围值）若取均值须说明依据与影响。

## 完成后强制复审（再次头脑风暴）
- 在完成“约束条件建立/整理”后，**必须再次调用 `math-modeling-brainstorm`**。
- 复审目标：对照题目要求与附件数据（如 PDF 题面、Excel 附件），逐条核查**是否遗漏任何约束**、是否与题面一致。
- 如发现不符合或遗漏，**必须明确指出具体问题与位置**，并给出修正建议。
