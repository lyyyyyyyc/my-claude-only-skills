# 自然化改写审计清单

改写完成后执行这份清单。它检查的是可观察事实，不是“读起来像不像人”的主观评分。

## 事实与学术诚信

- [ ] 所有数字、单位、指标、样本范围和小数位与原始证据一致。
- [ ] 公式、变量、上下标、约束、初值、边界条件和算法名称没有被语言改写破坏。
- [ ] 图表编号、表格列、代码文件和正文引用仍然对应。
- [ ] 没有添加未做的实验、消融、基线、灵敏度、重复运行或统计检验。
- [ ] 没有把假设、相关性或定性观察升级成未经支持的因果或全局最优结论。
- [ ] 没有新增虚构文献、参数来源、实验设备、调试经历或作者决策。

## 表达与证据

- [ ] 套话和连接词被删减或改为准确逻辑，而不是被另一组固定套话替代。
- [ ] 连续句子不再机械使用同一主语、谓语和段首模式。
- [ ] 关键结果至少有数据、图表、公式、文献或题面依据中的一种明确支撑。
- [ ] 结果分析先报告观察，再给解释，并限定解释的适用条件。
- [ ] 方案权衡、风险提示和异常排查只有在真实记录或当前明确推理支持时才出现。
- [ ] 术语没有为了“换词”而变得不准确，句式变化没有降低可读性。
- [ ] 已检查九类常见痕迹：句长均匀、段落对称、连接词过密、“不是 X 而是 Y”过密、抽象名词堆积、内容空泛、结果过于完美、引用与判断脱节、语言水平跳变。
- [ ] 模型选择、参数来源、失败方案和适用边界均有真实依据；缺证据的内容已标记为待核验或待验证。
- [ ] 已从图表中提取可核查观察，并回到程序输出或数据确认，而不是凭目测编造数值。

## 交付说明

输出改动记录时，至少说明：

| 项目 | 内容 |
|---|---|
| 改写范围 | 哪些章节、段落或代码被处理 |
| 主要模式 | 全局风格 / 模型建立 / 结果分析 / 代码注释 |
| 删除的模板痕迹 | 具体重复结构或空泛表达 |
| 保留的事实 | 数字、公式、数据、引用、结论 |
| 待核验内容 | 缺少的记录、来源或图表 |
| 作者确认项 | 可能改变语气、强度或解释边界的改动 |

不要输出未经检测器定义和实际测量的“AI 率下降百分比”。自然化的合格标准是表达更准确、证据更贴合、
作者判断不被伪造，而不是某个检测器的不可复现分数。
