# 全局写作风格自然化

本文件对应原模块 A，适用于数学建模论文的中文或英文正文。目标是消除机械模板感，保持学术表达的准确、克制和可核查性。

## 1. 处理模板化过渡词

以下词语不是绝对禁词，但不应机械地作为每段开头。先判断逻辑关系，再决定是否保留：

- 英文：`Furthermore`、`Moreover`、`Additionally`、`Consequently`、`Notably`、`It is worth noting that`、
  `In conclusion`、`To summarize`、`In summary`、`It should be emphasized that`、`It is important to note that`、
  `Subsequently`、`Thereby`、`Accordingly`。
- 中文：`此外`、`值得注意的是`、`综上所述`、`总而言之`、`需要指出的是`、`不言而喻`、`显而易见`、
  `毋庸置疑`、`与此同时`、`在此基础上`、`有鉴于此`、`由此可见`。

处理优先级：

1. 如果逻辑关系已经由内容自然表达，直接删掉连接词。
2. 如果确实需要因果、转折或递进，换成准确、短的关系词，如“因此/但/进一步”，并紧跟事实或判断。
3. 用具体事实连接句子，不用空泛评价。例如，把“此外，该方法精度较高”改成“在测试集上，最大残差为……，
   相比基线下降……”。数字必须来自实际结果。
4. 不要把所有连接词都替换成另一个固定词，否则只是更换模板。

## 2. 打散重复句式

- 避免连续句子重复“本方法……”“我们……”“结果表明……”的主语和谓语结构。
- 不要连续使用“首先/其次/最后”来模拟完整性；若只有两个事实，直接按因果或时间关系组织。
- 合并真正属于同一判断的短句，拆开承载不同证据的长句。
- 技术细节可以用较长句子展开，关键判断可以用短句落地；不要为了满足固定字数而硬拆或硬并。
- 不要把三个优点写成同构清单。应说明主优势、代价、适用条件和限制；没有证据的优点不补写。

示例：

> 本方法具有计算效率高的优点。本方法具有精度高的优点。本方法具有实现简单的优点。

可改为：

> 在相同计算预算下，RK4 的截断误差低于 Euler 法。代价是每个时间步需要计算四次右端函数值；对本题规模而言，
> 额外开销仍在可接受范围内。实现上的关键并不复杂，但中间状态 `k1` 到 `k4` 必须保持同一时间层的定义。

这里的具体数值、计算预算和“可接受”判断都必须有对应实验或记录；示例中的数字不能直接套用。

## 3. 调整段落节奏，但不制造规则感

- 相邻段落不要都以同一种句式开头，例如不要连续使用“根据……”“由……可知”。
- 适当加入简短的判断或限制句，让段落体现研究者对模型边界的自我审视。
- 只有作者确实使用的术语才保留第一人称“我们”；如果原稿采用客观语态，不要强行改成“我们”。
- 可以使用破折号或括号补充限定条件，但应服务于信息层级，不能作为装饰。
- 不强制每段包含长句、短句或口语表达，也不强制每千字出现固定次数；机械配额会制造新的 AI 风格。
- “这里的关键在于”“问题出在”等口语化表达只能偶尔使用，并且必须连接具体技术事实。

## 4. 作者视角的合法来源

自然的学术写作可以呈现判断、取舍和限制，但只能来自：

- 用户提供的建模讨论或方案比较。
- 代码、实验日志、结果文件中可核验的实际过程。
- 题面约束、文献、物理量级估算或数据证据。

若没有上述材料，应写“本文选择……，原因是……”的当前论证，不得写成“我们最初试过……后来排查发现……”。
