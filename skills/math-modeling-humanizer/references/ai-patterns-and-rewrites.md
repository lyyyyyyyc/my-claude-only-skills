# AI 写作痕迹诊断与改写

本文件蒸馏图片中的“AI 味”诊断框架。它用于识别模板化结构和空泛表达，不是机械禁词表，也不能单凭语言表面判断文本是否由 AI 生成。

## 1. AI 味的工作定义

在数学建模论文中，所谓“AI 味”通常不是某几个词，而是多种可观察特征叠加：

> 模板化结构 + 过度平滑的语言 + 泛化内容 + 缺少真实决策或证据痕迹。

因此改写不能只做同义词替换。应同时检查信息是否具体、结论是否有证据、方法选择是否有依据、段落结构是否服务于
当前小问，以及语气是否与原作者一致。

## 2. 九类常见痕迹

### 2.1 句长过于均匀

连续句子长度接近、每段句数固定、信息密度几乎相同，容易呈现批量生成感。根据内容重新组织句子：复杂推导可以长一些，
关键判断可以短一些，但不要为了制造波动而硬拆句子。

### 2.2 段落过于对称

常见结构是“背景 -> 三点 -> 总结”，甚至每个观点都写成完全相同的三句。保留真正的逻辑层级即可；若只有两个有效观点，
不要为了凑成“三点”补一个空观点。

### 2.3 连接词密度过高

`首先、其次、再次、最后、此外、进一步、综上所述` 或 `First、Second、Finally、Moreover、Furthermore、In conclusion`
连续出现时，段落会像套用提纲。能直接连接的地方就删掉；需要连接时，使用准确的因果、转折、时间或条件关系，并马上接具体信息。

### 2.4 “不是 X，而是 Y”过密

连续用否定对比制造所谓深度，往往没有增加信息。只有在确实需要区分两个定义或两个机制时保留；其他情况直接写比较对象、
差异和数据。

### 2.5 抽象名词堆积

“赋能、重构、机制、维度、范式、闭环、协同、体系、框架”等词如果没有对应变量、操作或结果，会遮蔽真正动作。改写时追问：

- 谁对什么对象做了什么操作？
- 输入、输出或约束是什么？
- 这个词对应哪一个变量、方程、算法、图表或决策？

不能回答时，换成具体动词、对象和过程。

### 2.6 内容正确但空泛

“提高准确性、增强鲁棒性、提升可解释性、具有重要意义”等判断，若没有指标、实验、图表或明确应用对象，只是空壳。应改成
可核查的结果，例如误差、排名、扰动区间、解释变量、决策变化或实际约束。

### 2.7 结果过于完美

全文没有异常样本、失败方案、敏感区间、边界条件或误差来源，所有分析都顺利闭环，会削弱可信度。可以报告真实的偏差、限制和
未解决项；没有真实记录时，不能编造失败经历或“意外发现”。

### 2.8 引用与作者判断脱节

文献全部堆在段末，却没有说明哪篇文献支持哪个定义、参数范围、方法选择或研究缺口。应把引用贴近它实际支持的判断；如果是作者
基于本题数据的选择，要明确区分“文献依据”和“本文观察”。

### 2.9 语言水平突然跳变

前文是普通、具体的学生式表达，某一节突然出现大量复杂长句和高阶术语，容易显得拼接。统一术语、句法和信息密度；复杂术语只有在
它比普通表达更准确时才使用。

## 3. 结构层改写原则

- 定义段可以只有两句；模型建立段可以更长，因为需要承载变量、约束和推导关系。
- 不要每个小节都写成同一套“背景 - 三点 - 总结”，也不要每段最后都加“因此，本模型具有重要意义”。
- 已有三级标题、公式编号或图表逻辑时，不要再用“首先/其次/最后”重复导航；让标题和公式承担结构作用。
- 结果段可按“观察 -> 解释 -> 决策”组织，而不是固定“目的 -> 方法 -> 结果”的空模板。
- 每个句子尽量承担一个主要任务：报告数据、解释机制、限定边界或做出决策，不要在一个长句里同时塞入背景、方法、结果和意义。

## 4. 高频模板替换表

下表是诊断方向，不是强制逐字替换。右侧写法必须填入当前论文的真实内容。

| 常见模板 | 暴露的问题 | 更合适的写法 |
|---|---|---|
| 值得注意的是，模型显著提升了性能 | 强调词代替证据 | 指出具体测试集、指标、数值和比较对象 |
| 在此基础上，进一步构建综合评价体系 | 模板衔接、动作不明 | 说明标准化的几个指标如何进入 TOPSIS 或其他实际步骤 |
| 从多个维度对问题进行深入分析 | “维度/深入”没有内容 | 直接写比较成本、等待时间、违约率等具体对象 |
| 模型具有良好的鲁棒性 | 评价空泛 | 写清参数扰动范围、排名/预测/目标值变化和结论边界 |
| 综上所述，该模型具有重要意义 | 万能结尾 | 删除，或改成一个具体的模型决策、预测结果或适用条件 |
| 研究范式 / 发展范式 | 抽象名词过重 | 若实际指模型或框架，直接写“模型”“框架”及其作用 |
| 模型揭示了内在机制 | 因果强度过高 | 若证据不足，改写为“结果与……关系一致”或“可能反映……过程” |
| 赋能 / 重构 / 颠覆 / 闭环 | 动作和对象不清 | 说明具体改了什么、输入什么、输出什么、带来什么可测变化 |

## 5. 改写后的最低标准

一段自然化后的正文不需要刻意显得“像人”，但应满足：读者知道你观察了什么、做了什么选择、依据是什么、结果支持到哪一步、
还有什么限制。没有这些内容时，优先补足已有证据的表达，不能用华丽词语或虚构经历填空。
