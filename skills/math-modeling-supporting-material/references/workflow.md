# 制作细则

## 内部盘点与提交范围

读取题目、原始附件、当前论文入口、各问代码、公共计算、检验和绘图结果。先确定论文实际使用的版本；多个版本有差异时先确认，不根据时间戳猜测。

原文件、哈希、功能、交付脚本、前序依赖、输入输出和排除理由写入包外审核目录。废弃探索稿可排除，论文选用模型的依据、敏感性和对照实验代码仍保留。来源记录不随支撑材料交付。

结果文件逐项回答一个问题：它直接给出了赛题所问的什么答案？能回答才进入对应题号目录。最终计划、授信方案、风险评级、逐对象决策、冲击调整和必要汇总可以保留，单独的清洗或验收过程文件留在包外。选择范围以文件为单位；选中的答题工作簿连同其原有辅助工作表完整复制，不拆表、不裁列。

论文表格另建完整清单，从当前论文逐表登记表号、标题、所在页、行列数和跨页情况。符号说明、数据统计、参数表、模型对照、敏感性及附录表均检查，不能因为不属于直接答题结果而漏收论文表。

## PY 改写

1. 用 JSON 或 nbformat 解析原 Notebook，读取代码单元；source 可能是字符串或字符串列表。识别跨单元变量、跨文件输入和真实顺序。这些格式细节只在技能和内部操作中使用，不写进交付说明。
2. 移除空单元、重复导入、纯展示、无效日志和专用内核语法；依赖在清单中管理。不得把必要计算随展示代码删掉。
3. 保留模型训练、特征处理、折内筛选、数据划分、随机种子、求解器设置、扰动实验和约束。精简抽象与重复，不用一行表达式压缩可读性。
4. 留下必要的中文功能注释，不随机删字、不承诺降低 AI 检测率。去掉制作历史、源文件出处和长篇自证说明。
5. 改名时一起核对动态参数字典、`**kwargs`、数据列、命名元组、序列化类路径和库 API。原始字段可集中映射，结果标题和表头尽量中文。
6. 原始附件只读，输入参数显式传入，不能依赖个人工作目录或原中间表。用户没有提供题外数据时，User_data 为空。
7. 每个功能脚本有主入口，能在前序产物存在时单独执行；使用少量公共代码与总入口管理依赖，不强行做成复杂工程。
8. 非 Python 程序必须用可靠 Python 实现重写并比较结果，不靠改后缀或隐含调用未交付程序实现全 PY。

## 运行产物隔离

`run_all.py` 按依赖调用功能脚本，错误即停止。原始输入、临时计算目录和必要参数通过接口提供；临时目录在交付包外。对包内临时目录参数进行拦截，避免再次生成待清理的目录。

所有中间数据、模型、诊断图、日志、环境记录和详细实验表放到临时目录。采用文件级发布清单，只将答题结果原文件、论文表格和编号图片交付到 Figures。结果发布直接复制文件，禁止重新读取后写成新表、合并文件、删行列、调格式或额外加色；复制前后字节须一致。用户要求删除的独立过程文件不能被移到 Code 或其他位置规避。

完整运行、续跑及缓存依赖的详细方法只在程序帮助和内部工作记录中保留。Readme 的第二部分只写环境，通常一至两句。Windows 数值环境按实际激活或用 conda run；依赖版本以已用环境为准，优先隔离环境，不自动升级共享环境。

## 图片和结果表

先从论文正文列出使用的图片，再按出现顺序编码为 01、02、03，去掉来源前缀并填平断号。同一图多种格式共用编号；多格式不是多张图。

现有图片只调整文件名和不必要元数据，不改变图面。隐私清理后用像素比较和尺寸核对确认内容；不能要求清理前后 SHA256 一致，也不能只改 DPI 标签冒充更清晰的图。真正重绘仍遵守用户的字体、DPI和格式要求，必要时调用适用绘图技能。

结果表格按题号存放原程序输出，文件名、工作表、行列、排序、单位、精度、公式和原有样式全部保留。不额外设置颜色、字体、边框、行列尺寸、筛选或冻结；原程序已有样式也不主动抹掉。分别核对完整对象与情景、主键、记录数和 SHA256，不只比数值。不要用截图替代可编辑结果表。

论文全部表格单独放在 paper_tables，按论文顺序一表一文件，保留表号与标题，不加来源表或总索引。已有与论文一致的可编辑原表时原样复制；只能从论文提取时，准确恢复内容、单位和显示精度，采用普通无配色表格，不添加装饰。正确处理表头分隔、公式竖线、长表重复表头、合并单元格及 OCR 误识别，并与实际论文逐格核对。不能用完整计算表替代论文中的节选表，也不能用节选表代替完整计算结果。

附录中的文件说明若指向私人工作目录，将提交副本中的导航映射到支撑材料真实文件名，包外记录映射；论文原文不改，其他科研表格内容不改。若无法兼顾完整性和隐私，明确指出具体冲突，不静默漏表。

## 隐私与文案

交付包内所有文件都检查，不只看 Readme。重点是源码字符串、作者信息、EXIF/PNG文本块、办公文件属性、批注、隐藏工作表、超链接、外部链接和嵌入路径。发现结果文件含个人信息时，在生成端移除非业务身份信息并重新输出，再原样复制；不能借脱敏另改样式或数据。经核实的通用生成器属性（如 openpyxl）不是个人身份，不清除它来破坏字节一致性。题面企业名称和合法样本字段正常保留。

交付文案不提 Notebook、MD、Markdown、LaTeX 等制作格式，不讲原项目怎么组织、不列验证日期和过程记录。正常介绍“求解程序、论文图片、结果表格”即可。系统字体的公共安装位置不属于个人路径，但本机用户字体目录须换成可配置或可移植的字体查找。

用文字扫描加元数据解析核对。可见图面有路径或姓名时必须查看并重制受影响图片，不能只清理属性。文案简短不等于虚构：真实缺失依赖或未完成验证在对话说明，不能声称已经完成。

## 数据分类

| 类型 | 处理方式 |
|---|---|
| 原赛题附件 | 通过程序参数读取，默认不重复打包，不在 Readme 展开文件名清单 |
| 实际使用的题外数据 | 放 User_data，保留使用必需的匿名化数据；许可允许且必要时附简短来源说明 |
| 人工设定的情景参数 | 在代码或必要配置中定义，不放 User_data 冒充观测数据 |
| 自产特征、模型、日志及缓存 | 包外临时目录 |
| 字体、运行依赖 | 写环境和依赖清单，不擅自分发无授权文件 |

无题外数据时目录真空；压缩工具可能漏掉空目录，应检查目录项而不是添加占位文件。无法分发的必要题外数据在对话说明并处理依赖，不能假称材料自包含。

## 故障排查

| 表现 | 核查与处理 |
|---|---|
| 数值计算原生退出 | 最小复现并检查环境激活、动态库与退出码，不把某次环境原因套用到全部故障 |
| 改名后未知关键字 | 检查参数字典、动态调用和函数签名是否同时更新 |
| 色板或数据表未定义 | 补回初始化，排除旧内核隐藏状态 |
| Path 无法写 JSON | 显式转换对应字段，不用全局 default=str 隐藏类型问题 |
| colorbar 后布局报错 | 创建画布时确定布局，不在保存前切换布局引擎 |
| 导出字体变化 | 保存时仍应用字体上下文，检查真正导出的文件 |
| 中文方框或数学字体缺字 | 核对实际字形覆盖，不用仅含扩展汉字的字体，也不把中文送入不支持的数学字体 |
| Agg 后端交互警告 | 批量脚本保存并关闭图片，不要求交互 show，不全面屏蔽警告 |
| 连接后列名消失或空表 | 检查主键、同名列后缀和索引对齐 |
| 禁入对象获选数刚好为零 | 同时核对候选过滤和最终决策，验证约束真实生效 |

## 清理与重验

先备份现有材料到包外，再在候选目录生成新结构。移动或清理前解析绝对路径并确认在允许范围，注意 Windows 连接点，不递归删除原项目。

代码改变后重验受影响步骤和下游。保留完整运行与增量记录在包外，不能仅更新哈希让旧日志匹配新代码。交付时只保留规定文件，重跑后同样检查目录、编号、结果选择和隐私。
