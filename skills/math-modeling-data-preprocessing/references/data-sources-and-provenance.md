# 数据来源、外部材料与溯源

仅在题目附件不足、需要外部变量/参数/阈值/背景依据或需要独立验证时读取本文件。外部材料不是“搜到就能用”；先确认它解决什么问题，再判断是否适配、可用、可引用。

## 1. 先定义用途

对每个候选外部材料只选定明确用途，可多选但须分别说明：

| 用途 | 需要重点核验 |
|---|---|
| 模型输入 | 预测时点可得性、粒度、覆盖范围、连接键、许可 |
| 参数估计 | 对象、单位、测量/估计方法、版本、时间适配性 |
| 阈值或约束依据 | 适用人群/设备/地区、口径、版本、边界条件 |
| 假设论证 | 原文论断是否支持当前假设，而非只支持相似背景 |
| 独立验证 | 数据与训练数据的独立性、评估口径一致性 |
| 结果讨论 | 统计口径和比较范围，避免与模型输入混淆 |

题目附件已经足够时，不因资料“看起来更丰富”而引入外部数据。外部数据可以进入模型，但必须通过时间可用性、粒度和泄漏检查；“外部数据一律不进模型”同样不成立。

## 2. 候选来源到已核验来源

1. 从题目、数据字典、原始发布机构、论文参考文献、补充材料和综述的来源清单开始检索。
2. 搜索引擎结果、AI 提供的名称、二手转载页和无法打开的链接只登记为“候选”，不作为已核验依据。
3. 打开原始页面、原文或下载内容，核对发布者、字段说明、覆盖范围、更新时间、版本和使用条件。
4. 将“来源存在”与“来源适合当前任务”分开判断。来源权威不能补足粒度、时间或口径不匹配。
5. 文件下载后记录文件名、大小、必要时校验值、读取日期及读取配置；网页动态更新时同时记录访问日期和页面所述版本日期。

## 3. 可用性判定表

对每个来源填表并给出 `通过 / 条件通过 / 不通过` 结论：

| 检查项 | 要问的问题 | 常见处置 |
|---|---|---|
| 发布者与原文 | 是否能定位原始发布者和原始页面/文献？ | 无法核验时仅作背景候选 |
| 覆盖对象 | 地区、对象、人群、设备或情境是否适配？ | 说明外推限制或放弃 |
| 时间覆盖 | 数据期、事件期、发布时间与预测时点是否匹配？ | 只用于可用时间之后的描述或调整任务 |
| 粒度 | 行代表什么，能否与当前实体/时间粒度对应？ | 聚合/拆分前评估信息损失，不能伪造细粒度 |
| 字段与单位 | 是否有关键变量、定义、单位和缺失说明？ | 单位转换需保留原值和规则 |
| 统计口径 | 是流量、存量、均值、比例还是模型估计？ | 不按名称相同直接合并 |
| 版本与稳定性 | 能否标明版本、更新时间和获取日期？ | 标注不可复现风险 |
| 连接条件 | 是否有可靠键、允许的时间间隔和匹配方向？ | 转入连接/时间对齐审计 |
| 使用限制 | 下载、分析、共享、公开附件和上传外部服务是否允许？ | 采用本地受限处理或替代来源 |

不要以固定样本量、固定“近几年”或某个平台名称作万能可用性标准。样本量是否足够取决于任务、效应大小、组数、模型复杂度和不确定性目标。

## 4. 权限与敏感性

分别核验并记录以下状态：`允许 / 限制允许 / 未确认 / 不允许`。

- 获取：是否允许下载、抓取或通过接口读取。
- 分析：是否允许用于本次竞赛、研究或商业分析。
- 共享：是否允许向队友、评委、公开仓库或附件再分发。
- 上传：是否允许上传至云端、第三方模型或外部 AI 服务。

不得绕过访问控制、反爬限制或付费墙。无法确认时，不应默认允许；优先仅在允许的本地环境处理，或更换来源。

## 5. 无实测数据时的替代路径

无法获得真实观测值时，明确区分：

| 类型 | 可用于什么 | 不可声称什么 |
|---|---|---|
| 文献参数 | 参数先验、敏感性分析、情景比较 | 当前样本已经实测 |
| 待校准参数 | 在训练范围内估计或校准 | 已被独立验证 |
| 情景区间 | 稳健性与边界分析 | 真实分布或唯一真值 |
| 仿真设定 | 检查方法在设定机制下的行为 | 现实系统有效性 |

记录区间依据、生成机制、随机种子、模拟次数和验证用途。不要把演示数字、文献数字或仿真输出写成当前数据的实测结果。

## 6. 最小来源登记

每份外部数据、参数或阈值至少记录：

```text
source_id:
status: candidate / verified / rejected
publisher:
title_or_identifier:
original_location:
accessed_on:
version_or_release_date:
coverage: object / region / time
granularity_and_unit:
intended_use:
compatibility_decision:
license_and_usage_limits:
local_file_or_query:
verification_notes:
paper_citation_location:
```

参数还应记录原文页码、表号或公式位置。若来源被拒绝，保留拒绝理由，避免后续重复检索并误将候选重新当成已核验材料。
