# 读入、解析与模式核验

仅在存在多格式读入、列名问题、混合类型、日期转换、单位文本、边界值或编码映射时读取。本文件强调“原始值可追溯、失败可定位”；它不替代专门的 PDF/OCR/文档提取技能。

## 1. 读入前与读入后的核验

读入前记录格式、工作表或页码、表头行、编码、分隔符、单位行、合并单元格和脚注。读入后核对：

- 工作表、跨页续表、合计行、脚注和隐藏行是否被错误当成观测。
- 千分位、负号、小数点、科学计数法、百分号、日期系统和文本编码是否按预期解释。
- 行数、列数、原始列名、代表记录、关键字段范围是否与原文件相符。
- 大文件若先抽样体检，需标注抽样范围；抽样未发现问题不等于全量不存在问题。

对扫描件或复杂文档的提取结果，至少随机回对原页面的表头、关键数值、页间衔接和脚注。提取工具如何运行属于其专门技能，本技能只验收结构与语义。

## 2. 列名与字段字典

列名规范化可包括去首尾空白、替换不可见字符、统一换行/空白及限定的命名规则。规范化前后均应保存映射：

```text
source_table | original_column | normalized_column | action | rationale
```

必须检查：

1. 空表头、重复表头、`Unnamed` 类表头和规范化后新重名。
2. 跨表同名异义、同义异名及同名不同单位。
3. 空表头列是否含有效数据；不能按名称前缀直接删除。
4. 删除列的理由、非空值数和业务确认状态。

## 3. 类型体检与受控转换

表层 `dtype` 不足以说明列内容。对日期候选、数值候选和混合列记录实际值类型频数、非空样例、异常编码及解析候选。例如：

```text
field | declared_dtype | observed_types | non_null_examples | special_codes | planned_rule
```

转换应遵循：

- 保留原字段或可逆的原值副本，写入新字段后再替换。
- 明确允许格式、单位、时区、合法范围和失败去向。
- 转换前保存“原值是否有效”的逐行标记；转换后分别统计原生缺失、合法占位符转缺失、已确认非法值转缺失和解析失败。
- `errors='coerce'` 只可用于将失败值收集到待核验表，不能让失败静默消失。
- 逐行记录新缺失的行标识、原值、规则、失败原因和目标字段。总缺失数相同也不能证明转换没有损失。

## 4. 日期、时间与时区

为每一种日期表示建立分支规则，而不是用一个自动推断覆盖所有值：

| 原始形式 | 需要确认 |
|---|---|
| 已是日期时间对象 | 时区、精度、空值 |
| 年月日整数 | 位数、零填充、合法日期 |
| 带分隔符文本 | 年月日顺序、地区习惯、时区 |
| Excel 序列值 | 日期系统、数值范围、是否真为日期 |
| 混合文本 | 每个格式分支、歧义和失败样例 |

`format='mixed'` 可以作为探索工具，但不能替代格式审计。月日顺序或时区有歧义时，必须查数据字典、来源说明或标记为未确认。解析后检查最小/最大日期、时区、异常年份、跨日边界和新增 `NaT`。

## 5. 复合量、区间与检测限

对“主单位 + 子单位”文本，先定义换算关系、允许格式和子单位范围。例如不要把任意 `x+y` 都解释为一个量。验收至少覆盖纯主单位、零子单位、上界、越界、空白和非法格式。

对 `>=3`、`<0.01`、`1-3`、`未检出` 等值：

- 保留原始表达及不等号/区间/检测限语义。
- 根据模型选择有序类别、边界值加界限标记、区间方法或删失方法。
- 不得无说明地把边界值当成精确数值；边界值加标记不恢复被隐藏的真实值。

## 6. 类别、标签与派生字段

类别映射需有已核验来源。映射表至少包含：

```text
original_value | normalized_value | category | status | source_or_rule
```

- 未知、空白、异常编码和“不适用”要保留为不同状态，除非已确认可以合并。
- “不是 A”不能自动改成“B”；派生列名必须反映实际覆盖范围。
- 标签缺失不得自动编码为阴性、正常或未发生。
- 编码后核对各类别的转换前后交叉表、未知率和新缺失。

## 7. 解析验收最小集

每项高风险解析执行以下可观察检查：

1. 结构断言：字段是否存在、规范化后是否唯一、行列数是否符合预期。
2. 边界样例：空值、上界、下界、非法值、歧义格式与异常单位。
3. 行级追踪：抽查或全量检查原值、转换值和失败原因。
4. 汇总对照：原生/新增缺失、值域、类别频数、日期范围和独立实体数。
5. 回读：保存后重新读取并核对模式、时间、类别、精度与关键阈值判断。

任何检查结果都应标明是实际运行、外部资料、演示示例还是待运行占位符。
