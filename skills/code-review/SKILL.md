# Code Review 技能

## 描述
当用户请求代码审查时自动激活。帮助检查代码质量、发现潜在bug、提供优化建议。

## 何时使用
- 用户说"review"、"审查"、"检查代码"时
- 用户提交代码前想要检查

## 指令
1. 检查代码是否有语法错误
2. 检查潜在的安全漏洞
3. 检查代码风格是否一致
4. 提供性能优化建议
5. 使用中文回复

## 输出格式
### 🔍 代码审查报告

**文件**: [文件名]

#### ✅ 优点
- ...

#### ⚠️ 问题
- ...

#### 💡 建议
- ...
