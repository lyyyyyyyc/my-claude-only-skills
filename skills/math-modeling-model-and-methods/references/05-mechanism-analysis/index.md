# 机理分析类方法索引

## 这类问题主要解决什么
- 机理分析类问题主要处理“系统内部规律、物理 / 化学 / 生物 / 工程机理、变量演化关系”的问题。
- 输出通常是方程、机理模型、参数解释或系统行为分析结果。

## 典型输入 / 输出特征
- 输入：
  - 已知机理规律
  - 守恒关系
  - 物理量、状态变量、边界条件
- 输出：
  - 方程模型
  - 机理解释
  - 参数意义
  - 系统演化结论

## 候选方法清单
- 常微分方程（ODE，详见 `ode.md`）
- 差分方程
- 偏微分方程（PDE）
- 微分代数方程（DAE）
- 守恒关系建模
- 传热 / 传质 / 动力学机理模型
- 参数辨识与数据校准（详见 `parameter-identification.md`）

## 各方法适用场景 / 不适用边界
- 常微分方程：适合有限维状态的连续时间变化过程；不适合空间分布不可忽略却被强行压缩成单一状态的问题。
- 差分方程：适合离散时刻、逐期演化问题；不适合连续空间连续时间高精度过程。
- 偏微分方程：适合同时涉及时间和空间变化的问题；需要明确边界、初始条件和离散化方案。
- 微分代数方程：适合微分状态与代数约束同时存在的系统；需要检查约束一致性和初始条件可行性。
- 守恒关系建模：适合质量、能量、流量等守恒问题；不适合根本没有守恒机制可依的问题。
- 传热 / 传质 / 动力学机理模型：适合工程、物理、生化过程问题；不适合纯经验统计关系主导的场景。
- 参数辨识：适合方程结构已有依据但参数未知、且存在可对齐的观测数据；不适合只凭极少数据同时自由估计大量参数。

## 常见混淆点与误判风险
- 机理分析类和预测类经常混淆：前者先解释“为什么这样变”，后者更关注“将来会变成多少”。
- 有真实机理支撑时，不应直接跳到黑箱模型。
- 机理模型并不排斥数据分析，很多题目需要“机理 + 数据校准”。
- ODE 的模型参数、数值求解器参数和智能算法超参数必须分开记录；`rtol`/`atol` 变化会改变数值误差和拟合目标的可比性。
- Euler 适合教学、初步检查和误差分析，不应因为能运行就默认适合最终高精度结果；刚性问题应考虑 Radau/BDF 等隐式方法。

## 与邻近类别的区别
- 相比预测类：机理分析强调解释系统规律，预测类强调未来输出。
- 相比仿真模拟类：机理分析更偏建模方程本身，仿真模拟更偏在规则已知基础上做运行试验。
