# 统计分析类方法索引

## 这类问题主要解决什么
- 统计分析类问题主要处理“描述数据、检验差异、分析相关关系、降维提取结构”的问题。
- 输出通常是统计量、显著性结论、相关关系、主成分 / 因子结构等。

## 典型输入 / 输出特征
- 输入：
  - 样本数据
  - 实验 / 调查结果
  - 多变量观测值
- 输出：
  - 描述统计表
  - 显著性检验结果
  - 相关性结论
  - 降维结果

## 当前可直接读取的方法
- 相关分析（Pearson / Spearman / Kendall）
- 主成分分析

## 各方法适用场景 / 不适用边界
- 描述统计：适合快速概览数据特征；不适合直接替代机制解释或预测。
- 假设检验：适合检验差异或关系是否显著；不适合样本条件和前提完全不满足的情况。
- 方差分析：适合多组均值差异比较；不适合组间结构极不平衡且前提未检查的情况。
- 相关分析：适合分析变量关系强弱；不适合把相关误写成因果。
- 主成分分析：适合降维和提取综合指标；不适合变量间几乎无相关结构的问题。
- 因子分析：适合挖掘潜在公共因子；不适合样本太小、结构不稳定的问题。

## 常见混淆点与误判风险
- 统计分析类不等于评价类；统计分析更偏“解释数据”，评价类更偏“综合打分”。
- 相关分析不能直接得出因果结论。
- 主成分分析和因子分析不应混用为同一件事。

## 与邻近类别的区别
- 相比预测类：统计分析类不一定预测未来，更多是在解释现有数据。
- 相比评价类：统计分析类强调统计结论，评价类强调综合排序。
