# 模型检验索引

## 这份索引解决什么

模型检验用于说明模型结果的可信边界，而不是把所有检验指标堆进论文。它是跨题型环节：先明确要支持的主张，再选择能直接检验该主张的证据。

模型检验不替代各题型的专属验证：

- 评价类仍要检查权重、标准化、对象增删和排名稳定性；
- 优化类仍要检查变量域、约束、求解状态、上下界或 `MIP gap`；
- 分类和聚类仍要使用类别、概率或簇结构的专属指标；
- 机理模型仍要检查量纲、守恒、非负性、初边界条件与数值精度；
- 随机仿真仍要报告随机设定、收敛、方差或置信区间。

## 先判断检验问题

| 需要回答的问题 | 读取内容 | 不应替代的证据 |
|---|---|---|
| 预测/拟合偏差有多大，错误集中在哪里 | [误差与残差诊断](error-and-residual-diagnostics.md) | 独立验证、优化可行性、物理约束 |
| 面对新样本、未来数据或未见群组时是否仍有效 | [泛化评估与复杂度诊断](generalization-diagnostics.md) | 训练集拟合度、单次最佳折 |
| 哪些输入或参数会推动输出变化 | [灵敏度分析](sensitivity-analysis.md) | 因果结论、样本外预测能力 |
| 核心结论是否依赖某一数据定义、样本范围、模型设定或处理方式 | [稳健性检验](robustness-checks.md) | 所有替代模型都必须一致 |
| 评价排名是否依赖权重、指标或评价对象 | [评价模型稳健性与敏感性分析](../01-evaluation/evaluation-robustness.md) | 通用预测误差阈值 |

## 跨题型路由

### 预测与回归

先检查时间、群组或独立同分布结构，确定留出、交叉验证或滚动验证；再报告样本外误差、必要的残差诊断和关键场景误差。详细时间序列规则优先读取：

- `../03-prediction/prediction-validation.md`
- `../03-prediction/forecasting-workflow.md`

### 分类与聚类

分类任务使用主指标、类别级表现、阈值/概率校准和交叉验证；聚类任务使用内部/外部指标及稳定性。详细规则优先读取：

- `../04-classification-and-recognition/classification-clustering-validation.md`

### 优化

纯确定性优化不强行划分训练、验证、测试。先复算目标值、约束违反量、变量域和求解器状态；精确方法提供上下界或最优性证据，随机启发式方法报告多随机种子、可行率、运行时间和稳定性。

### 机理模型与参数辨识

先检查单位、符号、初边界条件、守恒、非负性和数值精度。需要由数据估参时，再区分训练/验证/测试、参数可识别性、观测噪声和独立验证。详细规则优先读取：

- `../05-mechanism-analysis/ode.md`
- `../05-mechanism-analysis/parameter-identification.md`

### 评价

评价稳健性由通用稳健性规则和评价专属规则共同组成。通用文档解释何时做变量、样本和模型设定替换；评价专属文档处理权重扰动、GRA/FCE 参数、指标或对象增删和排名一致性。

## 最少记录

每次模型检验至少记录：

```text
待检验主张
模型、数据版本与评估对象
参照数据、基准模型或约束
数据依赖结构与划分方式
改变的对象、范围和依据
固定条件与重新拟合范围
主指标、辅助指标、单位和判据
随机种子、求解配置或模型调用预算
结果波动、失败样本/失败运行和限制
结论支持什么，以及不能推出什么
```

## 实际执行责任

本目录不假设存在独立的“模型检验执行 skill”。用户要求实际计算时，当前执行代理必须在可用的数据和代码环境中运行所选检验，并回传可复核的数值、图表或失败记录。开始前必须形成以下交接包：

```text
模型与代码版本
数据版本、抽取规则和依赖结构
训练/验证/测试、重抽样或情景划分规则
待改变对象、范围、固定条件与范围依据
指标、单位、通过判据及其依据
随机种子、求解器/数值配置、计算预算
预期图表、异常/失败运行的记录与处理方式
```

没有独立数据、基准或足够计算条件时，必须报告缺口并把结论限制为“检验设计已完成，尚未执行”，不能把设计方案写成检验通过。

## 常见错误

- 有一项低误差就宣称模型全面可靠。
- 把训练残差当成独立预测误差。
- 把局部参数扰动与稳健性检验或因果证明混为一谈。
- 随意随机打乱时间、群组或重复测量数据。
- 未说明变化范围和判据，只写“模型稳定”。
