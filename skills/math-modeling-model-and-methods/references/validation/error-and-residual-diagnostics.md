# 误差与残差诊断

## 适用范围

当存在观测值 `y`、预测值或拟合值 `yhat` 时，使用本文件选择误差指标、定位异常样本并检查残差模式。训练样本内的残差与独立数据上的预测误差必须分开报告：

```text
训练数据：残差与拟合诊断
验证/测试数据：预测误差与泛化表现
```

没有观测值时，不虚构 MAE、RMSE 或 R²；纯优化、机理仿真和评价模型应优先使用各自的可行性、物理或排名证据。

## 基本量与指标选择

令：

\[
e_i=y_i-\hat y_i,\qquad AE_i=|e_i|.
\]

`e_i>0` 表示低估，`e_i<0` 表示高估。逐点绝对误差用于定位问题样本，汇总指标用于比较模型。

| 指标 | 公式 | 适合回答的问题 | 主要限制 |
|---|---|---|---|
| MAE | \(\frac1n\sum_i|e_i|\) | 典型偏差有多大 | 对大偏差的惩罚较弱 |
| MSE | \(\frac1n\sum_i e_i^2\) | 是否更重视大偏差 | 单位平方，不便直接解释 |
| RMSE | \(\sqrt{\frac1n\sum_i e_i^2}\) | 大偏差的典型规模 | 对异常值敏感 |
| MAPE | \(\frac{100\%}{n}\sum_i\frac{|e_i|}{|y_i|}\) | 比率尺度目标的相对误差 | `y_i` 为零或接近零时失稳 |
| sMAPE | \(\frac{100\%}{n}\sum_i\frac{2|e_i|}{|y_i|+|\hat y_i|}\) | 部分需要对称百分比口径的场景 | 双零和近零仍需明确处理，定义版本必须固定 |

MAE 与 RMSE 应在相同样本、相同权重和相同单位下联合阅读。RMSE 明显大于 MAE 时，说明少数较大偏差值得进一步检查；这只是诊断线索，不能单独证明误差具有特定分布形状。

百分比误差仅适合存在有意义零点的比率尺度目标。对摄氏温度等区间尺度变量，不应无条件使用 MAPE 或 sMAPE。

## R² 与调整 R²

对带截距的回归拟合：

\[
R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}
{\sum_i(y_i-\bar y)^2}.
\]

`R²` 描述相对均值基准的样本内平方误差改善，不是预测准确率；在测试数据上可为负。不要仅因为它无量纲就跨目标、跨数据分布或跨损失函数直接比较。

若是常规带截距的线性回归，且 `n>p+1`：

\[
R^2_{\mathrm{adj}}
=1-(1-R^2)\frac{n-1}{n-p-1},
\]

其中 `p` 为不含截距的解释变量数。它是对该类模型自由度的调整，不能证明变量具有因果解释力，也不能替代独立验证；不要把它机械套到树模型、神经网络或任意正则化模型。

## 残差图的诊断顺序

优先画：

1. 残差对拟合值；
2. 残差对关键解释变量；
3. 有自然顺序时，残差对时间、空间或实验顺序；
4. 需要经典推断时，再考虑 QQ 图和相应统计检验。

| 图形或现象 | 可能问题 | 后续候选动作 |
|---|---|---|
| 残差呈曲线或系统趋势 | 均值结构未捕捉非线性、交互或时间变化 | 重新检查特征、变换、动态项或候选模型 |
| 残差呈漏斗形 | 方差随条件变化 | 检查异方差、目标变换、加权或稳健推断是否适用 |
| 个别点残差极大 | 测量错误、异常机制或漏掉关键情景 | 回核数据，分层报告，必要时做稳健性对照 |
| 相邻残差持续同号 | 可能遗漏时间依赖或周期 | 查看 ACF/PACF、Ljung-Box 或适合的动态模型 |

图形提供的是诊断线索，不是单独证明。异常值处理、变量变换和模型改造必须在训练/验证流程中完成；查看最终测试误差后反复修改模型会污染独立评估。

## ACF、DW 与 QQ 图

有自然时间顺序时，使用 ACF 检查残差是否仍保留自相关。Durbin-Watson 可作为相邻残差相关的补充线索：

\[
DW=
\frac{\sum_{t=2}^{T}(e_t-e_{t-1})^2}
{\sum_{t=1}^{T}e_t^2}.
\]

`DW` 位于 0 到 4，接近 2 表示一阶残差相关较弱的线索；它不证明高阶相关、季节性或所有依赖均不存在。没有自然排序的横截面数据不应机械计算。

QQ 图可比较残差分位数与目标理论分布。点接近参考线只是“与该分布相容”的图形证据，不构成正态性证明。残差正态性主要影响某些经典置信区间和推断，不是所有预测模型有效性的必要条件。

## 关键场景误差

总体平均误差可能掩盖关键场景失败。按业务或题目预先定义的高峰/非高峰、地区、季节、设备、风险等级或目标量区间分层，分别报告样本量、主指标和主要失败模式。不要事后反复搜索小群体，只挑选有利结果。
