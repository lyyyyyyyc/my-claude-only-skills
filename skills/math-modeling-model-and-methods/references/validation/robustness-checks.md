# 稳健性检验

## 这份文档解决什么

稳健性检验判断核心结论是否依赖某一组特定的样本、变量定义、模型设定、数据处理或合理扰动。先定义要保持的主张，再设计变化；不能只改变一个参数就笼统宣布“模型稳健”。

灵敏度分析关注“输入变化会使输出改变多少”；稳健性检验关注“在合理替代设定下，核心结论是否仍成立”。参数扰动可以构成稳健性证据的一部分，但结论仅限于已检验的范围。

## 先定义核心结论

| 问题类型 | 可检验的核心结论示例 |
|---|---|
| 评价 | 第一名、前三名、完整排序、主等级、关联度 |
| 预测/分类 | 样本外主指标、关键子群表现、阈值下的错误代价 |
| 优化 | 推荐方案、目标值差距、可行率、关键决策结构 |
| 机理模型 | 参数方向、关键事件、守恒/非负性、情景比较结论 |
| 统计解释 | 系数方向、效应区间、主要关系在合理设定下是否保持 |

同时写清可接受变化和其依据，例如业务容忍度、物理边界、预注册规则、基准模型差距或实际决策是否改变。`p` 值、误差、排名、置信区间和效应大小不是可相互替代的同一种证据。

## 常见策略

| 改变对象 | 适用问题 | 设计要求 |
|---|---|---|
| 核心变量或指标定义 | 评价、统计解释、代理变量建模 | 替代定义仍应衡量同一研究概念 |
| 样本区间、地区、群组或数据子集 | 时间、空间、群组异质性 | 报告样本量；区分固定模型评估和重新拟合 |
| 模型形式、损失函数或关键假设 | 回归、预测、机理和评价路线对照 | 目标、指标、预处理和预算保持可比 |
| 噪声、测量误差或输入情景 | 数据质量或不确定性问题 | 说明噪声位置、大小、分布和现实依据 |
| 异常值处理与数据清洗规则 | 异常机制可能影响结论 | 区分错误记录与真实极端事件；不得为改善结果删除测试样本 |
| 重抽样 | 独立样本、模型参数或排序稳定性 | 说明重抽样单位、重复次数和是否完整重新拟合 |
| 评价权重、标准化、对象增删、GRA/FCE 参数 | 评价模型 | 读取 `../01-evaluation/evaluation-robustness.md` |
| 控制变量、固定效应、安慰剂、分位数回归 | 统计解释或因果设计 | 只在相应研究设计成立时使用，不作为通用必做项 |

## Bootstrap 与数据依赖

Bootstrap 可用于估计参数、性能或排名的重抽样波动。至少说明抽样单位、重复次数、是否在每次重抽样中重新执行预处理和建模、失败次数及区间构造方式。

逐行独立有放回抽样只适合相应的独立样本假设。时间、空间、群组和重复测量数据需要相容的块、群组或其他设计；Bootstrap 不能自动替代外部验证，也不能通过重复训练误差证明新环境泛化。

## 统计解释相关的条件性方法

控制变量、固定效应、安慰剂检验和分位数回归只在统计解释、面板数据或因果设计等相应问题中按需使用：

- 控制变量和固定效应要说明对应的混杂或不可观测差异，不能自动消除全部偏差；
- 安慰剂检验要构造理论上不应出现目标效应的时间、对象或结果，不能等同于多随机种子实验；
- 分位数回归描述条件分位数关系，不是先按因变量切一段样本再做普通回归。

这些方法通过后也不单独构成因果证明。

## 结果解释

每项对照实验保持评价口径可比：写清哪些条件改变、哪些保持不变、是否重新拟合、是否使用相同数据划分与相近计算预算。若不同设定的结论不一致，应报告最敏感来源并限定适用范围，而不是只展示支持主结论的一组结果。

方法对照不是交叉验证：前者检查结论对方法假设的依赖，后者估计训练流程在数据划分变化下的表现。
