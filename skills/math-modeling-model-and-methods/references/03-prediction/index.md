# 预测类方法索引

## 这类问题主要解决什么

预测类问题根据历史观测、解释变量或状态转移信息，预测未来数值、趋势、区间、概率或离散状态。先区分预测任务与优化决策：预测是估计未来，优化是在预测结果或约束下选择方案。

## 进入本索引后先判断

- 是否存在可靠时间顺序和规则时间频率？
- 目标是连续数值、区间/分布，还是离散状态？
- 是横截面回归、单变量时序还是多变量时序？
- 预测步长 `h`、样本长度 `T`、趋势、季节性、自相关和结构突变是什么？
- 未来外生变量是否可得？是否需要训练集内滚动验证？

## 方法族

### 横截面/监督回归

- 线性回归、Ridge、Lasso：关系近似线性，需要系数解释或正则化。
- 多项式/非线性回归：函数形式有机理或趋势依据，能解释参数含义。
- KNN、SVM、决策树、随机森林、GBDT、XGBoost：特征交互或非线性明显，且能够使用时间顺序验证。

### 单变量连续时间序列

- Naive / Seasonal Naive：必须作为基准候选。
- ETS、Holt、Holt-Winters：水平、趋势和季节性状态递推。
- ARIMA / SARIMA：线性自相关、差分和季节结构。
- GM(1,1)：小样本、正值、弱信息和近似单调趋势。

### 多变量时间序列

- VAR / VECM：多个变量之间的线性动态关系或协整关系。
- ARIMAX / 动态回归：目标序列结合外生变量。
- 树模型或 LSTM：滞后特征交互复杂、非线性明显且样本足够。

### 离散状态预测

- Markov：状态可离散划分，下一状态主要依赖当前状态。
- 灰色-Markov：用状态转移修正灰色模型的趋势预测。

## 共同验证要求

- 固定模型、没有调参时，训练集+测试集可以使用。
- 需要模型比较、调参或早停时，使用训练集内滚动验证和独立测试集，或按时间顺序设置训练/验证/测试。
- 不随机打乱时间序列；所有预处理、参数搜索和特征选择只使用对应训练折。
- 测试集只在模型和参数锁定后使用一次。
- 复杂模型必须与 Naive 或 Seasonal Naive 比较。

## 常见混淆点

- 出现“未来”不一定就是预测类；最终目标可能是优化决策。
- 时间序列方法和回归方法可以结合，但验证方式不能混用。
- 非线性回归中的参数迭代是拟合过程，不等于资源优化问题。
- `T<20`、`T>200`、`n=4~20` 等样本量阈值是经验起点，不是数学边界。
- 高训练拟合度、低 AIC/BIC 或单次测试误差不能单独证明泛化能力。
