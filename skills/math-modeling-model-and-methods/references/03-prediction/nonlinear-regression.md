# 非线性回归 / 非线性拟合

## 适用题型
- 适合回归预测类问题，尤其适合“变量之间关系明显不是直线，而更像指数、对数、幂函数、Logistic、生长曲线、衰减曲线”等情形。
- 常用于参数拟合、趋势预测、机理参数估计后的数值预测。

## 什么时候优先考虑
- 已经能提出一个大致合理的非线性函数结构。
- 题目既要求拟合已有数据，又希望据此做预测。
- 线性回归残差较大、趋势明显弯曲，线性模型解释力不足。

## 什么时候不优先
- 连模型形式都完全不清楚，只是盲目想“上非线性模型”。
- 样本很少、参数很多，导致模型难以稳定识别。
- 初始值极难设置，或约束范围完全没有业务意义支撑。

## 模型选择准则
- `AIC`（赤池信息准则）：越小越好。
- `BIC`（贝叶斯信息准则）：越小越好。
- 调整 `R²`：用于考虑参数个数的影响，避免只因为参数多就看起来拟合更好。
- 若你的目标是“纯预测效果”，应在训练数据内部使用时间顺序验证或交叉验证比较预测误差；不能用全体数据的拟合 `MSE` 代替泛化误差，也不能用测试集反复挑选模型。

## 如何选择模型
1. 先提出若干候选非线性模型：
   - 例如指数型、幂函数型、Logistic 型、分段型或题目机理支持的其他函数。
2. 再对每个候选模型分别拟合。
3. 记录每个模型的训练内诊断与验证结果：
   - `AIC`
   - `BIC`
   - 调整 `R²`
   - 训练拟合 `MSE`
   - 训练内验证 MAE/RMSE（有时间顺序时为滚动验证误差）
4. 根据任务目标选择：
   - 若更关注模型解释与参数简洁，优先参考 `AIC / BIC / 调整R²`。
   - 若更关注预测误差，优先比较训练内验证误差；有时间顺序时使用滚动或扩展窗口验证。
5. 不要只看一个指标：
   - 拟合 `MSE` 小不代表模型一定最好，还要看验证误差、参数是否合理、是否过拟合、是否符合题目机理。

## 为什么这样选
- `AIC / BIC` 的价值在于：它们会惩罚模型复杂度，避免“参数越多越好”的错觉。
- 调整 `R²` 的价值在于：它不是单纯追求拟合度，而是把参数个数也考虑进去。
- “每个模型都试一遍，再比较验证误差”的价值在于：它更接近实际预测任务；拟合 `MSE` 只能作为训练内诊断，不能单独用于模型筛选。
- 论文里写理由时，不能只写“因为它拟合最好”，而要写：
  - 为什么拿这些准则比较；
  - 为什么这些准则适合本题；
  - 为什么最终选中的模型在“验证误差、复杂度、解释性”之间更平衡。

如果数据具有时间顺序，候选模型的拟合、初始值选择、参数约束和模型比较都必须遵守时间边界。应先在早期数据上拟合，在训练段内部用滚动验证比较，再在模型锁定后使用最后测试段。若只是对一组已经确定的参数做固定模型评估，可以使用训练集+测试集，不必为了形式强行增加验证集。

## 设置参数与初始值
- 初始值计算：
  1. 选择合适的初始值设置方法。
  2. 计算各参数的初始估计值。
  3. 检查初始值的合理性。
- 初始值必须有依据：
  - 可来自数据图像的拐点、上下界、增长率、平台值等。
  - 也可来自题目给出的业务范围、物理背景或经验参数。
- 如果初始值乱设，非线性回归很容易不收敛或收敛到坏的局部解。

## 约束设定
- 约束应根据实际意义设置参数范围。
- 必须确保初始值落在约束范围内。
- 不要设置过于严格的约束，否则会把合理解空间直接卡死。
- 约束理由也要能写进论文：
  - 例如某参数理论上必须为正；
  - 某增长率不可能超过某范围；
  - 某平台值不能超过实际可观测上限。

## 迭代优化
- 运行非线性回归算法后，应监控收敛过程。
- 若收敛不稳定或结果异常，应考虑：
  - 调整初始值；
  - 调整约束；
  - 更换模型形式。
- 论文里可以写成：
  - “为避免非线性优化受初值影响过大，本文先依据数据趋势给出参数初值，再设置符合实际意义的参数约束，并在迭代过程中检查收敛情况。”

## 输出时必须说明
- 你比较了哪些候选模型。
- 训练/验证/测试划分、基准模型和验证方式。
- 每个候选模型的训练内验证误差，以及锁定模型后的独立测试误差。
- 为什么选这些候选模型。
- 每个模型的 `AIC / BIC / 调整R²`、训练拟合 `MSE` 和验证误差是多少。
- 最终选中哪个模型，依据是什么。
- 初始值如何得到。
- 约束如何设置。
- 是否存在收敛问题，如何处理。

## 常见易错点
- 只试一个模型就下结论。
- 只看 `R²`，不看模型复杂度。
- 只看 `MSE`，不看参数是否合理。
- 初始值和约束全靠拍脑袋，论文里写不出理由。
- 明明是回归预测问题，却把“参数拟合优化”误写成“资源优化模型”。

## 与邻近方法的区别
- 相比普通线性回归：非线性回归允许更复杂的函数形态，但也更依赖初值和约束。
- 相比时间序列：非线性回归更强调“函数关系拟合”，时间序列更强调“时间依赖结构”。
- 相比优化类非线性规划：这里的迭代优化是为拟合参数服务，不是求资源配置最优方案。
