# 岭回归

## 适用题型
- 适合回归预测类中的线性数据问题。
- 适合普通线性回归拟合不太好的线性数据。

## 什么时候优先考虑
- 基本关系仍然是线性的。
- 希望在 n 元一次方程基础上加入正则化约束。
- 需要把相对不重要的特征权重压小，但不一定直接删掉特征。

## 什么时候不优先
- 问题本身不是线性关系。
- 希望通过模型直接完成明显的特征筛选。

## 基本思想 / 关键机制
- 岭回归是带 L2 正则化的 n 元一次方程。
- L2 正则化是一种弱约束。
- 相对不重要的特征权重会逼近 0。

## 输出时必须说明
- 为什么普通线性回归拟合得不够好。
- 为什么这里采用 L2 正则化。
- 哪些特征权重被明显压小。
- 最终回归方程如何解释。

## 常见易错点
- 把岭回归当成能直接删除特征的方法。
- 明明关系不是线性结构，却只靠 L2 去硬调。
- 只写“用了正则化”，不说明它压缩了什么。

## 与邻近方法的区别
- 相比线性回归：岭回归加入了 L2 正则化。
- 相比 Lasso 回归：岭回归更倾向于让权重逼近 0，而不是直接等于 0。
