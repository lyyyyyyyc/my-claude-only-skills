# 回归分析方法索引

## 这类问题主要解决什么
- 这类方法主要处理“利用方程形式直接描述特征与连续目标之间关系”的预测问题。
- 输出通常是回归方程、各特征对应的权重，或在给定输入下的预测值。

## 典型输入 / 输出特征
- 输入：
  - 连续型目标变量
  - 一个或多个解释变量
  - 线性或低阶非线性关系假设
- 输出：
  - 拟合方程
  - 系数或权重
  - 预测值

## 候选方法清单
- 线性回归（详见 `linear-regression.md`）
- 多项式回归（详见 `polynomial-regression.md`）
- 岭回归（详见 `ridge-regression.md`）
- Lasso 回归（详见 `lasso-regression.md`）

## 各方法适用场景 / 不适用边界
- 线性回归：适合标准线性回归问题，数学解释性很强；不适合明显复杂非线性的关系。
- 多项式回归：适合低次多项式可较好刻画趋势的问题；不适合把次数不断提高来强行追求拟合。
- 岭回归：适合普通线性回归拟合不太好的线性数据；不适合希望直接把无关特征压到 0 的场景。
- Lasso 回归：适合高维线性数据，并兼顾特征筛选；不适合仅靠简单线性结构无法表达的关系。

## 常见混淆点与误判风险
- 岭回归和 Lasso 回归都属于正则化线性回归，但一个让权重逼近 0，一个会把权重压到 0。
- 多项式回归不是“次数越高越好”，高次同样会导致过拟合。
- 这组方法都保留较强方程视角，和 KNN、SVM、树模型的建模逻辑不同。

## 与邻近方法的区别
- 相比非线性回归：这里仍以线性方程或低次多项式展开为主，结构更直接。
- 相比树模型：这里输出的是显式方程，树模型输出的是分裂规则或集成结果。
