# Lasso 回归

## 适用题型
- 适合回归预测类中的高维线性数据问题。
- 适合既要做线性回归，又希望顺带做特征筛选的场景。

## 什么时候优先考虑
- 数据维度较高。
- 基本关系仍然可按线性结构表达。
- 希望把相对不重要的特征直接压到 0。

## 什么时候不优先
- 数据维度不高，且没有明显特征筛选需求。
- 关系本身明显不是线性的。

## 基本思想 / 关键机制
- Lasso 回归是带 L1 正则化的 n 元一次方程。
- L1 正则化是一种强约束。
- 相对不重要的特征权重会等于 0。
- 这也相当于一个特征选择的过程。

## 输出时必须说明
- 为什么当前问题属于高维线性数据场景。
- 为什么需要 L1 正则化。
- 哪些特征权重被压到 0。
- 最终留下的特征如何解释。

## 常见易错点
- 把 Lasso 回归当成处理所有非线性问题的方法。
- 只写“做了特征选择”，却不说明哪些特征被舍弃。
- 不区分 L1 和 L2 的作用差异。

## 与邻近方法的区别
- 相比线性回归：Lasso 回归加入了 L1 正则化。
- 相比岭回归：Lasso 回归会把部分权重直接压到 0，更强调特征筛选。
