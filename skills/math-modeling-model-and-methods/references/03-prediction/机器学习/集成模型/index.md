# 决策树集成模型索引

## 这类问题主要解决什么
- 这类方法主要处理“把多个弱学习器组合起来，以提高预测效果”的问题。
- 输出通常是更稳定或更高精度的回归预测结果。

## 典型输入 / 输出特征
- 输入：
  - 样本特征
  - 连续型目标变量
  - 一组基学习器或回归树
- 输出：
  - 集成预测值
  - 多模型组合后的回归结果

## 各方法适用场景 / 不适用边界
- Bagging：适合希望通过平均多个弱学习器来降低方差的场景；不适合需要顺序纠错机制的问题。
- 随机森林：适合高维数据和准确率要求较高的场景；不适合特别依赖单模型解释性的任务。
- Boosting：适合希望让后续模型逐步纠正前序误差的场景；不适合把它和并联式集成混为一谈。
- GBDT：适合大多数回归问题；不适合直接当作多分类方法来使用。
- XGBoost：适合希望在 GBDT 基础上进一步增强正则化、缺失值处理和计算效率的场景；不适合参数预算和内存预算都非常紧的情况。

## 常见混淆点与误判风险
- Bagging 和 Boosting 都是集成方法，但前者偏并联平均，后者偏串联纠错。
- 随机森林属于 Bagging 系列，不等于所有树集成模型。
- GBDT 和 XGBoost 都建立在 Boosting 思路上，但不是同一个算法。

## 与邻近方法的区别
- 相比单棵决策树：集成模型的结构更复杂，但通常更强调预测效果。
- 相比线性回归和 KNN：集成模型不依赖单一方程或局部平均，而是依赖多个学习器组合。
