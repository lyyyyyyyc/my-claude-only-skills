# 机器学习预测方法索引

## 这类问题主要解决什么
- 这类方法主要处理“利用可在预测时获得的样本特征去预测连续数值结果”的问题。
- 输出通常是某个未来值、某个指标的估计值，或在不同输入条件下的回归预测结果。

## 典型输入 / 输出特征
- 输入：
  - 样本特征
  - 历史观测值
  - 连续型目标变量
- 输出：
  - 回归预测值
  - 拟合关系
  - 特征对结果的影响方向或分裂规则

## 各方法适用场景 / 不适用边界
- 回归分析：适合变量关系较清楚、希望保留较强数学解释性的预测问题；不适合明显复杂非线性且仅靠简单方程难以表达的场景。
- KNN：适合低维、数据分布特征不明显、存在大量异常值的回归预测场景；不适合高维、大样本和内存开销受限的问题。
- SVM：适合高维、小样本、需要通过核函数处理非线性关系的预测场景；不适合样本量很大、缺失数据较多的问题。
- 决策树：适合解释性要求高、希望直接提取规则的预测问题；不适合特别容易过拟合、且不做剪枝控制的场景。
- 决策树集成模型：适合更强调预测准确率、可接受结构更复杂的场景；不适合只需要单模型解释性的任务。XGBoost、GBDT 和随机森林也必须按时间顺序验证，不能因为是树模型就随机打乱时序数据。

## 常见混淆点与误判风险
- 同样是“回归预测”，并不意味着都该先上机器学习；如果题目更强调时间依赖结构，可能应优先考虑时间序列。
- 树模型的自动缺失值分支或较强拟合能力不能替代缺失机制分析、特征可得性检查和防数据泄漏。
- 截图中的方法并不覆盖所有机器学习回归模型，本目录只整理当前图片中能明确辨认的算法。
- 集成模型虽然也建立在决策树上，但与单棵决策树不是同一层级方法，不能混写。

## 与邻近方法的区别
- 相比时间序列：这里更强调“特征到结果”的映射关系，时间序列更强调序列本身的时序依赖。
- 相比非线性回归：这里允许用邻域、核函数、树分裂和集成方式做预测，不局限于单一函数形式。
