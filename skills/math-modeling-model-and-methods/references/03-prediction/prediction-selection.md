# 预测方法选择

## 使用目的

本文件负责把预测题从“预测类”继续分流到可执行的方法路线。它只负责选择和交接，不替代具体方法文档中的公式、代码和完整实验。

## 第一步：确认预测对象

| 题目结构 | 优先考虑 | 关键条件 |
|---|---|---|
| 没有可靠时间顺序，特征到连续目标的映射 | MLR、Ridge、Lasso、非线性回归、树集成 | 预测时的特征必须可获得 |
| 单变量连续时间序列 | Naive、ETS、ARIMA、GM(1,1) | 看趋势、季节性、自相关和样本长度 |
| 多变量时间序列 | VAR、VECM、ARIMAX、动态回归、LSTM | 未来外生变量是否已知；样本是否支撑参数量 |
| 离散状态随时间转移 | Markov、灰色-Markov | 状态划分和转移概率有实际含义 |

## 第二步：检查时间结构

依次回答：

1. 时间索引是否唯一、递增且频率规则？
2. 预测步长 `h` 是一步、短期多步还是长期多步？
3. 是否存在趋势、季节性、周期、自相关和结构突变？
4. 数据是否有缺失时间点、间歇需求、零值或负值？
5. 是否存在未来已知的日历、政策、天气或外生变量？

## 单变量连续序列的分流

```text
先建立 Naive / Seasonal Naive 基准
        ↓
样本很少、正值、趋势近似单调
        └── GM(1,1)（经验起点，不是自动结论）

有水平、趋势或季节性，关注短中期预测
        └── ETS / Holt / Holt-Winters

线性自相关明显，差分后可以平稳
        └── ARIMA / SARIMA

有外生变量且未来值可得
        └── ARIMAX / 动态回归

复杂非线性、长依赖且样本足够
        └── LSTM 或基于滞后特征的树模型
```

## 多变量时间序列的分流

```text
多个内生变量，水平上平稳或已合理处理为平稳
        └── VAR

多个变量通常为同阶单整，且训练段内存在有意义的协整关系
        └── VECM

主要是一个目标序列，其他变量是预测时可获得的外生输入
        └── ARIMAX / 动态回归

非线性和长依赖明显、有效训练窗口足够
        └── LSTM 或滞后特征树模型
```

## 方法边界

### MLR、Ridge、Lasso

- 适合横截面或带明确滞后特征的监督回归。
- 适合需要系数方向和大小解释的场景。
- 自变量高度相关时优先比较 Ridge、Lasso 或 Elastic Net。
- 如果目标主要由自身时间依赖决定，不能把普通随机划分的回归当作时间序列验证。

### ETS、Holt、Holt-Winters

- 适合单变量、时间间隔规则、有水平/趋势/季节性的序列。
- 短期预测通常是强基准；季节性必须提供合理的周期 `m`。
- 不适合解释多个外生变量的边际影响。

### ARIMA、SARIMA、ARIMAX

- ARIMA 适合线性自相关结构；非平稳序列需要合理差分。
- SARIMA 适合具有明确季节周期的序列。
- ARIMAX 只有在预测时能取得外生变量未来值，或明确采用情景值时才可使用。
- ACF/PACF 和 AIC/BIC 只能产生候选和训练内选择，最后仍要做时间滚动验证。

### GM(1,1)

- 适合正值/非负值、小样本、弱信息、趋势近似单调的场景。
- `n=4~20`、`|a|<0.3` 等只能作为经验提示。
- 不能因为数据点少就自动优先；必须检查级比、后验误差和留出预测。

### VAR、VECM

- VAR 适合多个平稳或经处理后平稳的变量之间存在动态滞后关系。
- 非平稳但存在协整关系时考虑 VECM，而不是对所有变量机械差分。
- 随着变量数和滞后阶数增加，参数数量快速增加，应检查 `T` 是否足够。
- VAR/VECM 的协整判断、滞后阶数和确定性项必须在训练数据内部完成，再用滚动预测验证确认。

### LSTM

- 适合复杂非线性、多变量和较长时间依赖，但需要足够有效样本。
- `T>200` 或 `500+` 不是理论门槛。
- 小样本、强解释性或简单线性趋势优先考虑 ETS、ARIMA 或回归基线。

## 初始参数只是候选范围

| 方法 | 参数 | 经验起点 |
|---|---|---|
| VAR | lags、trend、内生变量集合 | lags=1~2 可作小样本起点，再由信息准则和滚动验证筛选 |
| VECM | k_ar_diff、coint_rank、deterministic | k_ar_diff 从 0～2 起步；协整秩由训练段检验与领域意义共同确定 |
| ETS | `alpha`、`beta`、`gamma` | 在 `(0,1)` 内由时间验证估计或搜索 |
| ARIMA | `p,d,q` | `p,q=0~3`、`d=0~2` 作为小范围起点，再看诊断 |
| SARIMA | `P,D,Q,m` | `D=0~1`、`P,Q=0~2`，`m` 来自数据频率/季节证据 |
| GM(1,1) | 背景值系数、滚动窗口 | 默认背景值系数 `0.5`，再做敏感性检查 |
| LSTM | `lookback`、`units`、`layers`、`dropout`、`learning_rate` | 由独立调参 SKILL 搜索，不凭单次训练决定 |

`p,d,q`、`alpha` 等参数的搜索必须在训练数据内部进行。测试集只用于锁定模型后的最终报告。

## 路由输出要求

选择完成后，必须同时写出：首选方法、至少一个合理基准、选择理由、初始参数、时间验证方式、评价指标、主要失败风险和需要交给的下一个 SKILL。
