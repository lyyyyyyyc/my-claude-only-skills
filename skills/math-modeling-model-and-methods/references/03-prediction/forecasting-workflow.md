# 预测建模工作流

## 适用范围

本文件规定从题意到预测结果的通用执行顺序。预处理的具体操作交给 `math-modeling-data-preprocessing`，图形生成交给 `math-modeling-plotting`，调参实验交给 `model-hyperparameter-tuning`。

## Step 1：明确预测任务

记录目标变量、预测对象、时间频率、历史长度 `T`、预测步长 `h`、单步/多步方式、可用特征和最终报告形式。先区分“预测未来”与“根据预测结果做优化决策”；后者还需要进入优化类路由。

## Step 2：核对时间数据

- 按时间排序并检查重复时间点。
- 确认频率是日、周、月、季度或年。
- 区分“没有发生事件”和“观测缺失”，不能把所有空值都填成 0。
- 检查时间间隔是否规则；不规则序列不能直接套用要求固定频率的季节模型。
- 标记政策、疫情、设备更换等可能造成结构突变的时间点。

## Step 3：探索和基准

先请求画图 SKILL 生成时序图、季节性图、ACF/PACF 或残差图。然后建立 Naive、Seasonal Naive 或漂移基准，记录其滚动误差。

不要因为某个复杂模型在训练集上拟合得更好，就跳过基准比较。

## Step 4：确定时间验证方案

- 固定模型、无调参：训练集+测试集。
- 需要模型比较、超参数搜索或早停：训练集内滚动验证+独立测试集。
- 小样本：减少候选模型和参数规模，使用扩展窗口并报告折数不足的限制。
- 预测时没有真实未来标签：使用历史滚动回测，不把回测结果称为真实未来测试。

## Step 5：执行预处理交接

将以下信息交给数据预处理 SKILL：时间索引、缺失时间点、异常事件、缩放需求、滞后特征、滚动窗口、训练截止点和泄漏风险。

必须保证：

- scaler、填补器和异常值规则只在训练折拟合；
- 目标变换可以在预测后逆变换；
- 滞后特征只使用预测时已经可获得的信息；
- 滚动特征的窗口不读取未来值。

## Step 6：按结构选择模型

| 数据结构 | 首批候选 |
|---|---|
| 横截面特征到连续目标 | MLR、Ridge、Lasso、非线性回归、GBDT/XGBoost |
| 单变量水平/趋势/季节 | Naive、ETS、Holt-Winters |
| 单变量线性自相关 | ARIMA、SARIMA |
| 多变量线性动态关系 | VAR、VECM、ARIMAX |
| 小样本正值单调趋势 | GM(1,1) |
| 长序列复杂非线性 | LSTM 或滞后特征树模型 |
| 离散状态转移 | Markov、灰色-Markov |

## Step 7：拟合和调参

先训练基准，再训练一个可解释的简单模型，最后才尝试复杂模型。调参 SKILL 负责搜索：

- ETS 的 `alpha/beta/gamma`、趋势和季节形式；
- ARIMA 的 `p/d/q`、季节参数和趋势项；
- LSTM 的 `lookback/units/layers/dropout/learning_rate`；
- 树模型的深度、学习率、树数量和采样比例。

如果 PSO、GA 等优化算法用于调参，适应度必须是训练集内部的滚动验证误差，不能使用最终测试集。

## Step 8：验证和诊断

根据 `prediction-validation.md` 进行滚动预测，报告 MAE、RMSE、MASE 或任务需要的指标；同时检查残差、自相关、结构突变、区间覆盖率和不同预测步长的表现。

## Step 9：锁定和最终预测

根据训练内验证结果锁定模型和参数。若实验设计允许，可用训练集和验证集重新拟合；测试集只能最后使用一次。最终输出点预测、区间预测、误差、限制和复现所需参数。

## 各模型最小执行顺序

### MLR / 正则化回归

```text
定义特征与目标
→ 按时间切分
→ 检查线性关系、VIF 和残差
→ 比较 OLS/Ridge/Lasso
→ 滚动验证
→ 解释系数并预测
```

### ETS

```text
确认频率和季节周期
→ 判断水平/趋势/季节
→ 选择 additive/multiplicative 与初始化
→ 估计 alpha/beta/gamma
→ 滚动验证
→ 检查残差和预测区间
```

### ARIMA / SARIMA / ARIMAX

```text
检查平稳性和变换
→ 确定差分候选
→ 用 ACF/PACF 产生 p/q 候选
→ 训练内 AIC/BIC 筛选
→ 残差白噪声诊断
→ 滚动预测和区间评估
```

### VAR / VECM

```text
按时间切分并确定内生变量
→ 在训练段检查平稳性和变量阶数
→ 训练段内选择 VAR lags 或 VECM k_ar_diff
→ 训练段内检验协整秩和确定性项
→ 拟合 VAR、差分 VAR 或 VECM
→ 残差白噪声与系统稳定性诊断
→ 滚动预测并和 Naive/单变量基准比较
→ 锁定后在测试段报告点预测和区间
```

### GM(1,1)

```text
检查正值、级比和趋势
→ AGO
→ 生成背景值
→ 最小二乘估计 a/b
→ 时间响应式
→ IAGO 还原
→ 后验误差和留出验证
```

### LSTM

```text
按目标时间切分
→ 训练段拟合 scaler
→ 构造 lookback 窗口
→ 训练/验证/测试
→ 早停和梯度裁剪
→ 按部署方式递归或直接多步预测
→ 逆变换、多个随机种子和滚动验证
```
