# Markov 马尔可夫预测

## 适用题型
- 适合预测类中的状态预测问题，尤其适合“系统状态可离散划分、未来状态主要依赖当前状态、转移概率相对稳定”的场景。
- 常用于状态转移预测、概率分布预测、多步未来状态分析、长期稳态行为分析，以及状态分类和可达性分析。

## 什么时候优先考虑
- 系统具有明确、可区分的离散状态。
- 下一时刻状态主要由当前状态决定，符合“无记忆性”近似。
- 能从历史数据中统计出状态转移矩阵。
- 更关心未来各状态的概率分布，而不只是一个连续数值点。

## 什么时候不优先
- 状态边界不清楚，难以把对象划成有限个互斥状态。
- 未来状态明显依赖很长历史，而不是主要依赖当前状态。
- 转移概率变化很大，难以认为稳定。
- 问题本质是连续数值预测，此时 ARIMA、回归等通常更合适。

## 适用于解决什么问题
1. 状态预测问题
2. 概率分布预测
3. 多步未来状态概率问题
4. 长期稳态行为分析
5. 状态分类与可达性分析

## 基本思想
1. 状态定义：
   - 将研究对象所有可能出现的、互斥且完备的情形划分为有限个离散状态。
2. 转移矩阵估计：
   - 量化系统从一个状态转移到另一个状态，或保持不变的可能性。
3. 初始状态分布：
   - 给出预测起点时刻，系统处于各状态的概率。
4. 根据状态转移概率矩阵进行预测：
   - 利用初始状态分布和转移概率矩阵，计算未来任意时点系统处于各状态的概率分布。

## 建模流程
1. 确定问题
   - 系统是否有明确的、可区分的状态。
   - 未来状态是否主要依赖于当前状态。
   - 转移概率是否相对稳定。
2. 状态定义
   - 状态必须互斥且完备，即每个观测必须属于且只属于一个状态。
   - 状态数量要适中：太少会损失精度，太多会增加复杂性。
   - 状态必须有实际意义，不能只是为了建模方便而生硬划分。
3. 确定转移概率矩阵
   - 收集历史数据，统计系统在状态间转移的次数。
   - 计算从状态 `S_i` 转移到状态 `S_j` 的概率 `P_ij`。
4. 初始化状态分布
   - 给出 `t=0` 时系统处于各状态的概率分布。
5. 模型预测和验证
   - 检查转移矩阵的数学性质。
   - 与历史数据进行对比。
   - 进行交叉验证。
   - 检验马尔可夫性假设是否成立。

## 输出时必须说明
- 状态是如何定义的。
- 为什么这些状态互斥且完备。
- 转移概率矩阵如何估计。
- 初始状态分布如何给出。
- 是否做了马尔可夫性假设检验。
- 最终输出的是最可能状态，还是完整状态概率分布。

## 常见易错点
- 状态划分过粗或过细，导致模型解释力差。
- 状态不是互斥完备的，导致一个样本可落入多个状态。
- 只给转移矩阵，不解释它怎么来的。
- 把 Markov 硬用于连续数值预测问题。
- 不验证马尔可夫性假设，直接套模型。

## 与邻近方法的区别
- 相比 ARIMA：Markov 更强调离散状态转移，ARIMA 更强调连续值序列的自相关结构。
- 相比 GM(1,1)：Markov 更适合状态概率预测，GM(1,1) 更适合连续趋势预测。
- 相比分类识别类：Markov 不仅判断当前属于哪类，还分析状态之间如何演化。

## 可与哪些方法组合
- 可与 GM(1,1) 组合成灰色-Markov，用于趋势修正。
- 可与聚类、分箱等方法组合，先做状态划分，再做状态转移预测。
