# ARIMA、SARIMA 与 ARIMAX

## 核心想法

ARIMA 用自身滞后值和滞后误差描述线性时间依赖，并通过差分处理非平稳性。它适合单变量、线性自相关明显的短中期预测，是 ETS 和复杂模型之外的重要可解释基准。

## 模型形式

使用滞后算子 `B` 时，ARIMA 可写为：

\[
\phi(B)(1-B)^d y_t=c+\theta(B)\varepsilon_t
\]

其中 `p` 是 AR 阶数，`d` 是差分次数，`q` 是 MA 阶数。

有季节周期 `m` 时考虑 SARIMA：

\[
\Phi_P(B^m)\phi_p(B)(1-B)^d(1-B^m)^D y_t
=c+\Theta_Q(B^m)\theta_q(B)\varepsilon_t
\]

有未来可得的外生变量时，可以使用 ARIMAX 或动态回归；如果未来外生变量未知，必须先预测它们或明确采用情景值。

## 适用范围

- 时间索引明确、频率规则；
- 单变量或少量外生变量；
- 线性依赖和自相关较明显；
- 原序列平稳，或经过合理差分后平稳；
- 需要可解释的点预测和预测区间。

## 不宜直接使用

- 强非线性、频繁结构突变或规律不断变化；
- 变量多而样本少，导致 VAR/ARIMAX 参数量过大；
- 未来外生变量不可获得却直接使用其真实值；
- 过度差分造成信息损失；
- 缺失值、异常事件和时间间隔未处理就直接拟合。

## 平稳性判断

ADF 的原假设通常是“存在单位根”。因此：

- `p<0.05`：在给定检验设定下，有证据拒绝单位根原假设；
- `p>0.05`：不能拒绝单位根原假设，不能据此证明序列平稳；
- 可以结合 KPSS、时序图和滚动统计判断，不能只依赖一次 p 值。

差分的目标是得到足够平稳且不被过度差分破坏的序列，不是机械地差分到某个检验“通过”。平稳只意味着候选 `d` 可能为 0，不等于直接使用 ARIMA(0,0,0)。

## `p,d,q` 的选择

1. 用时序图、滚动均值/方差和 ADF/KPSS 产生 `d` 的候选。
2. 对差分后序列绘制 ACF/PACF，产生 `p,q` 的候选。
3. 在训练集内部枚举小范围候选，例如 `p,q=0~3`、`d=0~2`；范围应随 `T` 调整。
4. 用 AIC/BIC 进行训练内筛选：

\[
AIC=-2\log L+2k
\]

\[
BIC=-2\log L+k\log n
\]

5. 检查残差是否仍有自相关、异常和异方差。
6. 用滚动预测误差验证最终候选，再锁定模型。

ACF/PACF 的截尾和拖尾只是启发式判断；小样本、季节性和模型混合时不能只凭一张图拍板。

## 建模步骤

```text
核对频率和缺失时间点
→ 训练/验证/测试按时间切分
→ 时序图与平稳性诊断
→ 变换/差分并记录 d
→ ACF/PACF 产生 p/q 候选
→ 训练内 AIC/BIC 筛选
→ 残差 ACF 与 Ljung-Box 诊断
→ 滚动预测验证
→ 输出点预测和预测区间
```

## 残差与区间

Ljung-Box 的原假设通常是“指定滞后范围内没有自相关”。`p>0.05` 只能表示没有足够证据拒绝该原假设，不能证明残差绝对是白噪声。

最终结果应报告预测值、预测步长、置信水平、预测区间以及区间随步长变化的原因。残差正态性主要影响经典区间和统计推断，不是点预测有效性的必要条件。

## 常见错误

- 不检查时间频率和缺失时间点就拟合；
- 把 ADF 的 `p>0.05` 写成“接受平稳”或把一次检验当成绝对结论；
- 机械过度差分；
- 只凭 ACF/PACF 或只凭 AIC/BIC 选模型；
- 使用未来真实外生变量；
- 直接在测试集上搜索 `p,d,q`；
- 不检查残差就直接报告预测；
- 把单次测试误差当成所有未来时期的保证。

## 与邻近方法的区别

- 相比 GM(1,1)：ARIMA 更依赖自相关和平稳性，GM(1,1) 更依赖小样本趋势和 AGO。
- 相比 ETS：ARIMA 重点刻画随机扰动的滞后结构，ETS 重点刻画水平、趋势和季节状态。
- 相比回归：ARIMA 主要使用序列自身历史，回归主要使用解释变量。
- 相比 LSTM：ARIMA 结构更简单、可解释性更强，但非线性和长依赖表达能力有限。

## 输出要求

说明时间频率、训练/验证/测试区间、平稳性证据、差分次数、ACF/PACF 初步判断、候选模型、AIC/BIC、残差诊断、滚动误差、最终参数和预测区间。
