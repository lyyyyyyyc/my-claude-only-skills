# 指数平滑与 ETS

## 方法定位

ETS（Exponential Smoothing）用递推状态表示水平、趋势和季节性。它主要是单变量时间序列方法，适合短中期预测和作为复杂模型的强基准。

## 一次指数平滑

适合没有明显趋势和季节性的序列：

\[
S_t=\alpha y_t+(1-\alpha)S_{t-1},
\qquad S_1=y_1
\]

\[
\hat y_{T+h}=S_T
\]

`alpha` 越大，模型越重视近期观测；`alpha` 越小，平滑越强但反应更慢。

## Holt 双指数平滑

适合有趋势但没有明显季节性的序列：

\[
\ell_t=\alpha y_t+(1-\alpha)(\ell_{t-1}+b_{t-1})
\]

\[
b_t=\beta(\ell_t-\ell_{t-1})+(1-\beta)b_{t-1}
\]

\[
\hat y_{T+h}=\ell_T+h b_T
\]

也可以使用阻尼趋势，使长期预测中的趋势逐渐减弱：

\[
\hat y_{T+h}=\ell_T+(\phi+\phi^2+\cdots+\phi^h)b_T
\]

其中 `phi` 通常位于 0 和 1 之间，具体边界由实现和验证结果决定。

## Holt-Winters

有季节性时增加季节状态 `s_t`，并明确：

- 季节周期 `m`，例如月度数据的年度周期通常为 12；
- 加法季节性：季节波动的绝对幅度大致稳定；
- 乘法季节性：季节波动随水平变化；
- 初始水平、趋势和季节因子。

加法形式的典型递推为：

\[
\ell_t=\alpha(y_t-s_{t-m})+(1-\alpha)(\ell_{t-1}+b_{t-1})
\]

\[
b_t=\beta(\ell_t-\ell_{t-1})+(1-\beta)b_{t-1}
\]

\[
s_t=\gamma(y_t-\ell_t)+(1-\gamma)s_{t-m}
\]

乘法形式不能与加法形式混写；如果序列含有 0 或负值，乘法季节模型和对数/Box-Cox 变换需要特别检查。

## 关键参数

| 参数 | 作用 | 选择方式 |
|---|---|---|
| `alpha` | 水平更新速度 | 训练内滚动验证或状态空间估计 |
| `beta` | 趋势更新速度 | 同上；没有趋势时不使用 |
| `gamma` | 季节更新速度 | 有可靠周期时使用 |
| `m` | 季节周期 | 来自时间频率和数据证据，不盲目搜索 |
| `trend` | 趋势形式 | additive、multiplicative 或无趋势 |
| `seasonal` | 季节形式 | additive、multiplicative 或无季节 |
| `damped_trend` | 是否阻尼趋势 | 通过滚动预测比较 |
| initialization | 初始状态 | estimated、heuristic 或明确给定 |

## 建模步骤

1. 检查时间频率、缺失时间点和 0/负值。
2. 用时序图和季节图判断水平、趋势和季节性。
3. 先建立一次指数平滑和 Naive 基准。
4. 选择 Holt 或 Holt-Winters 的结构。
5. 在训练数据内部估计或搜索平滑参数和初始化。
6. 使用滚动原点验证比较不同结构。
7. 检查残差、预测区间和不同步长误差。
8. 锁定模型后再进行最终测试或未来预测。

## 适用范围

- 单变量、规则频率的连续序列；
- 水平、趋势和季节性可以用状态递推描述；
- 需要快速、可解释的短中期预测；
- 作为 ARIMA、树模型或 LSTM 的基准。

## 不适用或需谨慎

- 未来主要由外生变量决定，却没有把它们纳入模型；
- 政策、设备或制度导致结构突变；
- 季节周期不稳定或时间间隔不规则；
- 长期外推依赖不现实的线性或指数趋势；
- 只用训练误差选择 `alpha`、`beta`、`gamma`。

## 常见错误

- 把一次指数平滑的水平状态和 Holt 的水平/趋势状态混用；
- 固定 `alpha=0.3` 后不做验证；
- 未确认季节周期就使用 Holt-Winters；
- 对乘法季节性忽略 0 和负值；
- 把状态平滑曲线当作预测区间；
- 只比较拟合误差，不比较滚动预测误差。

## 输出要求

说明模型结构、季节周期、初始化方式、平滑参数、训练/验证/测试时间段、基准模型、滚动误差、残差诊断和预测区间生成方式。
