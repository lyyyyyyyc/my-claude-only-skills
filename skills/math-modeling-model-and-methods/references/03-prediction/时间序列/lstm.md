# LSTM 时间序列预测

## 方法定位

LSTM 通过细胞状态和门控机制学习序列依赖，适合复杂非线性、多变量和较长依赖，但计算、调参和验证成本较高。`T>200`、`500+` 等只能作为经验起点，不是理论门槛。

## 适用范围

- 序列较长且早期信息可能影响未来；
- 存在非线性、变量交互或复杂滞后结构；
- 有足够的有效训练窗口和计算预算；
- 可以接受黑箱模型并愿意做基准比较、敏感性分析和多随机种子实验。

## 不宜优先使用

- 只有几个数据点；
- 简单线性趋势或单变量自相关已经能被 ETS/ARIMA 解释；
- 需要强可解释系数或可靠的经典区间；
- 训练窗口高度重叠，实际独立信息很少；
- 没有独立验证段却准备使用早停和大量超参数。

## 核心公式

\[
f_t=\sigma(W_f[h_{t-1},x_t]+b_f)
\]

\[
i_t=\sigma(W_i[h_{t-1},x_t]+b_i)
\]

\[
\widetilde C_t=\tanh(W_C[h_{t-1},x_t]+b_C)
\]

\[
C_t=f_t\odot C_{t-1}+i_t\odot\widetilde C_t
\]

\[
o_t=\sigma(W_o[h_{t-1},x_t]+b_o),
\qquad h_t=o_t\odot\tanh(C_t)
\]

门控机制可以缓解长序列训练中的梯度问题，但不保证完全消除梯度消失、梯度爆炸或过拟合；必要时使用梯度裁剪、正则化和早停。

## 关键超参数

| 参数 | 作用 | 注意事项 |
|---|---|---|
| `lookback` | 输入历史窗口长度 | 与主要周期和依赖长度有关，不是越长越好 |
| `units` | 每层隐藏单元数 | 越大表达能力越强，也越易过拟合 |
| `layers` | LSTM 层数 | 小样本优先单层或浅层 |
| `dropout` | 输入/隐藏表示正则化 | 过大可能欠拟合 |
| `recurrent_dropout` | 循环状态正则化 | 可能增加训练成本 |
| `batch_size` | 批量大小 | 影响稳定性和计算速度 |
| `learning_rate` | 优化步长 | 过大不稳定，过小收敛慢 |
| `epochs` | 最大训练轮数 | 与早停配合，不应固定迷信 100/200 |
| `optimizer` | 优化器 | Adam 可作起点，但需记录版本和参数 |
| `loss` | 训练损失 | MSE、MAE、Huber 或分位数损失按任务选择 |
| `patience` | 早停等待轮数 | 验证集必须按时间留出 |
| `clipnorm` | 梯度裁剪 | 防止训练不稳定 |

## 严格的数据切分

若训练目标截止时间为 `t0`，训练样本按目标时间索引划分，而不是只按窗口数量划分：

```text
训练目标：t <= t0
测试目标：t > t0
```

训练窗口可以使用目标之前的历史观测，但不能包含测试目标或测试目标之后的信息。scaler 只能在训练时间段拟合，验证和测试只做 transform。

## 单步与多步预测

- 单步预测：每个窗口只预测下一个时间点；
- 递归预测：将上一步预测结果放回窗口继续预测，误差会累积；
- 直接多步预测：为不同预测步长建立输出；
- Seq2Seq：一次输出多个未来步长。

训练、验证和最终评估必须采用相同的部署方式。单步误差很低，不代表递归 20 步仍然可靠。

## 建模步骤

1. 先与 Naive、ETS 或 ARIMA 基准比较。
2. 按目标时间索引切分训练、验证和测试。
3. 只用训练段拟合 scaler，并保存逆变换参数。
4. 根据 `lookback` 构造 `(samples, timesteps, features)` 窗口。
5. 选择浅层架构和初始超参数。
6. 训练时使用时间顺序验证、早停和梯度裁剪。
7. 按真实部署方式进行单步或多步预测。
8. 逆变换后计算 MAE、RMSE、MASE 和不同步长误差。
9. 改变随机种子和关键参数，报告均值、波动范围和稳定性。

## 主要风险

- 滑动窗口高度相关，窗口数量不等于独立样本量；
- 用全部数据拟合 scaler 或窗口后再划分会造成泄漏；
- teacher forcing 训练与递归预测评估不一致；
- 训练误差很低而测试误差很高，可能来自过拟合、尺度泄漏、窗口泄漏或分布漂移；
- LSTM 点预测不会自动产生可靠预测区间；
- 正弦波示例只能演示流程，不能证明真实数据泛化。

## 与邻近方法的区别

- 相比 ARIMA：LSTM 更擅长复杂非线性和长依赖，ARIMA 更简单、更易解释。
- 相比 VAR：LSTM 更偏非线性神经网络序列建模，VAR 更偏多变量线性动态关系。
- 相比 ETS：LSTM 更灵活，但需要更多数据、调参和稳定性验证。

## 输出要求

说明输入形状、时间切分、`lookback`、网络结构、损失、优化器、学习率、早停、随机种子、预测方式、基准模型、滚动验证和测试结果。
