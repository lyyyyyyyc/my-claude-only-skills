# 时间序列方法索引

## 这类问题主要解决什么

时间序列方法利用按时间顺序排列的历史信息预测未来数值、趋势、区间或状态。时间顺序、预测步长和未来信息可得性决定方法选择与验证方式。

## 进入本索引前先确认

- 时间索引是否唯一、递增且频率规则？
- 是单变量还是多变量？目标是连续数值还是离散状态？
- 是否有趋势、季节性、自相关、结构突变或间歇需求？
- 预测步长 `h`、样本长度 `T` 和外生变量未来可得性是什么？

## 方法分流

```text
单变量、水平/趋势/季节性
    ├── Naive / Seasonal Naive：基准
    └── ETS / Holt / Holt-Winters

单变量、线性自相关、可差分平稳
    └── ARIMA / SARIMA

单变量、小样本、正值、近似单调趋势
    └── GM(1,1)

多变量线性动态关系
    ├── VAR
    ├── VECM：存在协整时考虑
    └── ARIMAX / 动态回归：有外生变量时

复杂非线性、长依赖且样本足够
    └── LSTM 或滞后特征树模型

离散状态转移
    └── Markov / 灰色-Markov
```

## 共用验证规则

- 不随机打乱时间序列。
- 固定无调参模型可以训练集+测试集；比较模型、调参或早停必须使用训练内滚动验证和独立测试集。
- 差分、变换、缩放、填补和特征工程必须在训练折内拟合。
- 真实未来外生变量只能在预测时确实已知的情况下使用。
- 预测结果必须和 Naive 或 Seasonal Naive 基准比较。
