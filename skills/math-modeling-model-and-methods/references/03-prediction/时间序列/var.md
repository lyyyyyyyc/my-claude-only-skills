# VAR / VECM

## 解决什么问题

VAR（向量自回归）用于同时建模多个时间序列的滞后关系。每个变量都可以由自身滞后项和其他变量的滞后项解释，因此它适合研究一个动态系统，而不是只预测单一序列。

VECM（向量误差修正模型）是存在协整关系的非平稳多变量序列的表达方式。它在短期差分变化中保留长期均衡偏离的修正项。

## VAR 模型形式

令 \(y_t\in\mathbb{R}^{K}\)，VAR(\(p\)) 为：

\[
y_t=c+A_1y_{t-1}+A_2y_{t-2}+\cdots+A_py_{t-p}+D_t\delta+u_t,
\]

其中：

- \(K\)：内生变量数；
- \(p\)：滞后阶数；
- \(A_i\)：\(K\times K\) 的滞后系数矩阵；
- \(D_t\)：趋势项、季节虚拟变量或其他确定性项；
- \(u_t\)：创新项。

不含确定性项时，每个方程大约有 \(Kp\) 个滞后系数，整个系统的参数量随 \(K^2p\) 增长。变量数、滞后阶数和样本长度必须一起评估，不能只看变量数。

## VECM 模型形式

将 VAR 改写为差分形式：

\[
\Delta y_t=\Pi y_{t-1}+\sum_{i=1}^{p-1}\Gamma_i\Delta y_{t-i}+D_t\delta+u_t,
\]

其中：

\[
\Pi=\alpha\beta^{\mathsf T}.
\]

\(\beta\) 表示长期协整关系，\(\alpha\) 表示各变量对偏离长期关系的调整速度。协整秩 \(r=\operatorname{rank}(\Pi)\) 决定模型分流：

- \(r=0\)：没有长期协整关系，可考虑差分后的 VAR；
- \(0<r<K\)：使用 VECM；
- \(r=K\)：序列在水平上平稳，可考虑水平 VAR。

协整检验和确定性项设定必须只在训练段内完成。VECM 的 k_ar_diff 通常表示差分项滞后阶数，不能直接与 VAR 的 p 混为同一个参数。

## 适用范围

- 多个变量都有可靠的时间索引，且变量之间可能存在动态联动。
- VAR：变量在水平上平稳，或已经依据训练数据进行合理差分。
- VECM：变量通常为同阶单整、水平上非平稳，并且存在有解释意义的协整关系。
- 样本量能够支撑 \(K^2p\) 级别的参数；样本很短时应减少变量和滞后阶数，或选择更简单的基准。
- 需要多变量联合预测、脉冲响应或系统内动态关系描述。

## 不宜直接使用

- 只有一个变量，且不需要建模变量之间的反馈关系。
- 变量数多、样本短，却不做参数数量和稳定性检查。
- 非平稳变量没有检验就直接拟合水平 VAR。
- 变量并不同阶单整，却机械套用 VECM。
- 未来外生信息被当成已知内生变量直接输入，或把相关关系写成因果结论。
- 变量之间存在明显非线性、结构突变或时间间隔不规则，而没有相应处理。

## 可执行建模步骤

1. 按时间排序，检查重复时间点、缺失时间点、异常事件和频率一致性。
2. 明确内生变量、确定性项和预测目标；只保留预测时确实可获得的信息。
3. 按时间顺序保留独立测试段。模型比较或调参时，在训练段内做滚动验证；不要随机打乱。
4. 在每个训练折内检查水平序列和差分序列的平稳性。ADF 的 p>0.05 只能表示不能拒绝单位根原假设，不能证明序列一定不平稳；应结合图形、KPSS 或领域知识判断。
5. 对多个非平稳且疑似同阶单整的变量，在训练段内进行 Johansen 协整检验，检查迹统计量或最大特征根统计量，并结合经济/机理意义判断协整秩。
6. 用 AIC、BIC、HQIC 或 FPE 在训练段内选择候选滞后阶数。信息准则只生成候选，不能替代滚动预测验证。
7. 根据平稳性和协整结果拟合 VAR、差分 VAR 或 VECM，并固定确定性项设定。
8. 做残差诊断：残差自相关/白噪声检验、系统稳定性根、异常残差和必要的异方差检查。Ljung-Box 的 p>0.05 只是没有足够证据拒绝白噪声，不是绝对证明。
9. 用扩展窗口或滚动窗口比较 Naive、单变量模型和 VAR/VECM，在每个预测步长上分别报告误差。
10. 模型和参数锁定后，在测试段上只进行一次最终评估，并说明协整秩、滞后阶数、确定性项和变量变换。

## 关键参数和初始搜索范围

| 参数 | 含义 | 使用建议 |
|---|---|---|
| K | 内生变量数 | 先由题意和样本量确定，不为追求复杂度盲目增加 |
| p / lags | VAR 滞后阶数 | 用信息准则给候选，再用滚动验证确认；小样本先从 1～2 起步 |
| k_ar_diff | VECM 差分滞后阶数 | 若原 VAR 阶数为 p，通常对应 p-1，以所用库的定义为准 |
| r / coint_rank | 协整秩 | 由训练段检验和领域意义共同确定，不凭单一检验机械决定 |
| deterministic / trend | 常数、趋势和季节项 | 必须与数据是否有确定性趋势、协整关系的设定一致 |
| window | 扩展或滚动窗口 | 结构稳定用扩展窗口；结构变化明显可比较固定长度滚动窗口 |
| confidence_level | 预测区间置信水平 | 常见报告 80% 或 95%，并检查覆盖率和区间宽度 |

表中的数值是搜索起点，不是普遍正确的固定范围。随着 \(K\) 和 \(p\) 增加，模型复杂度会快速上升；如果验证误差没有稳定改善，应回退到更简单的模型。

## 验证和结果报告

至少报告：

- 与 Naive、Seasonal Naive、单变量 ARIMA/ETS 或其他合理基准的比较；
- 训练内滚动验证和独立测试的 MAE、RMSE，必要时按预测步长报告 MASE；
- VAR/VECM 的滞后阶数、协整秩、确定性项和变量变换；
- 残差自相关检验、稳定性检查和异常点处理；
- 预测区间的置信水平、覆盖率与平均宽度（如果输出区间）；
- 若展示脉冲响应、方差分解或 Granger 预测因果检验，明确它们描述的是模型内动态关系或预测增益，不自动等于现实因果关系。

## 与邻近方法的区别

- 相比 ARIMA：VAR 面向多个内生时间序列，ARIMA 更偏单变量；有外生变量但不需要变量间联合反馈时，可考虑 ARIMAX/动态回归。
- 相比 VECM：VAR 适用于平稳水平序列或合理处理后的平稳序列；VECM 显式保留非平稳序列的长期协整关系。
- 相比 LSTM：VAR/VECM 结构更透明、对样本量要求通常更可控，但主要表达线性动态关系；LSTM 更灵活，也更依赖数据量、调参和稳定性验证。

## 常见错误

- 看到多个变量就直接使用 VAR，不检查平稳性、协整、滞后阶数和样本量。
- 把 AIC/BIC 最小的候选直接称为预测最优，不做时间滚动验证。
- 把 VECM 的 coint_rank 和 VAR 的滞后阶数混淆。
- 用测试集选择变量、协整秩、滞后阶数或确定性项。
- 直接把真实未来外生变量或未来目标变量的滞后信息泄漏给模型。
- 依据脉冲响应或 Granger 检验结果写出未经识别设计支持的现实因果结论。

## 输出时必须说明

- 为什么选择 VAR、差分 VAR 或 VECM；
- 变量、时间频率、样本长度和预测步长；
- 平稳性与协整判断、滞后阶数和确定性项的选择依据；
- 训练/验证/测试划分与滚动验证方式；
- 参数数量、残差诊断、稳定性、预测误差和预测区间；
- 与简单基准相比是否稳定改善，以及模型的主要限制。
