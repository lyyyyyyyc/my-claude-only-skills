# 关联规则分析类方法索引

## 这类问题主要解决什么
- 关联规则分析类问题主要处理“在大量事务或共现记录中发现项目之间的共同出现规律与内在联系”的问题。
- 输出通常是频繁项集、关联规则，或支持度、置信度等规则评价结果。

## 典型输入 / 输出特征
- 输入：
  - 事务型数据
  - 购物篮数据
  - 共现记录或离散项目集合
- 输出：
  - 频繁项集
  - 关联规则
  - 项目之间的共现关系

## 候选方法清单
- Apriori（详见 `apriori.md`）
- FP-Growth（详见 `fp-growth.md`）

## 方法选择提示
- 如果希望先用一个原理直观、容易解释、数据集要求较低的方法，优先考虑 Apriori。
- 如果数据规模较大，希望减少扫描次数与候选项集组合带来的额外开销，优先考虑 FP-Growth。

## 常见混淆点与误判风险
- 关联规则分析不等于聚类；前者关注“哪些项目经常一起出现”，后者关注“样本如何分组”。
- 关联规则分析不等于相关分析；前者更依赖事务型共现结构，后者更常处理数值变量之间的统计关系。
- 如果数据本身不是事务型或项目型记录，而是连续数值观测，不能直接把关联规则分析当作默认方法。

## 与邻近类别的区别
- 相比统计分析类：关联规则分析更偏发现项目共现模式与规则，统计分析更偏描述、检验和解释数据。
- 相比分类识别类：关联规则分析不直接给类别标签，而是寻找项目之间的联结结构。
