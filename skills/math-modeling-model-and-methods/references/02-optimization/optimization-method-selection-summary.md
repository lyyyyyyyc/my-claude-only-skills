# 优化算法选择指南

## 这份文档是干什么的
- 这不是某一个具体算法的教程，而是优化类问题里 `遗传算法（GA）`、`粒子群优化（PSO）`、`模拟退火（SA）` 和 `差分进化（DE）` 的选型总结。
- 适合在你已经知道题目属于“优化类”之后，进一步判断到底该先优先考虑哪一种算法。
- 重点不是追求“绝对最优算法”，而是先根据题目变量类型、搜索空间结构、局部最优风险、求解速度要求、调参预算，把算法选择空间尽快缩小。

## 先记住一句话
- **GA 更像会“进化”的群体搜索器，适合离散、组合、排列类问题。**
- **PSO 更像会“协同移动”的群体搜索器，适合连续变量、参数寻优问题。**
- **SA 更像会“允许犯错”的单轨迹搜索器，适合局部最优很多、邻域容易设计的问题。**
- **DE 更像通过差分向量产生候选解的连续黑箱搜索器，适合有边界、不可导的实值优化。**

如果只想先做第一轮粗筛，这四句话已经够用一半。

## 四种算法的核心差别

### 遗传算法 GA
- 维护的是一个种群。
- 先编码，再通过选择、交叉、变异不断演化。
- 强项在于：离散变量、组合结构、排列结构、复杂逻辑约束下，能通过编码把问题自然表达出来。
- 风险在于：编码方式、选择算子、交叉算子、变异算子都很影响结果，设计成本较高。

### 粒子群优化 PSO
- 维护的也是一个种群，但不是“进化”，而是“粒子移动”。
- 每个粒子同时参考自己的历史最优和群体历史最优。
- 强项在于：连续变量搜索、参数寻优、实现快、收敛快、表达简单。
- 风险在于：标准 PSO 对离散结构不天然友好，且容易早熟收敛、陷入局部最优。

### 模拟退火 SA
- 只维护一条当前搜索轨迹，而不是一个群体。
- 核心机制是：更优解直接接受，较差解按概率接受。
- 强项在于：局部最优多时更容易跳出来，不依赖梯度，适用范围宽。
- 风险在于：计算成本容易偏高，参数虽然直观但不代表不敏感，终止条件也不算特别干脆。

### 差分进化 DE
- 维护连续变量种群，通过个体差分向量生成候选解。
- 强项在于：不要求梯度，适合有边界的连续黑箱或非凸目标。
- 风险在于：高维或单次目标评估昂贵时计算成本较高；对离散、排列和复杂逻辑约束不自然。

## 快速选型总表

| 维度 | GA | PSO | SA | DE |
|---|---|---|---|---|
| 搜索形态 | 群体进化 | 群体协同移动 | 单轨迹邻域搜索 | 差分向量种群搜索 |
| 更适合的变量类型 | 离散、组合、排列 | 连续、实值参数 | 离散和连续都可，只要邻域容易设计 | 连续、有边界、黑箱 |
| 对编码/表示的依赖 | 很强 | 较弱 | 中等，主要依赖邻域设计 | 较弱，要求连续向量表示 |
| 对梯度要求 | 无 | 无 | 无 | 无 |
| 对局部最优的抵抗方式 | 种群 + 变异 | 群体分布 + 速度更新 | 概率接受劣解 | 差分扰动 + 种群 |
| 收敛速度直觉 | 往往偏慢 | 往往较快 | 往往偏慢 | 中等 |
| 参数负担 | 较高 | 中等偏低 | 中等 | 中等 |
| 论文表达难度 | 中等偏高 | 较低 | 中等 | 中等 |
| 最适合做 baseline 的场景 | 组合优化 baseline | 连续优化 baseline | 局部最优风险高的 baseline | 连续黑箱 baseline |

## 按题目特征怎么选

### 1. 先看变量类型

- 如果变量主要是 **连续变量 / 实值参数**：
  - 优先考虑 `PSO`
  - 若目标不可导、噪声较大或是黑箱函数，`DE` 也应进入主候选
  - 其次考虑 `SA`
  - `GA` 通常不是第一优先，除非你有很自然的实数编码方案

- 如果变量主要是 **离散选择 / 0-1 决策 / 组合方案**：
  - 优先考虑 `GA`
  - `SA` 可作为候选，前提是你能设计自然邻域
  - `PSO` 一般不作为第一选择

- 如果变量主要是 **排列 / 路径 / 调度顺序**：
  - 优先考虑 `GA`
  - `SA` 也很常见
  - `PSO` 通常不够自然，除非你已经有专门离散化处理方案

### 2. 再看搜索空间结构

- 如果搜索空间 **复杂、离散、不连续、带很多逻辑结构**：
  - 优先 `GA`
  - `SA` 次之
  - `PSO` 往往不够顺手

- 如果搜索空间 **连续、边界明确、目标像参数调优**：
  - 优先 `PSO`
  - 若目标是黑箱、不可导或非凸，优先比较 `PSO` 与 `DE`
  - `SA` 可做对照
  - `GA` 不一定划算

- 如果你预判 **局部最优特别多**：
  - 优先把 `SA` 纳入候选
  - `GA` 也值得保留
  - `PSO` 要警惕早熟收敛

### 3. 再看你更怕什么

- **更怕局部最优卡死**：优先 `SA`
- **更怕编码设计太麻烦**：优先 `PSO`
- **更怕变量结构不自然、算法根本不好表达**：优先 `GA`
- **更怕算得太慢**：优先 `PSO`，`GA/SA` 要谨慎

## 四种算法分别适合什么问题

### 什么时候优先考虑 GA
- 题目本质是排、选、组、配、调。
- 解天然适合写成染色体。
- 你愿意投入一点精力去设计编码和算子。
- 你需要较强的全局搜索能力，又不想依赖梯度或解析结构。

### 什么时候优先考虑 PSO
- 问题本质是连续参数寻优。
- 你想尽快搭一个可运行、可解释、收敛较快的 baseline。
- 你不希望在编码、解码、合法性修复上投入太多精力。
- 题目主要难点不在离散结构，而在连续变量搜索。

### 什么时候优先考虑 SA
- 你担心局部最优太多，贪心一走就卡死。
- 你能比较自然地定义“当前解附近的新解怎么产生”。
- 你不想一上来就做复杂群体算法。
- 你愿意接受“慢一点，但更有机会跳出来”的搜索风格。

### 什么时候优先考虑 DE
- 决策变量主要是连续实值，且每个变量都有明确上下界。
- 目标函数不可导、非凸、黑箱，或由仿真程序返回目标值。
- 你希望使用差分向量产生候选解，而不是设计复杂编码或梯度。
- 需要注意单次目标评估成本、种群规模和约束修复；若变量是排列、强离散或逻辑结构，通常不要直接使用标准 DE。

## 什么时候不要只用它

### 不要只用 GA 的情况
- 时间很紧，没空设计编码和算子。
- 变量其实主要是连续实值参数。
- 目标函数评价代价很高，种群迭代会非常贵。

### 不要只用 PSO 的情况
- 变量明显是离散、组合、排列结构。
- 题目局部最优多，且你担心标准 PSO 早熟。
- 你需要很强的结构表达能力，而不是简单位置更新。

### 不要只用 SA 的情况
- 你对求解速度要求很高。
- 单次评价代价很高，长链长和慢降温会拖慢很多。
- 你不方便设计合适邻域，或者边界处理会非常麻烦。

### 不要只用 DE 的情况
- 变量主要是离散、整数、排列或路径结构，且没有可靠的离散化与修复规则。
- 目标函数单次评估极其昂贵，种群迭代预算无法承担。
- 约束逻辑复杂且可行解比例很低，不能自然地构造可行初始种群或修复算子。

## 真正做选择时，建议按这个顺序判断

1. **变量类型是什么？**
   - 连续、离散、排列，先分清。

2. **搜索空间更像哪一类？**
   - 连续参数空间、组合空间、局部盆地很多的复杂空间。

3. **题目最怕的失败模式是什么？**
   - 编码不自然？
   - 早熟收敛？
   - 局部最优？
   - 算得太慢？

4. **你有没有时间做算法设计和调参？**
   - 有时间：GA 可以更有发挥空间。
   - 时间紧：PSO 更适合先出 baseline。
   - 局部最优风险特别高：SA 值得进候选。
   - 连续黑箱、无梯度且边界明确：DE 值得与 PSO 对照。

5. **最后再决定主算法 + 对照算法**
   - 很多时候不该问“唯一最优算法是什么”，而应该问“主算法选谁，对照算法选谁”。

## 一个很实用的粗筛规则

如果只想做一轮非常快的筛选，可以直接用下面这张简表：

| 题目特征 | 第一候选 |
|---|---|
| 连续变量参数寻优 | PSO |
| 连续黑箱、不可导、有边界 | DE |
| 离散/组合/排列优化 | GA |
| 局部最优多、容易卡死 | SA |
| 想快速出可解释 baseline | PSO |
| 想表达复杂解结构 | GA |
| 不想贪心卡死，想保留跳出能力 | SA |

## 如果这些算法都像能用，该怎么定主次

可以按下面思路排优先级：

### 情况 1：连续变量 + 需要快速出结果
- 主算法优先 `PSO`
- 对照算法可放 `SA`
- 一般不优先 `GA`

### 情况 2：离散组合 + 排列结构明显
- 主算法优先 `GA`
- 对照算法可放 `SA`
- 一般不优先 `PSO`

### 情况 3：局部最优很多 + 邻域很好设计
- 主算法优先 `SA`
- 对照算法可放 `GA`
- `PSO` 是否纳入要看变量是否连续

### 情况 4：题目又复杂又怕单一算法失灵
- 不要执着“唯一最优”
- 更实际的是：选一个最贴题的主算法，再配一个机制互补的对照算法
  - 连续问题：`PSO + SA`
  - 离散组合问题：`GA + SA`

### 情况 5：连续黑箱 + 目标评估成本可接受
- 主算法优先比较 `DE` 与 `PSO`，由滚动实验或多随机种子稳定性决定主次。
- 若存在明显局部盆地且邻域容易构造，可把 `SA` 作为补充对照。

## 常见误区
- “要求最优”就直接上智能算法：不对，能线性化时应优先考虑规划类方法。
- 觉得 GA 的全局搜索强，就默认它最强：不对，编码和算子设计成本很高。
- 觉得 PSO 收敛快，就默认它最好：不对，连续变量友好不等于离散问题友好。
- 觉得 SA 能接受差解，就默认最稳：不对，它的计算成本和参数敏感性也很明显。
- 试图找“绝对最优算法”：多数数模题里更合理的是“最贴题算法”。
