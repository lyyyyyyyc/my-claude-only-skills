# 动态规划

## 核心想法
- 将多阶段决策过程划分阶段，恰当地选择状态变量、决策变量以及最优指标函数，从而把问题转化成一族同类型的子问题，然后逐个求解。

## 适用题型
- 用于解决多阶段决策问题。
- 其子模型包括线性 DP、区间 DP、状态 DP、概率 DP、博弈 DP 等。
- 在最优路径、资源分配、库存、投资、排序等大部分优化问题中都适用。

## 什么时候优先考虑
- 问题天然可以分成若干阶段。
- 每一阶段的决策会影响下一阶段状态。
- 具有明显的最优子结构和递推关系。

## 什么时候不优先
- 状态定义后规模爆炸，无法承受状态空间大小。
- 问题没有清晰阶段结构，或子问题之间难以递推。
- 更适合直接线性 / 整数建模的一次性优化问题。

## 与邻近方法的区别
- 相比线性规划：动态规划更强调阶段递推与状态转移。
- 相比多目标优化：动态规划主要解决多阶段结构问题，多目标优化主要解决目标冲突问题。
