# 差分进化（DE）

## 核心定位

- DE 是基于种群和差分向量的连续黑箱优化方法。
- 它不需要梯度，适合目标函数不可导、非凸、由仿真程序返回，或只能通过程序计算的场景。
- 若问题可以直接建成 LP、IP/MILP、CP-SAT、DP 或图算法，应先比较精确方法，不要因为“需要最优”就直接使用 DE。

## 核心公式

对第 `i` 个个体 `x_i^t`，从不同个体中抽取 `r1、r2、r3`，构造差分变异向量：

```text
v_i^(t+1) = x_r1^t + F (x_r2^t - x_r3^t)
```

以 `bin` 交叉为例，试验向量为：

```text
u_ij^(t+1) = v_ij^(t+1),  if rand_j <= CR or j = j_rand
             x_ij^t,       otherwise
```

最小化问题的选择规则为：

```text
x_i^(t+1) = u_i^(t+1),  if f(u_i^(t+1)) <= f(x_i^t)
             x_i^t,     otherwise
```

最大化问题应先统一为最小化口径，例如令 `f_min(x) = -f_max(x)`，避免选择方向写反。

## 一步步执行

1. 先检查 LP/IP/MILP/CP-SAT/DP/图算法等精确方法是否适用，并确认用户选择 DE。
2. 明确连续决策变量、上下界、目标方向、约束和目标函数评估成本。
3. 在上下界内生成初始种群；若可行解稀少，应优先设计可行初始化或修复算子。
4. 为每个个体抽取互不相同的参考个体，按差分公式生成变异向量。
5. 执行二项式或指数交叉，得到试验向量。
6. 对越界或违反约束的试验解执行用户确认的修复、惩罚或可行性优先规则。
7. 计算目标值，将试验解与父代比较并保留较优者。
8. 记录每代最佳值、平均值、可行率、约束违反量和停止原因。
9. 达到 `maxiter`、目标阈值、无改进阈值或时间限制后停止，并用多个随机种子复核稳定性。

## 关键参数候选

以下都是推荐起点，不是最终配置。进入代码前必须由用户确认。

| 参数 | 推荐候选 | 说明 |
|---|---|---|
| `strategy` | `best1bin`、`rand1bin` | `best1bin` 收敛倾向更强，`rand1bin` 多样性通常更好 |
| `F` / `mutation` | `0.5 ~ 0.9` | 差分缩放因子，过大可能震荡，过小可能停滞 |
| `CR` / `recombination` | `0.6 ~ 0.9` | 交叉概率，需结合变量相关性和策略选择 |
| `popsize` | 维度的 `5 ~ 20` 倍作为候选 | SciPy 风格中它是每维倍率；自写实现必须确认是总规模还是倍率 |
| `maxiter` | `100 ~ 500` | 受维度、单次评估成本和运行预算影响 |
| `tol` | 由目标尺度和无改进容忍度确定 | 不能脱离目标函数量纲机械套用 |
| `polish` | `True` / `False` | 只在用户允许并且有合适局部求解器时使用 |
| `seed` | 用户确认的固定种子或多种子集合 | 多种子用于稳定性，不等于验证集 |

## 适用范围

- 连续、有界、不可导或黑箱目标。
- 目标函数非凸，且梯度方法不稳定或不可用。
- 可以承受种群多次调用目标函数的计算成本。

## 不适用边界与风险

- 纯离散、排列、路径或复杂逻辑变量不能直接套标准 DE；必须有明确的离散化、解码和修复规则。
- 高维或单次仿真很慢时，评估次数可能成为主要成本。
- 约束很多且可行域很窄时，惩罚权重、修复规则和可行初始化会决定结果，不能只看目标函数值。
- DE 的最好一次运行不能证明全局最优；应报告多随机种子、可行率、均值、标准差、停止原因，并在有精确基准时报告差距。

## 数据驱动目标的防泄漏

- 若 DE 搜索预测模型、代理模型或模型超参数，适应度只能使用训练集内部验证结果。
- 测试集必须在搜索结束、参数锁定后使用一次。
- 模型参数搜索空间和 DE 自身参数必须分成两张表，不能混在一起。
- 若目标是固定确定性规划，不强行创建训练/验证/测试集，改用可行性、最优性 gap、上下界和敏感性分析。
