# 蚁群算法（ACO）

## 适用范围

ACO 是基于路径构造和信息素学习的随机组合优化方法。它优先适用于：

- TSP、VRP、带时间窗的路径规划和巡回路径；
- 能逐步构造解的排列、分配或组合问题；
- 目标函数不可导、评价代价较高、精确模型规模过大的路径型问题。

不应把 ACO 当成所有“最短路”问题的默认方法。若只是静态非负边权最短路，应先比较 Dijkstra、Bellman-Ford、Floyd 或其他图算法；小规模 TSP/VRP 应先比较 MILP、CP-SAT、DP、最近邻和 2-opt。连续 ACO 变体存在，但必须明确变体和连续概率模型，不能直接使用离散路径规则。

## 数学对象

设图为 (G=(V,E))，蚂蚁 (k) 在节点 (i) 选择候选节点 (j) 的概率为：

$$
P_{ij}^{(k)}=
\frac{\tau_{ij}^{\alpha}\eta_{ij}^{\beta}}
{\sum_{\ell\in\mathcal C_i^{(k)}}
\tau_{i\ell}^{\alpha}\eta_{i\ell}^{\beta}}
$$

其中：

- (	au_{ij})：边 ((i,j)) 的信息素浓度；
- (eta_{ij})：启发式信息，例如距离型问题中的 (1/(d_{ij}+\varepsilon))；
- (alpha)：信息素影响强度；
- (eta)：启发式信息影响强度；
- (mathcal C_i^{(k)})：蚂蚁 (k) 在节点 (i) 的可行候选集。

一轮完成后可使用全局更新：

$$
\tau_{ij}\leftarrow(1-\rho)\tau_{ij}+
\sum_{k=1}^{m}\frac{Q}{L_k}
\mathbf 1\{(i,j)\in P_k\}
$$

其中 (m) 是蚂蚁数量，(L_k) 是第 (k) 条完整路径的目标长度，(Q) 是信息素沉积尺度，(ho) 是蒸发率。最大化问题必须先统一为最小化成本，或明确使用与收益一致的沉积公式，不能直接把收益和长度公式混用。

## 算法步骤

1. 明确节点、边、方向、起终点、回路要求和不可行边。
2. 构造成本矩阵或邻接表，处理缺失边、零距离、重复节点和单位。
3. 选择启发式信息 (eta)，设置初始信息素 (	au_0)，并定义候选集。
4. 对每只蚂蚁从起点开始逐步选点，只从当前可行候选集采样。
5. 完成路径后执行闭环、容量、时间窗、覆盖和访问次数检查。
6. 对不可行解执行重构、交换、插入、局部搜索或明确的惩罚，并记录可行率。
7. 按既定口径执行一次信息素蒸发，再执行局部或全局沉积；同一轮不能重复蒸发。
8. 更新全局最好路径，记录目标值、可行率、路径长度和停滞轮数。
9. 达到最大迭代、无改进轮数或时间限制后停止。
10. 用多个随机种子、最近邻/2-opt 和可用精确方法比较结果。

## 关键参数

| 参数 | 推荐起点或范围 | 影响 | 必须确认 |
|---|---|---|---|
| `alpha` | 1 左右 | 越大越依赖历史信息素，过大易早熟 | 是 |
| `beta` | 2--5 | 越大越依赖启发式信息，过大可能贪心 | 是 |
| `rho` | 0.1--0.5 | 越大遗忘越快，过小可能停滞 | 是 |
| `ant_count` | 节点数的 1--2 倍 | 增加搜索覆盖但提高计算量 | 是 |
| `Q` | 按路径长度和 `tau0` 尺度校准 | 控制沉积量，不能脱离目标尺度机械设置 | 是 |
| `tau0` | 依据初始路径成本确定 | 影响早期探索 | 是 |
| `candidate_list` | 最近邻的固定数量或比例 | 降低计算量但可能排除好边 | 是 |
| `q0` | 仅在伪随机比例规则中使用 | 控制贪心选择与随机采样的比例 | 是 |
| `tau_min/tau_max` | 视信息素停滞情况设置 | 防止信息素塌缩或无限放大 | 是 |
| `max_iter` | 100--500 作为候选 | 迭代预算，不代表收敛保证 | 是 |

这些值只是推荐候选。进入代码或正式实验前，必须展示“推荐值、用户确认值、实际运行值”三列。若用户选择贝叶斯或其他自动调参，还要先确认搜索范围、预算、评价指标、随机种子和早停规则。

## 图和信息素的实现注意事项

- 有向图要分别存储 (	au_{ij}) 和 (	au_{ji})；无向图要明确二者是否共享同一条边的信息素。
- 距离为零时不能直接使用 (1/d)，应使用问题有意义的修正规则并记录。
- 不可达边不能仅用极大数掩盖；应进入候选集过滤或路径修复逻辑。
- 约束优先级要明确：可行解通常优先于不可行解；惩罚项必须与目标尺度相容。
- 全局最好沉积、每只蚂蚁沉积和精英蚂蚁沉积不是同一策略，必须记录实际策略。
- 不要在每个子步骤和每轮末尾各蒸发一次，除非算法变体明确规定。
- 信息素早熟时，可降低 `alpha`、提高 `rho`、设置信息素上下界、扩大候选集或注入随机/局部搜索。
- 只报告最好路径不足以证明稳定性，应同时报告可行率、均值、标准差、停止原因和多随机种子排名。

## 输出与验证

至少输出：

- 图表示、边方向和距离/成本定义；
- `alpha`、`beta`、`rho`、`Q`、蚂蚁数、`tau0`、候选集和停止配置；
- 最优路径、目标值、可行率、约束违反量和运行时间；
- 每轮最好值、平均值、可行率、停滞轮数，必要时输出信息素统计；
- 多随机种子结果以及与最近邻、2-opt、MILP/CP-SAT 或图算法的比较；
- 若目标函数来自数据或仿真，训练内部验证口径和独立测试结果必须分开。
