# 非线性规划与混合整数非线性规划

## 模型形式

连续非线性规划（NLP）可写为：

```text
min f(x)
s.t. g_i(x) <= 0,
     h_j(x) = 0,
     l <= x <= u
```

含整数或 0-1 决策变量时，为混合整数非线性规划（MINLP）：

```text
min f(x, z)
s.t. g_i(x, z) <= 0,
     h_j(x, z) = 0,
     l <= x <= u,
     z_j in Z or {0,1}
```

## 适用范围

- 目标函数或约束天然包含乘积、幂、指数、对数、距离、概率或其他非线性关系。
- NLP：变量主要连续，且可以计算函数值和必要的导数或梯度近似。
- MINLP：同时存在连续变量和整数/0-1 变量，非线性结构不能合理线性化。

## 路由步骤

1. 明确变量域、上下界、目标方向、等式约束和不等式约束。
2. 检查函数定义域，例如对数的正值条件、分母非零条件和开方的非负条件。
3. 判断目标与可行域是否凸；凸性成立时优先使用能提供全局最优条件的求解器。
4. 若是 MINLP，先检查是否可以线性化、分段线性化或改写为 MILP/CP-SAT。
5. 选择局部、凸优化、全局或混合整数求解器，并设置用户确认的停止条件。
6. 对非凸 NLP 使用多起点、边界检查和敏感性分析；不能把单次局部解直接写成全局最优。
7. 对 MINLP 报告可行性残差、求解状态、上下界、最优性 gap 和时间限制。
8. 复算目标值、约束违反量和变量域，确认输出解可以代回原题解释。

## 求解配置候选

以下只作为推荐起点，最终值必须由用户确认或由用户确认的搜索范围决定：

| 配置 | 推荐考虑方式 | 风险 |
|---|---|---|
| `tol` / 可行性容差 | 按目标和约束量纲设定，并做敏感性检查 | 过严会变慢，过松可能接受不可行解 |
| `max_iter` / `TimeLimit` | 根据变量规模和运行预算给候选范围 | 截止时可能只有可行解而非证明最优 |
| `MIPGap` | 仅适用于带整数分支的求解过程，先确定可接受误差 | gap 不是模型误差，也不替代可行性检查 |
| 多起点数量 | 非凸 NLP 从少量到中等数量起点试验 | 起点少不能说明全局性，起点多会增加成本 |
| 初始点 | 使用可行点或用户确认的生成规则 | 不可行初始点可能导致求解失败 |

## 常见错误

- 把“存在非线性”直接等同于必须使用智能优化。
- 忽略函数定义域、变量边界或约束方向。
- 把局部求解器的单次结果称为全局最优。
- 只报告目标值，不报告约束残差、求解状态和最优性 gap。
- 对固定确定性规划强行套训练/验证/测试；只有目标或约束参数来自数据模型时才需要按数据驱动任务划分。
