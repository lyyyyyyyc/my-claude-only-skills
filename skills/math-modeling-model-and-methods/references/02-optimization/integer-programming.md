# 整数规划 / 0-1 规划

## 核心想法
- 决策变量部分或全部只能取整数的情况，可看作是一种特殊的线性规划。

## 适用题型
- 一般用于处理调度问题、资源分配问题、网络设计、组合优化、选址问题等。
- 适合“选 / 不选”“开 / 不开”“分几台 / 派几人”这类决策变量必须离散化的问题。

## 什么时候优先考虑
- 决策变量必须是整数。
- 连续解在实际语义上没有意义。
- 问题本质是离散选择、组合配置或布尔决策。

## 什么时候不优先
- 决策变量天然连续，允许小数解。
- 问题非线性过强，单纯整数线性结构难以表达。
- 状态转移和阶段递推关系比整数约束更核心时，应优先比较动态规划。

## 与邻近方法的区别
- 相比线性规划：整数规划更强调变量离散性，求解难度通常更高。
- 相比遗传算法等智能优化：整数规划若模型结构清晰，优先考虑精确建模与精确求解，而不是直接转启发式算法。
