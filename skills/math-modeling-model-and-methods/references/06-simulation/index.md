# 仿真模拟类方法索引

## 这类问题主要解决什么
- 仿真模拟类问题主要处理“系统运行过程难以直接解析求解，需要在规则下模拟”的问题。
- 输出通常是模拟轨迹、统计结果、情景对比、系统行为或策略测试结果。

## 典型输入 / 输出特征
- 输入：
  - 规则集
  - 事件机制
  - 状态转移逻辑
  - 随机过程或场景参数
- 输出：
  - 多轮模拟结果
  - 平均指标
  - 情景比较
  - 稳健性分析

## 当前可直接读取的方法
- Monte Carlo

## 各方法适用场景 / 不适用边界
- Monte Carlo：适合不确定性传播和随机抽样分析；不适合完全确定、可直接求解的问题。
- 离散事件仿真：适合事件驱动流程，如服务、生产、物流；不适合连续机理主导的问题。
- Agent-based 模拟：适合个体行为交互显著的问题；不适合个体规则无法描述或样本无法支撑的问题。
- 系统动力学：适合宏观反馈结构分析；不适合微观个体差异特别重要的问题。
- 排队模型：适合到达-服务-等待机制明确的问题；不适合系统机制远超排队假设的复杂场景。

## 常见混淆点与误判风险
- 有随机性不一定就要仿真；若能解析或优化求解，仿真可退居验证工具。
- 仿真结果不是现实真值，必须说明规则假设和参数来源。
- Monte Carlo 不是万能兜底，不能代替模型结构本身。

## 与邻近类别的区别
- 相比机理分析类：仿真更强调“跑起来看结果”，机理分析更强调“方程和规律”。
- 相比优化类：仿真常用于比较情景，优化类常用于找最优决策。
