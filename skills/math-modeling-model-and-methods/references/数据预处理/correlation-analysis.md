# 相关性分析

> 用途：当用户已经进入“数据预处理 / 特征理解”阶段，并且想进一步判断“变量之间到底相关不相关”“该用皮尔逊还是斯皮尔曼”“异常值多时该怎么选相关系数”时，读取本文件。
>
> 说明：本文件把相关性分析整理成数模里可选方法、可写论文、可解释边界的参考模块。重点放在皮尔逊相关系数与斯皮尔曼相关系数的区别。

## 这份文档适合什么时候看

- 你想先看变量之间有没有相关性，再决定是否做建模或特征筛选。
- 你不确定该用 Pearson 还是 Spearman。
- 你需要在论文里说明变量关系的方向和强度。

## 一句话先判断处理思路

- **如果变量是连续型，且你更关注线性关系，优先考虑皮尔逊相关系数。**
- **如果关系可能不是线性的、数据有异常值，或者更关心排序一致性，优先考虑斯皮尔曼相关系数。**

## 1. 皮尔逊相关系数

### 核心思想

皮尔逊相关系数（Pearson correlation coefficient）用来衡量：

- 两个连续变量之间的**线性关系**
- 以及这种关系的方向和强度

### 数值范围

- `1`：完全正相关
- `0`：完全不相关
- `-1`：完全负相关

### 通俗例子

- 温度越高，冰淇淋销量越高，皮尔逊相关系数接近 `1`
- 年龄越大，玩具购买量越低，皮尔逊相关系数接近 `-1`
- 鞋码和考试成绩往往接近 `0`

### 注意事项

- 更适合连续型变量；
- 更适合近线性关系；
- 对异常值比较敏感。

## 2. 斯皮尔曼相关系数

### 核心思想

斯皮尔曼相关系数（Spearman's rank correlation coefficient）用来衡量：

- 两个变量的**排名 / 顺序关系**是否一致。

它不要求一定是直线关系，只要一边大体上升、另一边也大体上升，就可能体现较强相关。

### 数值范围

- 同样在 `-1` 到 `1` 之间

### 通俗例子

- 成绩越高，名次越小，常呈显著负相关；
- 身高排名和篮球水平排名如果大体一致，则斯皮尔曼相关系数接近 `1`；
- 若顺序完全混乱，则接近 `0`。

### 优点

- 可处理非线性但单调的关系；
- 对异常值不如皮尔逊那么敏感；
- 对顺序型 / 排名型数据也更友好。

## 3. 两者怎么选

| 特性 | 皮尔逊相关系数 | 斯皮尔曼相关系数 |
|---|---|---|
| 关系类型 | 线性关系 | 单调关系 |
| 数据类型 | 连续型 | 排名型、顺序型、连续型 |
| 对异常值敏感 | 是 | 否 |
| 是否更依赖正态前提 | 相对更强 | 相对更弱 |

如果只记一句话：

- **线性关系用皮尔逊；**
- **非线性单调关系、异常值较多或排名关系更重要时用斯皮尔曼。**

## 4. 一个论文里可直接使用的表述

> 为分析变量间的相关性，本文分别采用皮尔逊相关系数与斯皮尔曼相关系数进行检验。对于连续变量之间可能存在的线性关系，使用皮尔逊相关系数度量其方向与强度；对于可能存在非线性单调关系、或受异常值影响较大的变量组合，则采用斯皮尔曼相关系数进行稳健性补充分析。

## 小结

相关性分析可以概括成一句话：

- **先判断你要抓的是线性关系，还是更一般的排序 / 单调关系，再决定用皮尔逊还是斯皮尔曼。**
