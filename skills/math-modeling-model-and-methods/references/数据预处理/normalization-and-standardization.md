# 数据标准化

> 用途：当用户已经进入“数据预处理”阶段，并且想进一步判断“什么时候用 Min-Max”“什么时候用 Z-Score”“是否要先做预处理再做标准化”时，读取本文件。
>
> 说明：本文件重点整理标准化方法选择逻辑，并把你给出的 `min-max` 口径与图片中的 `Z-Score / Max-Min / MaxAbs / RobustScaler` 选择思路统一起来。

## 这份文档适合什么时候看

- 你已经基本完成数据清洗、缺失值、异常值、重复值处理，准备进入缩放阶段。
- 你在选择 `Min-Max`、`Z-Score`、`MaxAbs` 或 `RobustScaler`。
- 你需要把标准化方法写进论文或建模说明。

## 一句话先判断处理思路

- **一般先做数据预处理，再做数据标准化。**
- **如果你希望把数据明确压到固定区间，如 `[0,1]`，可优先使用 Min-Max。**
- **如果你更强调中心化，且数据分布近似正态，优先考虑 Z-Score。**
- **如果异常值影响特别大，优先考虑 RobustScaler。**

## 1. 为什么标准化通常放在预处理之后

你给的口径很明确：

- **一般都是先数据预处理之后，再做数据标准化。**

这背后的原因是：

- 如果缺失值、异常值、重复值还没处理好，标准化后的范围和统计量会被这些脏数据带偏；
- 比如均值、标准差、最小值、最大值都可能失真；
- 这样标准化结果本身就不可靠。

因此，在数模的常见顺序里，通常是：

1. 缺失值处理
2. 异常值处理
3. 重复值处理
4. 再做标准化或归一化

## 2. 常见标准化方法

### 2.1 Min-Max 标准化

Min-Max 的目标是把数据缩放到固定区间，最常见的是 `[0,1]`。

公式常写为：

```latex
x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
```

优点：

- 结果直观；
- 很适合需要指定数据分布范围的情况；
- 作为预处理后的一般性 baseline 很常见。

缺点：

- 对异常值特别敏感；
- 如果最大值或最小值异常，整体缩放会被拉坏。

结合你给出的口径，可以把它理解成：

- **在“已经完成数据预处理”的默认流程下，Min-Max 往往是最直观、最容易落地的标准化 baseline。**

### 2.2 Z-Score 标准化

如果更强调中心化，并且对数据分布有近正态要求，则常采用 Z-Score。

公式常写为：

```latex
x' = \frac{x - \mu}{\sigma}
```

其中：

- `\mu` 是均值；
- `\sigma` 是标准差。

优点：

- 适合很多机器学习算法；
- 有利于把不同量纲的数据拉到可比尺度；
- 在分布较稳定时效果好。

缺点：

- 仍然会受到异常值影响；
- 若数据分布极端偏态，效果可能不理想。

### 2.3 MaxAbs 标准化

MaxAbs 更适合：

- 稀疏数据；
- 希望保留数据稀疏结构的场景。

它通常按绝对值最大值做缩放，因此在文本特征、稀疏矩阵类任务里更自然。

### 2.4 RobustScaler

如果你想尽量保留异常值信息，但又不想让异常值完全主导缩放过程，那么 RobustScaler 往往更合适。

它通常基于中位数和 IQR 做缩放，因此：

- 对异常值更稳；
- 不容易被极端值拖偏。

## 3. 一个实用的选择规则

根据你给的图片，可以整理成下面这张简表：

| 场景 | 更推荐的方法 |
|---|---|
| 需要中心化，且对分布有近正态要求 | Z-Score |
| 需要压到 `[0,1]` 或其他固定区间 | Min-Max |
| 稀疏数据 | MaxAbs 或 Min-Max |
| 异常值很多且希望降低其影响 | RobustScaler |

如果只给一个最简规则，可以写成：

- **一般先预处理，再标准化；常规 baseline 可先用 Min-Max；若强调中心化和近正态，再看 Z-Score。**

## 4. 一个论文里可直接使用的表述

> 在完成缺失值、异常值和重复值处理后，本文进一步对连续特征进行标准化。考虑到后续模型需要将特征映射到统一量纲范围，本文优先采用 Min-Max 标准化将数据压缩至固定区间。若任务更强调中心化处理且变量分布近似正态，则可进一步考虑 Z-Score 标准化；对于异常值较敏感的数据，则可采用基于中位数与四分位距的 RobustScaler 作为替代方案。

## 小结

数据标准化可以概括成一句话：

- **先完成清洗，再根据目标区间、分布特征和异常值影响，选择 Min-Max、Z-Score 或更稳健的缩放方式。**
