# 异常值处理

> 用途：当用户已经进入“数据预处理”阶段，并且想进一步判断“哪些值算异常值”“怎么识别异常值”“识别出来后是删除、替换还是转成缺失值再处理”时，读取本文件。
>
> 说明：本文件把异常值处理整理成数模里可选方法、可写论文、可解释边界的参考模块。重点放在识别方法、适用前提和后续处理衔接。

## 这份文档适合什么时候看

- 你发现样本中有明显偏离整体水平的数据点，例如身高数据里出现 `3.2 米` 这样的值。
- 你想判断应使用 `3σ 原则`、`箱线图/IQR` 还是其他方式识别异常值。
- 你希望把异常值识别和缺失值处理串成同一套预处理流程。
- 你需要在论文中说明“哪些值被视为异常值，以及后续如何处理”。

## 一句话先判断处理思路

- **如果数据总体近似正态分布，优先考虑 3σ 原则。**
- **如果数据分布未知、偏态明显或不满足正态前提，优先考虑箱线图 / IQR 规则。**
- **如果异常值只是局部字段级问题，而不是整行样本彻底失真，通常可先把异常值记为缺失，再转入缺失值处理。**

## 1. 先把异常值想成什么

异常值并不只是“和别人不一样的值”，而是：

- 在统计分布上明显偏离主体群体；
- 在业务含义上很可能不合理；
- 或者会显著影响均值、方差、拟合结果和分类边界的值。

对数模来说，异常值最大的风险不是“看着奇怪”，而是：

- 它可能把整体统计量拉偏；
- 它可能让模型把噪声当规律；
- 它可能让可视化和结论都失真。

## 2. 识别异常值的两类常见方法

### 2.1 3σ 原则

如果总体大致符合正态分布，则可采用 3σ 原则。

基本思想是：

- 先计算样本均值 `\mu` 和标准差 `\sigma`；
- 再判断每个值是否落在区间 `(\mu - 3\sigma, \mu + 3\sigma)` 内；
- 不在这个区间内的值，可视为异常值。

直观理解是：

- 正态分布中，大约 `99.73%` 的数据会落在 `\mu \pm 3\sigma` 范围内；
- 落在这个区间之外的值，通常已经非常罕见。

#### 适用场景

- 总体近似正态分布；
- 数据更像人口统计、测量误差、考试成绩、生产加工质量等。

#### 不适用场景

- 数据不服从正态分布；
- 例如公交站排队人数这类更接近泊松分布的情形；
- 或数据本身偏态明显、多峰分布明显。

### 2.2 箱线图 / IQR 法

当总体分布未知、偏态明显，或者不想强依赖正态假设时，常用箱线图 / IQR 法。

基本步骤：

1. 将数据从小到大排序。
2. 计算下四分位数 `Q1` 和上四分位数 `Q3`。
3. 计算四分位距：

```latex
IQR = Q3 - Q1
```

4. 定义正常区间：

```latex
[Q1 - 1.5 \times IQR,\; Q3 + 1.5 \times IQR]
```

5. 落在该区间外的值视为异常值。

这种方法的优点是：

- 不要求正态分布；
- 对偏态数据更稳；
- 在实际数模题里适用面更广。

## 3. 异常值识别后的默认处理口径

你这次给出的要求是：

- **识别出异常值后，直接删掉，然后再当作缺失值去处理。**

为了让这个口径在数据处理中更可执行，本文把它整理成更规范的写法：

1. 先识别异常值；
2. 将异常值所在字段位置置空，视为“缺失”；
3. 再调用缺失值处理流程，决定是删除、补全、真值转换、不处理还是特征选择。

也就是说，不建议简单理解成“整行样本一律删除”，而是更推荐：

- **先删除异常值本身，再把该位置作为缺失值交给 `missing-value-handling.md` 继续处理。**

这样做的好处是：

- 不会因为单个字段异常就把整条记录全部丢掉；
- 处理逻辑能和缺失值模块统一；
- 文档表达上更清楚、更可复核。

## 4. 什么时候可以整行删除

虽然默认口径是“删异常值 -> 转缺失值处理”，但在以下场景也可以考虑整行删除：

- 样本本身整体明显错误；
- 多个关键字段同时异常；
- 该行已无法代表真实观测对象；
- 且删除后不会明显破坏类别分布。

## 5. 一个论文里可直接使用的表述

> 针对原始数据中的极端异常值，本文先依据数据分布特征进行识别：对近似正态分布的数据采用 3σ 原则，对分布未知或偏态明显的数据采用箱线图与 IQR 区间法。对于识别出的异常值，不直接保留参与建模，而是先将其剔除并记为缺失项，再统一并入缺失值处理流程，以减少极端值对统计量和模型拟合结果的干扰。

## 6. 常见误判风险

- 不先判断分布，就机械使用 3σ 原则。
- 把“极端但合理”的真实观测值误删。
- 看到异常值就整行删除，导致样本损失过大。
- 异常值删掉后，没有继续补全或说明后续处理方式。
- 把异常值处理与缺失值处理割裂开来，导致流程不统一。

## 小结

异常值处理可以概括成一句话：

- **先用合适的统计规则识别异常值，再把异常值位置转入缺失值处理流程，而不是简单粗暴地全删整行。**
