# TOPSIS

## 适用题型
- 适合评价类、多指标排序类问题，尤其适合“多个方案在多个指标上比较，想衡量谁更接近理想最优解”的场景。
- 常见于城市评价、方案优选、系统比较、产品排序等问题。
- 适合根据已有客观数据判断多个方案优劣，也适合处理多目标、多准则的综合排序问题。

## 什么时候优先考虑
- 有多个评价对象和多个评价指标。
- 需要输出清晰的综合排序。
- 可以把所有指标统一成“越大越优”的方向。
- 不想额外假设各决策标准必须相互独立，希望直接基于现有指标做距离比较。
- 需要一个计算流程相对清晰、实现复杂度不高的排序方法。

## 什么时候不优先
- 指标方向混乱且无法合理正向化。
- 排序背后更关心主观偏好解释，此时往往要结合 AHP 等赋权方法。
- 数据极少且很多指标高度模糊时，单用 TOPSIS 可能不够稳。
- 对新出现的外部情况适应性较弱，更适合基于已有样本做静态比较。
- 经典 TOPSIS 不显式处理指标之间的交互作用；若交互效应明显，结果可能出现偏差。

## 常见优点
- 直接利用已有客观数据进行方案排序。
- 能同时处理多个决策目标 / 多个评价指标。
- 计算流程相对简洁，结果易于解释为“接近理想解的程度”。

## 常见局限
- 对数据质量、标准化和极值处理较敏感。
- 对新情景或外部冲击的适应性一般。
- 当指标之间存在明显交互作用时，经典模型表达能力有限。

## 核心求解步骤
1. 原始矩阵正向化：
   - 先把所有指标统一为“极大型指标”。
   - 也就是将不同类型的指标转成“值越大越好”的形式。
2. 正向化矩阵标准化：
   - 通过标准化消除不同指标的量纲影响。
3. 找出理想最优解和理想最劣解：
   - 理想最优解可理解为“六边形战士”式的最佳方案。
   - 理想最劣解对应每个指标上的最差水平。
4. 确定指标权重 `w_i`：
   - 可由 AHP、熵权法、Delphi 法、对数最小二乘法等提供。
   - 若题目未给权重来源，必须说明权重是主观给出还是客观计算。
5. 计算各方案与理想最优解、理想最劣解的距离。
6. 计算贴近度并排序：
   - 越接近理想最优解、越远离理想最劣解的方案，综合表现越好。

## 标准公式
设有 \(m\) 个评价对象和 \(n\) 个评价指标。先将成本型、中间型或区间型指标转换为统一的效益型矩阵 \(X'=(x'_{ij})\)，再进行向量标准化：

\[
z_{ij}=\frac{x'_{ij}}
{\sqrt{\sum_{i=1}^{m}(x'_{ij})^2}}
\]

如果某一指标满足 \(\sum_{i=1}^{m}(x'_{ij})^2=0\)，说明该列没有可用区分信息，不能直接除以 0；应在标准化前删除、标记为零信息列或采用经过说明的退化处理。

给定权重 \(w_j\)，其中 \(w_j\ge 0\) 且 \(\sum_{j=1}^{n}w_j=1\)，构造加权标准化矩阵：

\[
v_{ij}=w_jz_{ij}
\]

正理想解和负理想解分别为：

\[
A^+=(\max_i v_{ij})_{j=1}^{n},
\qquad
A^-=(\min_i v_{ij})_{j=1}^{n}
\]

各方案到正、负理想解的距离为：

\[
D_i^+=\sqrt{\sum_{j=1}^{n}(v_{ij}-A_j^+)^2},
\qquad
D_i^-=\sqrt{\sum_{j=1}^{n}(v_{ij}-A_j^-)^2}
\]

相对贴近度为：

\[
C_i=\frac{D_i^-}{D_i^++D_i^-}
\]

如果某个方案满足 \(D_i^++D_i^-=0\)，说明正、负理想距离同时退化，不能直接计算贴近度；应报告方案并列或评价对象完全相同的情况，并停止把该数值解释成有区分度的排名。

通常按 \(C_i\) 从大到小排序。必须说明正向化方式、权重来源、标准化方法以及理想解是基于哪些评价对象构造的。

## 稳定性与敏感性检查
- 权重必须说明来源，例如 AHP、熵权法、CRITIC 或其他赋权方法；TOPSIS 本身不是赋权方法。
- 不同标准化方法可能产生不同排名，不能把某一种标准化规则当成唯一正确答案。
- 成本指标不能盲目取倒数；当原值为 0 或为负时，倒数变换可能无定义或改变指标含义，应根据指标语义选择差值、极差或其他正向化方法并记录。
- 极端值会改变正理想解、负理想解和距离，必要时应先做异常值诊断，并比较处理前后的排名。
- 高度相关指标可能造成重复计权，必要时先做相关性检查、指标合并或 PCA，并说明是否改变了评价体系。
- 增加或删除评价对象可能改变理想解和相对贴近度，需检查排名逆转风险。
- 至少进行一次权重敏感性分析和排名稳定性分析，报告第一名、前三名及完整排名是否变化。

## 输出时必须说明
- 哪些指标经过了正向化，如何正向化。
- 标准化公式是什么。
- 理想最优解、理想最劣解如何构造。
- 权重来源是什么。
- 最终排序依据是什么，并给出每个方案的 \(D_i^+\)、\(D_i^-\) 和 \(C_i\)。
- 标准化替换、权重扰动、方案增删或异常值处理后，排名是否稳定。

## 常见易错点
- 直接做 TOPSIS，但没先做正向化。
- 权重来源不明，导致结果解释不足。
- 只给最后排序，不展示“距离 / 贴近度”中间结果。
- 把 TOPSIS 当作赋权方法使用，它本身不是赋权方法。
- 使用倒数处理 0 或负值成本指标，却不说明数学和业务含义。
- 忽略极端值、相关指标或评价对象增删造成的排名逆转。

## 可与哪些方法组合
- AHP + TOPSIS：AHP 给主观权重，TOPSIS 排序。
- 熵权法 + TOPSIS：熵权法给客观权重，TOPSIS 排序。
- CRITIC + TOPSIS：CRITIC 给客观权重，TOPSIS 排序。
