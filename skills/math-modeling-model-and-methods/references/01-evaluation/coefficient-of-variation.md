# 变异系数法

## 适用题型

- 适合评价类、多指标综合评价类问题中的客观赋权。
- 适合希望依据指标相对离散程度分配权重的场景。
- 更适用于正值、比率尺度且均值具有明确意义的指标。正值只是必要的数值条件，不代表指标自动满足比率尺度。

## 核心公式

设第 \(j\) 个指标的样本均值为 \(\bar{x}_j\)，标准差为 \(s_j\)，则变异系数为：

\[
CV_j=\frac{s_j}{|\bar{x}_j|}
\]

归一化后得到权重：

\[
w_j=\frac{CV_j}{\sum_{k=1}^{n}CV_k}
\]

变异系数越大，表示相对于自身均值的离散程度越高，在该方法中通常会获得更大的权重。

## 核心求解步骤

1. 明确 \(m\) 个评价对象和 \(n\) 个指标，并统一指标口径。
2. 检查每个指标是否满足比率尺度要求，记录均值和标准差的计算方式。
3. 计算 \(\bar{x}_j\)、\(s_j\) 和 \(CV_j\)。
4. 处理均值接近 0、均值为负、常数列和异常值问题。
5. 归一化得到 \(w_j\)，检查权重和是否为 1。
6. 将权重传递给 TOPSIS、GRA、模糊综合评价或加权评分方法。

## 重要边界

- 当 \(|\bar{x}_j|\) 接近 0 时，\(CV_j\) 会非常不稳定，不能仅靠加入很大的 \(\varepsilon\) 掩盖问题。
- 当均值为 0 时，变异系数无定义；当均值为负时，即使使用绝对值，也必须先确认该指标是否适合比率尺度解释。
- 比率尺度要求零点具有实际意义，且“相差两倍”具有可解释性；仅因为数据为正，不能自动使用变异系数法。
- 指标为常数时 \(s_j=0\)，通常应赋零权重或删除，并记录处理原因。
- 极端值会同时影响均值和标准差，应先进行异常值诊断。
- 变异系数只反映相对离散程度，不等于专家认为的实际重要性。
- 如果所有 \(CV_j=0\)，不能强行归一化，应重新检查指标体系或改用其他赋权方法。

## 输出时必须说明

- 指标为何满足比率尺度和均值可解释要求。
- 均值接近 0、负均值、常数列和异常值如何处理。
- \(\bar{x}_j\)、\(s_j\)、\(CV_j\) 和最终权重。
- 权重是否进入后续排序或综合评价方法。

## 常见易错点

- 不检查均值是否接近 0 就直接计算。
- 把不同量纲或不同统计口径的指标直接比较变异系数。
- 把变异系数权重当成最终评价得分或排名。
- 忽略异常值导致标准差虚高。
