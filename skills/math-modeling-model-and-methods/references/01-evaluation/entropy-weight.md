# 熵权法

## 适用题型
- 适合评价类、多指标综合评价类问题，尤其适合“希望客观赋权、弱化人为主观判断”的场景。
- 常用于给 TOPSIS、综合评分模型、模糊综合评价等方法提供权重。
- 本质上是一种客观赋权方法，主要用于确定多指标在综合评价中的权重分配。

## 什么时候优先考虑
- 各指标都有较完整的原始数据。
- 希望通过数据本身的信息差异来确定权重。
- 不希望完全依赖专家打分。
- 如果更希望依据指标离散程度来分配权重，而不是依赖主观判断，熵权法通常比 AHP 更合适。

## 什么时候不优先
- 数据很少、缺失很多或波动不稳定。
- 指标全都差不多，没有明显信息差异，此时熵权容易区分度不足。
- 题目明确要求体现专家偏好，此时熵权法不应单独使用。
- 若数据误差较大、异常值较多，权重结果容易被放大干扰。

## 常见优点
- 客观赋权，主观偏差较小。
- 适合与 TOPSIS、综合评分、模糊综合评价等方法配合使用。
- 当指标差异较明显时，权重结果通常较稳定。

## 常见局限
- 依赖数据质量，受误差和异常值影响较大。
- 如果各指标波动都很弱，权重区分度会下降。
- 不能替代专家知识；若题目强调偏好表达，通常需要和主观赋权法结合。

## 核心求解步骤
1. 原始矩阵正向化：
   - 先将指标数据统一转换为极大型指标。
   - 原始矩阵可记为 `X = [x_ij]`，其中 `m` 是评价对象数，`n` 是评价指标数。
   - 常见正向化规则：
     - 极大型（效益型）指标：
       - `x̂ = (x - x_min) / (x_max - x_min)`
     - 极小型（成本型）指标：
       - `x̂ = (x_max - x) / (x_max - x_min)`
     - 中间型指标：
       - `M = max{|x_i - x_best|}`
       - `x̂ = 1 - |x_i - x_best| / M`
     - 区间型指标：
       - `M = max{a - min{x_i}, max{x_i} - b}`
       - 当 `x_i < a` 时：`x̂ = 1 - (a - x_i) / M`
       - 当 `a ≤ x_i ≤ b` 时：`x̂ = 1`
       - 当 `x_i > b` 时：`x̂ = 1 - (x_i - b) / M`
2. 正向化矩阵标准化：
   - 通过标准化消除不同指标的量纲。
   - 常用写法：
     - `z_ij = x'_ij / sqrt(sum_i (x'_ij)^2)`
   - 其中 `x'_ij` 为正向化矩阵元素，`z_ij` 为标准化后的元素。
3. 标准化矩阵归一化：
   - 将标准化矩阵进一步调整到 `0-1` 范围结构下。
   - 常用写法：
     - `p_ij = z_ij / sum_i z_ij`
   - 其中 `p_ij` 为归一化后的元素。
4. 计算信息熵、信息效用值、熵权：
   - 信息熵：
     - `e_j = -(1 / ln m) * sum_i p_ij ln(p_ij)`
   - 信息效用值：
     - `d_j = 1 - e_j`
   - 熵权：
      - `w_j = d_j / sum_{k=1}^n d_k`
5. 用得到的权重进入综合评价模型：
   - 可直接做加权综合评分。
   - 也可与 TOPSIS 等排序方法结合使用。

## 标准公式与符号
统一记号为：\(m\) 个评价对象、\(n\) 个评价指标，\(x'_{ij}\) 表示已经完成方向统一和非负化处理的指标值。比例矩阵可写为：

\[
p_{ij}=\frac{x'_{ij}}{\sum_{i=1}^{m}x'_{ij}}
\]

如果前一步先得到向量标准化矩阵 \(z_{ij}\)，也可以写成 \(p_{ij}=z_{ij}/\sum_{i=1}^{m}z_{ij}\)，但必须明确两步的作用不同，不能把正向化、标准化和比例化混为一步。

信息熵、差异系数和权重分别为：

\[
e_j=-\frac{1}{\ln m}\sum_{i=1}^{m}p_{ij}\ln p_{ij}
\]

\[
d_j=1-e_j,
\qquad
w_j=\frac{d_j}{\sum_{k=1}^{n}d_k}
\]

约定 \(0\ln 0=0\)。熵权反映的是指标在当前样本中的数据区分度，不等于指标在现实决策中的实际重要性。

## 零值、常数列与计算复核
- 如果某指标所有评价对象取值相同，它没有区分力。不能直接套用分母为 0 的极差标准化；应将其标记为常数列，并记录是删除该指标，还是保留后令其信息效用为 0。
- 如果某列存在零值，按 \(0\ln 0=0\) 处理，不要为了避免报错而使用过大的 \(\varepsilon\)；若必须加入 \(\varepsilon\)，应报告取值并检查它是否改变了权重。
- 若所有指标都没有区分力，使得 \(\sum_{k=1}^{n}d_k=0\)，熵权法无法给出有区分度的权重，应回到指标体系或改用专家赋权 / 组合赋权，而不是强行归一化。
- 极端值会改变离散程度和熵权；异常值处理必须在计算熵权前完成，并说明处理规则。
- 指标高度相关时，多个指标可能重复计权；必要时先做相关性检查、指标合并或降维，并说明对权重的影响。
- 经验上的 `m ≥ 5`、`m ≥ 10` 只能用于方法初筛，不能当成普遍适用的样本量定理。
- 具体计算前，按 [entropy-weight-checklist.md](entropy-weight-checklist.md) 逐项核对方向、常数列、零值、熵值范围、权重和以及手算 / 程序复核结果。

## 输出时必须说明
- 每类指标分别属于哪种类型：效益型、成本型、中间型还是区间型。
- 正向化规则是否已统一。
- 标准化和归一化分别用了什么公式。
- 熵权结果是多少，权重和是否为 1。
- 熵权后续是如何进入最终评价模型的。
- \(m\) 和 \(n\) 分别代表什么，常数列和零值如何处理。
- 熵值是否满足预期范围，手算或程序复核是否通过。

## 常见易错点
- 把正向化、标准化、归一化混成一步。
- 指标类型判错，导致后面权重和评价结果失真。
- 公式写了，但不解释各矩阵元素含义。
- 只求出了熵权，却没说明熵权后续如何用于综合评价。
- 对常数列直接套极差标准化，造成分母为 0 或伪造区分度。
- 忽略零值、极端值或高度相关指标对权重的影响。
- 把客观数据区分度解释成现实中的指标重要性。

## 可与哪些方法组合
- 熵权法 + TOPSIS：最常见，用熵权给客观权重，再做排序。
- 熵权法 + 综合加权评分：直接给各指标客观权重后求总分。
- 熵权法 + 模糊综合评价：先客观赋权，再做模糊评价。
