# 熵权法计算复核清单

## 使用时机

在熵权法进入 TOPSIS、综合评分或模糊综合评价之前，完成一次“做完后确认”的复核。该清单用于发现方向、下标、零值、常数列和程序实现错误，不替代具体方法文档。

## 计算前

- [ ] 已明确 \(m\) 是评价对象数、\(n\) 是评价指标数，并核对矩阵维度。
- [ ] 已逐列标记效益型、成本型、中间型和区间型指标。
- [ ] 已记录每一列的正向化公式，确认指标方向没有写反。
- [ ] 已检查常数列；对 \(x_{\max}=x_{\min}\) 的指标没有直接套极差标准化。
- [ ] 已检查异常值、缺失值和极端值，并记录处理方式。

## 计算中

- [ ] 已明确 \(x'_{ij}\) 或 \(z_{ij}\) 的含义，没有把正向化、标准化和比例化混成一步。
- [ ] 对比例矩阵使用

\[
p_{ij}=\frac{x'_{ij}}{\sum_{i=1}^{m}x'_{ij}}
\]

- [ ] 已按 \(0\ln 0=0\) 处理零值，没有用未经说明的过大 \(\varepsilon\) 改变权重。
- [ ] 每个指标的比例列和约等于 1。

- [ ] 如果采用向量标准化后的 \(z_{ij}\) 路径，明确改用

\\[
p_{ij}=\frac{z_{ij}}{\sum_{i=1}^{m}z_{ij}}
\\]

并在报告中说明没有把 \(x'_{ij}\) 路径和 \(z_{ij}\) 路径混用。
- [ ] 熵值满足预期范围，且使用的是

\[
e_j=-\frac{1}{\ln m}\sum_{i=1}^{m}p_{ij}\ln p_{ij}
\]

- [ ] 已计算 \(d_j=1-e_j\)，并确认没有把熵值本身误当成权重。

## 输出前

- [ ] 权重使用

\[
w_j=\frac{d_j}{\sum_{k=1}^{n}d_k}
\]

并且权重和约等于 1。
- [ ] 如果所有 \(d_j=0\)，已停止强行归一化，并重新检查指标体系或改用其他赋权方式。
- [ ] 已检查高度相关指标是否造成重复计权。
- [ ] 已使用独立手算、表格或程序复核至少一组中间结果，不能只核对最终权重。
- [ ] 已说明熵权表示当前样本的数据区分度，不把它直接解释成现实中的指标重要性。
- [ ] 已说明熵权后续进入了哪一种综合评价或排序方法。
