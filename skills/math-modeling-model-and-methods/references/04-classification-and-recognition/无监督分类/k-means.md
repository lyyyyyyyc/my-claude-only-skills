# K-means（均值聚类）

> 用途：当用户已经判断问题属于“分类识别 / 聚类发现”方向，并且想进一步理解“什么时候适合用 K-means”“K-means 的流程是什么”“K 值怎么理解”“为什么它适合做无监督分组”时，读取本文件。
>
> 说明：本文件不是把教材原句搬过来，而是把 K-means 整理成“数模里能选方法、写论文、解释结果”的参考模块。重点放在直观理解、步骤逻辑、优缺点边界和论文表达。

## 这份文档适合什么时候看

- 你面对的是“没有现成标签，但想把样本按相似性自动分组”的问题。
- 你已经确定题目更像聚类或分群，而不是监督分类。
- 你想先用一个简单、快速、可解释的聚类方法做 baseline。
- 你需要在论文中解释“为什么选择 K-means，而不是层次聚类或其他更复杂方法”。

## 一句话先判断它适不适合这题

- **如果样本之间可以用数值特征表示，且你希望把它们分成若干个相对圆形、紧凑的簇，K-means 往往值得优先进入候选。**
- **如果数据里离群点很多、簇形状很扭曲、密度差异很大，K-means 往往不是第一选择。**
- **如果你连簇数都完全没有概念，或者更关心层次结构而不是固定分组，通常要先看层次聚类。**

## 1. 先把 K-means 想成什么

K-means 可以理解成一种“找代表中心，再按最近中心分组”的方法。

按截图中的原始定义，它属于“原型聚类”：原型是指样本空间中具有代表性的点，通过一组原型刻画，这一方法在实际聚类任务中最为常用。

它的目标不是直接告诉你“真实类别是什么”，而是先在样本中找出 `K` 个代表性的中心点，然后把每个样本分配给最近的中心。通过反复更新中心位置，最终让同一组内部尽量相似、不同组之间尽量分开。

所以，K-means 的核心不是“给数据贴标签”，而是：

- 先假设要分成 `K` 组；
- 再让每一组有一个中心；
- 通过反复“分组 -> 重新计算中心”的过程，把分组慢慢调整到稳定状态。

你可以把它想成“反复整理座位表”：

- 先随便指定几个小组长；
- 再让每个人坐到离自己最接近的小组长旁边；
- 然后重新在每组里选一个更能代表这组平均水平的新组长；
- 一直重复，直到大家的位置基本稳定。

## 2. K-means 到底在优化什么

K-means 的标准目标，是让每个簇内部的样本尽量靠近自己的簇中心。常见写法是最小化簇内平方和：

```latex
\min \sum_{j=1}^{K} \sum_{x_i \in C_j} \|x_i - \mu_j\|^2
```

其中：

- `K` 是簇的个数；
- `C_j` 是第 `j` 个簇；
- `\mu_j` 是第 `j` 个簇的质心；
- `x_i` 是某个样本点。

这条公式的直观含义是：

- 每个样本都尽量离自己的中心近一些；
- 所有簇加起来的“组内离散程度”尽量小。

因此，K-means 的追求不是“让类别名称好看”，而是“让每组内部更集中”。

## 3. 流程总览：K-means 怎么工作

K-means 的标准流程可以整理成下面这条线：

1. 先决定簇数 `K`。
2. 随机选取 `K` 个初始质心。
3. 计算每个样本到各个质心的距离。
4. 把每个样本分到最近的质心所在簇。
5. 对每个簇重新计算质心。
6. 重复“分配样本 -> 更新质心”。
7. 当质心变化很小，或者分组结果不再变化时停止。

这条流程的关键不是“反复迭代”四个字，而是它每一轮都只做两件事：

- **先分组**：谁离哪个中心近，就先归到哪里；
- **再更新中心**：每组用自己的平均值重新代表自己。

所以 K-means 的本质其实非常清楚：

- 用“最近中心”来定义分组；
- 用“平均值”来更新中心。

## 4. 一个通俗例子：按成绩给学生分组

假设我们有 5 个学生的数学和英语成绩：

| 学生 | 数学 | 英语 |
|---|---:|---:|
| A | 85 | 80 |
| B | 90 | 85 |
| C | 75 | 60 |
| D | 70 | 55 |
| E | 95 | 90 |

如果我们设定 `K = 2`，意思就是想把这 5 个学生分成两组。

### 第一步：初始化质心

为了让例子更清楚，我们假设初始质心选成：

- 质心 1：A = `(85, 80)`
- 质心 2：D = `(70, 55)`

这一步可以理解成：先随便指定两个“组代表”。

### 第二步：把每个学生分给最近的质心

这时会计算每个学生到两个质心的距离。使用二维欧几里得距离：

```latex
d(x, y) = \sqrt{(x_1 - y_1)^2 + (x_2 - y_2)^2}
```

直观来看：

- A、B、E 的成绩彼此更接近，会倾向于分到高分组；
- C、D 的成绩彼此更接近，会倾向于分到另一组。

因此第一轮分组结果可以写成：

- 簇 1：A、B、E
- 簇 2：C、D

### 第三步：更新质心

对每个簇重新取平均值：

簇 1 的新质心：

```latex
\mu_1 = \left(\frac{85+90+95}{3}, \frac{80+85+90}{3}\right) = (90, 85)
```

簇 2 的新质心：

```latex
\mu_2 = \left(\frac{75+70}{2}, \frac{60+55}{2}\right) = (72.5, 57.5)
```

这一步可以理解成：

- 不再让 A 和 D 继续代表各自组；
- 而是让每个组自己的“平均水平”来当新中心。

### 第四步：继续迭代

再根据新质心重新分组。如果分组结果不再变化，或者质心变化已经非常小，算法就停止。

在这个例子里，分组已经很稳定，所以最终结果通常会保持为：

- 一组是较高成绩学生：A、B、E
- 一组是较低成绩学生：C、D

## 5. K 值到底在控制什么

`K` 表示你想分成几个簇。它不是算法自动从题意里读出来的，而是建模者要先设定或通过额外方法去判断的。

这也是 K-means 最关键的一个前提：**你必须先给它一个簇数。**

### K 太小时会怎样

- 原本应该分开的群体会被硬挤在一起；
- 簇内部差异会变大；
- 解释时容易显得分组过粗。

### K 太大时会怎样

- 一个本来完整的群体可能被切碎；
- 分组结果会变得琐碎；
- 论文里会出现“虽然分得很细，但解释价值不高”的问题。

### 数模里常见处理方式

- 结合题意先给一个业务上合理的簇数；
- 再用肘部法、轮廓系数等指标辅助判断；
- 最后把“为什么取这个 K”写成方法选择依据。

## 6. K-means 的优点

### 6.1 简单

它的逻辑很直观，容易讲清楚，特别适合做论文里的 baseline 方法。

### 6.2 速度快

相比很多更复杂的聚类方法，K-means 在数据量较大时依然比较高效，因此常被用来做第一轮分群。

对大数据集而言，它通常也能保持较好的可伸缩性和高效性。

### 6.3 可解释性强

每个簇都有一个质心，这个质心可以被解释为“该组的平均代表特征”，很适合在论文里说明每组画像。

## 7. K-means 的缺点与边界

### 7.1 必须先给 K

它不会自动告诉你“最自然的簇数是多少”，所以如果题意对簇数没有提示，你还需要额外做 K 值判断。

### 7.2 对离群点敏感

由于质心是平均值，异常值会把中心拉偏，从而影响整体分组。

### 7.3 更适合“较圆、较紧凑”的簇

如果真实数据呈现出月牙形、条带形、环形等复杂形状，K-means 往往分得不理想。

### 7.4 对特征尺度敏感

如果某个指标量纲特别大，它会主导距离计算。因此实际使用前通常要先标准化或归一化。

### 7.5 关键是欧氏距离下的紧凑结构

K-means 的关键前提不是每个簇必须服从正态分布，而是：在选定距离和尺度下，各簇尽量呈紧凑、近似球形，且组内平方和能够反映“相似程度”。如果簇形状、密度或尺度明显不满足这一条件，不能只凭分布名称继续使用 K-means。

### 7.6 只适用于连续型数据

由于它以均值作为簇中心的代表，因此更适合连续型数值特征，不适合直接处理纯离散类别型数据。

## 8. 它和层次聚类有什么不同

- K-means 先给定 `K`，再反复优化中心。
- 层次聚类不一定先给定最终簇数，而是先构造层次结构，再决定在哪一层切开。
- K-means 更像“固定分几组，然后快速优化”。
- 层次聚类更像“先看样本是怎么一步步合并或拆开的，再决定分法”。

因此：

- 如果你已经大致知道要分几组，K-means 更自然；
- 如果你更关心样本之间的层次关系，层次聚类通常更合适。

## 9. 数模里怎么把它写进论文

如果你最终决定用 K-means，论文里一般要交代四件事：

1. 为什么这是一个无监督分组问题。
2. 为什么选择 K-means 作为聚类方法。
3. K 值是怎么确定的。
4. 聚类结果如何解释、如何验证。

一个比较自然的论文表述可以写成：

> 由于题目未提供现成类别标签，而研究目标是根据样本特征将对象自动分组，因此本文将该问题视为无监督聚类问题。考虑到样本特征为数值型指标、聚类结果需要较强可解释性，且需要快速获得分组基线，本文采用 K-means 聚类方法对样本进行分群。该方法通过最小化簇内平方和，不断迭代更新质心与样本归属，最终形成内部相似、组间差异较明显的聚类结构。

## 10. 常见误判风险

- 把 K-means 当成监督分类方法使用。
- 数据没有做标准化就直接计算距离。
- 只给出聚类结果，不解释每个簇代表什么。
- 只说“我们取 K=3”，但不说明取值依据。
- 数据中离群点明显，却仍直接使用普通均值质心而不做处理。

## 11. 核心公式与关键超参数

样本 `x_i` 的簇分配为：

\[
c(i)=\arg\min_{1\le k\le K}\lVert x_i-\mu_k\rVert_2^2
\]

簇中心更新为：

\[
\mu_k=\frac{1}{|C_k|}\sum_{x_i\in C_k}x_i
\]

典型目标函数为簇内平方和：

\[
J=\sum_{k=1}^{K}\sum_{x_i\in C_k}\lVert x_i-\mu_k\rVert_2^2
\]

| 参数 | 作用 | 建议起点 |
|---|---|---|
| `n_clusters` | 簇数 `K` | 由题意、肘部、轮廓、稳定性和业务解释共同确定 |
| `init` | 初始中心方式 | `k-means++` 通常作为起点 |
| `n_init` | 独立初始化次数 | 多次初始化，避免单次局部最优 |
| `max_iter` | 每次运行最大迭代次数 | 根据收敛情况设置 |
| `tol` | 收敛容差 | 与特征尺度和目标精度一起检查 |
| `random_state` | 随机种子 | 固定并记录，稳定性分析时再改变 |

表中的范围和设置都是经验起点，不是适用于所有数据集的绝对阈值；最终参数要结合轮廓、稳定性和业务解释确定。

## 12. K 值与稳定性检查

- 肘部法只说明簇内平方和的下降趋势，不能单独证明某个 `K` 正确。
- 轮廓系数、Calinski–Harabasz、Davies–Bouldin 需要结合距离和簇规模解释。
- 至少比较多个随机种子；必要时做重采样或轻微扰动，检查簇结构是否保持。
- 结果报告应包含每个簇的样本数、质心/画像、指标差异和异常样本，而不只给簇编号。
- K-means 的均值质心对离群点敏感；异常点处理要在预处理流程中完成并记录。
- `K`、标准化方式和异常值规则都可能改变结果，必要时做敏感性分析。

## 13. 什么时候建议优先看别的方法

- 如果你需要看样本的层次关系，而不是只要固定分组，优先转 `hierarchical-clustering.md`。
- 如果数据簇形状复杂、离群点明显、密度差异大，K-means 往往不是第一选择。
- 如果你需要的是“有标签后的判别模型”，那就不是聚类问题，而应转向逻辑回归、SVM、决策树等监督分类方法。

## 小结

K-means 可以概括成一句话：

- **先假设分成 K 组，再通过“最近质心分配 + 平均值更新质心”的反复迭代，让每组内部尽量相似。**

它最大的优点是简单、快速、可解释；最大的限制是必须先给 `K`，而且对离群点和复杂簇形状比较敏感。

如果你要的是一个干净、直观、适合做 baseline 的聚类方法，K-means 往往是很好的第一候选。
