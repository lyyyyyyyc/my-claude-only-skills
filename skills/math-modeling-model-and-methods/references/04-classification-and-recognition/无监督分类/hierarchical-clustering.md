# 层次聚类（Hierarchical Clustering）

> 用途：当用户已经判断问题属于“分类识别 / 聚类发现”方向，并且想进一步理解“层次聚类到底在看什么”“凝聚式和分裂式有什么区别”“为什么树状图能表达层次关系”时，读取本文件。
>
> 说明：本文件重点不是把教材步骤机械罗列，而是把层次聚类整理成“数模里能选方法、写论文、解释树状图”的参考模块。

## 这份文档适合什么时候看

- 你还不确定该把样本分成几组，想先看整体层次结构。
- 你关心的是“哪些样本先合并、哪些样本更接近”，而不是只关心最终固定分组。
- 你需要用树状图展示数据的分层关系。
- 你想比较层次聚类与 K-means 的差异，判断哪种更适合题目。

## 一句话先判断它适不适合这题

- **如果你更关心样本之间的层次关系，而不是先固定簇数，层次聚类往往值得优先进入候选。**
- **如果你希望最终分组数量可以后置决定，而不是一开始就锁定，层次聚类通常比 K-means 更自然。**
- **如果数据量特别大、计算效率要求特别高，层次聚类往往不如 K-means 轻便。**

## 1. 先把层次聚类想成什么

层次聚类可以理解成一种“把样本之间的亲疏远近画成家谱树”的方法。

它不是一开始就告诉你“分成 3 类还是 5 类”，而是先通过不断合并或不断分裂，把样本之间的层次关系全部表示出来，最终形成一个树状结构（dendrogram）。

因此，层次聚类最有特点的地方是：

- 它不仅给出“分组结果”；
- 还给出“这些组是怎么一步步形成的”。

对数模来说，这种方法特别适合：

- 先探索样本结构；
- 再根据业务需求决定切成几类；
- 并用树状图解释分类依据。

## 2. 两大主流方向：自底向上与自顶向下

层次聚类主要有两条路线：

### 2.1 凝聚式层次聚类（Agglomerative / AGNES）

- 从“每个样本都是一个小簇”开始；
- 每次找到最相似的两个簇，把它们合并；
- 一直合并，直到所有样本都并成一个大簇。

它是典型的“自底向上”。

### 2.2 分裂式层次聚类（Divisive / DIANA）

- 从“所有样本先看成一个大簇”开始；
- 每次把当前最不均匀的大簇继续拆开；
- 一直分裂，直到每个簇都足够小，甚至只剩一个样本。

它是典型的“自顶向下”。

如果只想先有一个直观印象，可以这样记：

- **AGNES 是“从点到树”地往上合并。**
- **DIANA 是“从树到点”地往下拆分。**

## 3. 凝聚式层次聚类（AGNES）怎么工作

AGNES 的标准流程可以整理成下面这条线：

1. 先把每个样本都当成单独一个簇。
2. 计算所有簇之间的距离。
3. 找到距离最近的两个簇。
4. 合并这两个簇。
5. 重新计算新簇与其他簇之间的距离。
6. 重复上面过程，直到满足停止条件。

这里最核心的问题不是“会不会合并”，而是：

- **簇之间的距离怎么定义？**

常见簇间距离定义有：

- 单链接（single linkage）：取两个簇中最近点之间的距离；
- 全链接（complete linkage）：取两个簇中最远点之间的距离；
- 平均链接（average linkage）：取两簇所有点对距离的平均值；
- Ward 法：以簇内方差增量最小为合并标准。

因此，层次聚类不是只有一个固定答案，它会受“链接方式”影响。

## 4. 一个通俗例子：按身高做 AGNES

假设有 5 个学生，他们的身高分别是：

| 学生 | 身高（cm） |
|---|---:|
| 学生1 | 160 |
| 学生2 | 170 |
| 学生3 | 180 |
| 学生4 | 150 |
| 学生5 | 165 |

### 第一步：计算两两距离

由于这里只有一个指标“身高”，欧几里得距离就是：

```latex
d(x, y) = \sqrt{(x-y)^2} = |x-y|
```

所以关键距离为：

- 学生1 和 学生5：`|160-165| = 5`
- 学生2 和 学生5：`|170-165| = 5`
- 学生1 和 学生2：`|160-170| = 10`
- 学生2 和 学生3：`|170-180| = 10`
- 学生1 和 学生4：`|160-150| = 10`
- 学生3 和 学生4：`|180-150| = 30`

### 第二步：先合并最近的两个样本

最小距离是 `5`，因此最先可能发生的合并是：

- 学生1 与 学生5 合并；
- 或 学生2 与 学生5 合并。

这说明在层次聚类中，如果存在并列最小距离，不同实现可能出现不同但都合理的合并顺序。

为了演示清楚，这里假设先合并：

- 簇 A = `{学生1, 学生5}`

### 第三步：重新计算簇距离

如果采用**单链接法**，则新簇与其他样本的距离取“最近那一对”的距离。

例如：

```latex
d(\{160,165\}, 170) = \min(|160-170|, |165-170|) = 5
```

```latex
d(\{160,165\}, 150) = \min(|160-150|, |165-150|) = 10
```

```latex
d(\{160,165\}, 180) = \min(|160-180|, |165-180|) = 15
```

于是接下来，簇 A 往往会优先和学生2再合并，因为距离仍然最小。

### 第四步：继续合并

这样会得到：

- 簇 B = `{学生1, 学生5, 学生2}`

之后再和学生4或学生3比较。由于这里会出现并列距离，后续合并顺序可能继续存在分支，但整体趋势很清楚：

- `160, 165, 170` 会更早聚在一起；
- `150` 与这个群体仍相对较近；
- `180` 往往在较后阶段再并入。

### 这个例子真正想说明什么

重点不在于每一步唯一顺序，而在于：

- 层次聚类会把“谁先靠近谁”完整记录下来；
- 这种记录最后能画成树状图；
- 你可以在不同高度把这棵树切开，从而得到不同的簇数。

## 5. 分裂式层次聚类（DIANA）怎么理解

DIANA 的思路与 AGNES 相反。

它不是从很多小簇往上并，而是从一个大簇往下拆。

标准理解可以写成：

1. 先把所有样本视作一个总簇。
2. 找出内部差异最大的部分。
3. 把这个大簇拆成两个子簇。
4. 对仍然内部不均匀的簇继续分裂。
5. 重复，直到达到停止条件。

因此，DIANA 更像在做：

- “这个大群体内部到底应该先裂成哪两部分？”

而不是：

- “当前哪两个小点最应该先合并？”

## 6. DIANA 的优点和代价

### 优点

- 对于差异明显的大群体，往往能比较早地切出主要分支。
- 有时更适合表达“一个总体先分成几个大类”的结构。

### 代价

- 计算复杂度通常更高；
- 每次分裂都要分析簇内结构，处理大样本时代价明显；
- 当簇形状复杂、边界模糊时，也不一定稳定。

所以在实际数模里，DIANA 常被当作“理论上重要、概念上清晰”的方法，但真正落地时，AGNES 更常见。

## 7. 层次聚类和 K-means 的核心区别

### 7.1 是否要先给簇数

- K-means：通常一开始就要先给 `K`。
- 层次聚类：可以先构树，再决定在哪一层切开。

### 7.2 输出形式

- K-means：更强调最终分组与簇中心。
- 层次聚类：更强调样本的层次关系与合并 / 分裂路径。

### 7.3 计算效率

- K-means：通常更快，更适合大样本 baseline。
- 层次聚类：通常更重，但结构解释更强。

### 7.4 可解释方式

- K-means 的可解释性主要来自“质心代表组特征”。
- 层次聚类的可解释性主要来自“树状图表达了谁和谁先靠近、谁属于哪一层结构”。

## 8. 层次聚类的优点

- 不必一开始就固定簇数。
- 能完整展示层次结构。
- 树状图在论文中有很强的展示价值。
- 对探索性分析很有帮助，尤其适合先看数据结构再决定分组方案。
- 原理相对直观，通常比较容易向读者解释“为什么这样分层”。
- 某些链接方式可以探索非球形结构，但不能因此无条件声称层次聚类适合所有不规则形状；结果仍由距离和链接方式决定。

## 9. 层次聚类的缺点

- 计算复杂度通常较高，不适合特别大的数据集。
- 结果会受距离度量和链接方式影响。
- 一旦合并或分裂发生，很多实现里后续不会回退，因此早期错误可能影响后续结构。
- 如果数据中噪声很强，树状结构可能被干扰。
- 层次聚类不会像 DBSCAN 那样显式把噪声点剔除出去，孤立点有时可能被单独并成一小簇。
- 合并操作不能撤销。
- 需要明确树状图切割高度或最终簇数；如果切割规则不清，容易把任意可视化选择误写成自然分类。

## 10. 距离、链接方式与关键参数

常见链接方式可写为：

单链接：

\[
d_{single}(A,B)=\min_{a\in A,b\in B}d(a,b)
\]

全链接：

\[
d_{complete}(A,B)=\max_{a\in A,b\in B}d(a,b)
\]

平均链接：

\[
d_{average}(A,B)=\frac{1}{|A||B|}\sum_{a\in A}\sum_{b\in B}d(a,b)
\]

Ward 方法通常以合并造成的簇内平方和增量为依据，常规实现通常要求欧氏距离；不要把 Ward 和任意距离度量无条件组合。

若 `A`、`B` 的样本数分别为 `|A|`、`|B|`，质心分别为 `\mu_A`、`\mu_B`，Ward 合并代价常写为：

\[
\Delta_{Ward}(A,B)=\frac{|A||B|}{|A|+|B|}\lVert\mu_A-\mu_B\rVert_2^2
\]

它选择使簇内平方和增量较小的合并，不等于“所有数据都应使用 Ward”。

| 参数 | 作用 | 选择注意 |
|---|---|---|
| `linkage` | `single`、`complete`、`average`、`ward` 等 | 用题目结构解释，不要写成普遍最优 |
| `metric` | 样本间距离 | 必须和特征类型、尺度及 linkage 兼容 |
| `n_clusters` | 最终切出的簇数 | 可由树状图、指标和业务解释确定 |
| `distance_threshold` | 树状图切割高度 | 与 `n_clusters` 通常二选一，按实现规则设置 |
| 树状图切割高度 | 后置分组边界 | 需要说明为何在该高度切开 |

使用注意：

- 单链接容易产生链式效应；全链接可能偏向紧凑簇；平均链接是折中方案。
- 聚类合并通常不可撤销，早期距离或噪声影响可能传递到后续结构。
- 层次聚类常见时间/空间成本为 `O(n^2)` 量级或与实现相关的近似量级；样本量大时必须评估内存和运行时间。
- 结果依赖距离、链接方式、标准化和异常值处理；至少做一组敏感性比较。
- 任何参数范围、样本量条件或切割高度都只是经验起点，必须结合当前数据验证，不能写成绝对阈值。

## 11. 数模里怎么把它写进论文

如果最终采用层次聚类，论文里通常要说明四件事：

1. 为什么该问题属于无监督分组问题。
2. 为什么需要层次结构而不是直接固定簇数。
3. 采用了哪种距离度量与链接方式。
4. 树状图是如何切分成最终类别的。

一个比较自然的表述可以写成：

> 由于题目未提供现成类别标签，且研究目标不仅在于获得样本分组结果，还希望分析样本之间的层次相似关系，因此本文采用层次聚类方法对样本进行聚类分析。该方法通过逐步合并相近样本（或逐步分裂大簇），构建树状图结构，从而在不同聚类层级下观察样本的分群规律。与需要预先指定簇数的 K-means 相比，层次聚类更适合用于探索样本的层次结构与自然分组边界。

## 12. 常见误判风险

- 把树状图当成“唯一分类真相”，而不说明切分阈值依据。
- 只说用了层次聚类，却不说明采用的是单链接、全链接还是平均链接。
- 数据量很大时仍直接套层次聚类，却不讨论计算成本。
- 只画树状图，不解释“为什么在这一层切开”。

## 13. 什么时候建议优先看别的方法

- 如果你已经明确知道大概要分几类，并且更在意效率，优先考虑 `k-means.md`。
- 如果任务其实是有标签后的监督识别问题，应转向逻辑回归、决策树、SVM 等监督分类方法。
- 如果数据中存在明显复杂密度结构，也需要谨慎评估层次聚类是否足够稳定。

## 小结

层次聚类可以概括成一句话：

- **它先把样本之间的亲疏关系组织成一棵树，再由你决定在什么层级上切开得到最终分组。**

它最大的优势是结构表达强、可后置决定簇数；最大的代价是计算更重、结果更依赖距离和链接方式。

如果题目更强调“分层关系”“自然分组结构”“树状图解释”，层次聚类通常比 K-means 更值得优先考虑。
