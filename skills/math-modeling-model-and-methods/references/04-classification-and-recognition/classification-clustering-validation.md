# 分类与聚类验证、稳定性与报告

> 本文件负责评价指标、概率质量、聚类内部/外部指标和稳定性检查。它不替代画图 SKILL 生成图形，也不替代超参数调优 SKILL 执行搜索。

## 1. 分类评价指标

二分类混淆矩阵包含 `TP`、`TN`、`FP`、`FN`。常用指标为：

\[
\operatorname{Precision}=\frac{TP}{TP+FP}
\]

\[
\operatorname{Recall}=\frac{TP}{TP+FN}
\]

\[
F_1=\frac{2\cdot\operatorname{Precision}\cdot\operatorname{Recall}}
{\operatorname{Precision}+\operatorname{Recall}}
\]

\[
\operatorname{Balanced\ Accuracy}=\frac{TPR+TNR}{2}
\]

其中 `TPR=Recall`，`TNR` 为特异度。实际计算中分母为 0 时要明确处理规则，不能静默产生无意义的数值。

### 按任务选择指标

| 任务重点 | 主指标候选 | 辅助报告 |
|---|---|---|
| 类别大致均衡、错误代价相近 | Accuracy、Macro-F1 | 混淆矩阵、每类 Precision/Recall |
| 类别不平衡 | Macro-F1、Balanced Accuracy、PR-AUC | 少数类 Recall/Precision、混淆矩阵 |
| 关注漏检 | Recall、PR-AUC | Precision、阈值敏感性 |
| 关注误报 | Precision | Recall、阈值敏感性 |
| 需要多分类整体表现 | Macro-F1、Weighted-F1 | 每类指标、混淆矩阵 |
| 需要概率 | LogLoss、Brier Score | 校准曲线、可靠性表 |

不要把 ROC-AUC 在极度不平衡场景下当成唯一结论；PR-AUC 常更能反映少数正类识别能力。

### 多分类与补充指标口径

- `Macro` averaging 对每个类别等权，适合关注少数类；`Weighted` averaging 按类别支持数加权，可能被多数类主导；`Micro` averaging 汇总所有样本，适合整体实例层面评价。
- 多分类报告至少说明使用了 Macro-F1、Weighted-F1 或 Micro-F1 中的哪一种，并给出混淆矩阵或每类 Recall。
- 特异度为 `TNR=TN/(TN+FP)`；类别不平衡且关注负类识别时，应同时报告它或 Balanced Accuracy。
- MCC（Matthews Correlation Coefficient）适合二分类不平衡场景作为补充，但不能替代按业务代价选择主指标。
- ROC-AUC 关注排序区分能力，PR-AUC 更关注正类稀少时的 Precision-Recall 权衡；二者都不直接代表阈值下的最终业务效果。

## 2. 概率校准与阈值

- 分类概率应在独立的验证流程中检查校准，而不是只看排序指标。
- 校准器只能用训练折拟合基础模型，再用独立验证集或 out-of-fold 预测拟合；最终测试集不能参与校准器训练。
- 阈值选择与概率校准是两个不同步骤：前者决定标签分界，后者检查概率是否具有频率意义。
- SVM 的间隔分数、树模型的原始分数和阈值输出不能无条件称为概率。
- 多分类不能只校准一个“正类”；应检查各类别概率和整体多分类 LogLoss/Brier，必要时采用适合多分类的校准方案。
- 阈值选择必须在训练/验证阶段完成，测试集只用于最终报告。
- 如果输出用于资源分配或风险排序，应同时报告阈值前后的指标变化。

## 3. 聚类内部评价

### 3.1 轮廓系数

对样本 `i`，令 `a(i)` 为它与同簇其他样本的平均距离，`b(i)` 为它与最近其他簇样本的平均距离，则：

\[
s(i)=\frac{b(i)-a(i)}{\max\{a(i),b(i)\}}
\]

整体轮廓系数通常取有效簇样本的平均值，但 DBSCAN 的噪声点是否排除必须明确；把噪声当作普通簇会扭曲距离。它偏好紧凑且分离的簇，但对距离定义、簇数量、噪声点和簇规模不平衡敏感。

### 3.2 其他内部指标

- Davies–Bouldin 指数：越小通常表示簇内紧凑、簇间分离更好。
- Calinski–Harabasz 指数：越大通常表示组间离散相对组内离散更强。
- K-means 的簇内平方和 `J(K)` 会随 `K` 增大而下降，不能单独用它选最优 `K`。
- DBSCAN 必须额外报告噪声比例、有效簇数量和是否存在极小簇；不能只报告轮廓系数。

## 4. 有真实标签时的外部指标

如果聚类只是用于探索，但事后拥有参考标签，可以报告：

- ARI（Adjusted Rand Index）：校正随机一致性的分组相似度；
- NMI（Normalized Mutual Information）：聚类标签与参考标签的归一化互信息。

有外部标签时也不能只报一个指标；需要说明参考标签的来源、是否参与了算法选择，以及是否存在标签与特征泄漏。

## 5. 稳定性分析

### 5.1 分类稳定性

- 更换分层折或随机种子，观察 Macro-F1、Recall、PR-AUC 和概率校准的波动。
- 报告均值、标准差或置信区间，不要只报告最佳折。
- 比较特征重要性排序是否稳定；单次树模型的 Gini importance 不宜直接作为最终解释。
- 对小样本，优先报告重复交叉验证结果，明确随机性来源。

### 5.2 聚类稳定性

- K-means：多随机初始化、多随机种子、重采样或轻微扰动。
- DBSCAN：改变 `eps`、`min_samples`，观察簇数和噪声比例。
- 层次聚类：改变链接方式、距离度量或树状图切割高度。
- BIRCH：改变压缩阈值并比较压缩后簇画像。

可报告：

- 第一名/主要簇是否保持；
- 簇数和噪声比例范围；
- 对象两两共聚率；
- 不同运行结果间的 ARI/NMI 或其他一致性指标；
- 结论在不同预处理和参数下是否改变。

## 7. 验证中的禁止事项

- 用测试集反复选模型、特征、阈值或聚类参数。
- 把 Accuracy、轮廓系数或一次最优运行当成充分证据。
- 把聚类内部指标写成监督分类准确率。
- 把特征重要性写成因果影响。
- 只报告最终数字，不报告划分、参数、随机种子和预处理范围。
