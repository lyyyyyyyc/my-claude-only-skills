# SVM

> 说明：本文件只整理本次截图中可以明确辨认的内容；看不清的句子未纳入正文。

## 截图中可明确辨认的核心描述
- 通过核函数将数据映射到高维空间。

## 优点
- 可以解决高维问题。
- 解决小样本机器学习问题。
- 可以处理非线性特征的相互作用。
- 无局部极值问题（相较于神经网络）。
- 无需依赖整个数据。
- 泛化能力强。

## 局限与边界
- 当样本多时，效率不高。
- 对于非线性问题，准确度依赖核函数的选择。
- 对核函数的高维映射解释能力不强，尤其是 `RBF`。
- 常见于二分类；多分类可通过 One-vs-Rest 或 One-vs-One 组合，但性能和成本取决于类别数、核函数及数据规模。
- 对缺失数据敏感。

## 适用场景
- 一般用于数据量不太大的二分类场景。
- 高维小样本、边界可能非线性且可以接受参数搜索的任务。

## 核心公式

软间隔线性 SVM 的一个标准形式为：

\[
\min_{w,b,\xi}\ \frac{1}{2}\lVert w\rVert_2^2+C\sum_{i=1}^{N}\xi_i
\]

约束为：

\[
y_i(w^T x_i+b)\ge 1-\xi_i,\qquad \xi_i\ge0
\]

RBF 核常写为：

\[
K(x_i,x_j)=\exp\left(-\gamma\lVert x_i-x_j\rVert_2^2\right)
\]

其中 `C` 控制间隔与训练误差的权衡，`gamma` 控制 RBF 的局部影响范围。

## 关键超参数与初始搜索

以下范围只是经验起点，必须在训练/验证流程中按数据规模和指标验证，不是绝对阈值。

| 参数 | 作用 | 建议起点 |
|---|---|---|
| `kernel` | 线性、RBF 或多项式核 | 先比较 `linear` 与 `rbf` |
| `C` | 误分类惩罚 | `10^{-2}`～`10^3` 对数搜索 |
| `gamma` | RBF 的影响范围 | `scale` 或 `10^{-4}`～`10^1` 对数搜索 |
| `degree` | 多项式核次数 | 仅使用多项式核时搜索 2～5 |
| `class_weight` | 类别不平衡权重 | 普通；不平衡时尝试 `balanced` |
| `probability` | 是否拟合概率 | 只有确实需要概率时开启，并另做校准检查 |

## 使用注意

- SVM 对特征尺度敏感，通常应在训练折中标准化；不要对全数据提前拟合 scaler。
- `C` 太大可能追求训练集低误差，`gamma` 太大可能形成过于局部的边界；两者应联合验证。
- SVM 的 decision score 不是天然概率；开启概率选项也不能替代校准和独立验证。
- 样本数很大时训练和预测成本可能较高；不要把“小样本优势”扩写成所有规模都适用。
- 多分类通常由 One-vs-Rest 或 One-vs-One 组合完成，需报告多分类策略和 Macro-F1。
- 缺失值处理、类别编码和异常值规则由预处理 SKILL 负责，但必须在训练数据中拟合。
