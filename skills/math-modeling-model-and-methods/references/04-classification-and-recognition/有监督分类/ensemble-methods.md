# 树模型集成方法

> 说明：本文件只整理本次截图中可以明确辨认的内容；看不清的句子未纳入正文。

## 随机森林
- 每颗树的分类强度越大，则随机森林的分类性能越好。
- 树之间的相关度越大，则随机森林的分类性能越差。
- 随机森林常用较深的基树来降低偏差，但仍需通过深度、叶节点和特征采样控制过拟合，不能主动追求训练集过拟合。
- 具有较好的准确率。
- 训练可以高度并行化，能够有效地运行在大数据集上，提高运行速率。
- 能够处理具有高维特征的输入样本，而且不需要降维。
- 能够评估各个特征在分类问题上的重要性。
- 对部分特征的缺失不敏感。
- 采用有放回随机抽样，训练出来的模型方差小，泛化能力强。
- 取值比较多的特征对 `RF` 的决策会产生更大的影响，有可能影响模型的效果。
- 在某些噪声比较大的特征上，`RF` 模型还是容易陷入过拟合。
- 适用于高维数据，以及准确率要求较高的场景。

### 随机森林的关键参数

| 参数 | 作用 | 建议起点 |
|---|---|---|
| `n_estimators` | 树的数量 | 200～1000，观察 OOB/验证结果是否趋稳 |
| `max_depth` | 单树最大深度 | `None` 或 3～20 |
| `min_samples_split` | 内部节点最少分裂样本数 | 2～20 |
| `min_samples_leaf` | 叶节点最少样本数 | 1～10 |
| `max_features` | 每次分裂的候选特征数 | `sqrt`、`log2` 或比例 |
| `class_weight` | 类别权重 | 不平衡时尝试 `balanced` |
| `bootstrap` | 是否有放回抽样 | 通常为 `True` |
| `oob_score` | 是否计算袋外估计 | 可作内部参考，但不能替代独立测试集 |

### 随机森林的解释边界

- 随机森林通过降低基学习器相关性和集成方差提高稳定性；“每棵树自由生长”不是必须规则，仍可用深度和叶节点参数控制过拟合。
- Gini importance 可能偏向取值多或尺度结构特殊的特征；必要时补充 permutation importance 或 SHAP。
- OOB 是内部泛化估计，不等于最终测试集成绩。
- 树模型通常不依赖标准化，但缺失值、类别编码、目标泄漏和 ID 列仍需由预处理流程处理。

若第 `b` 棵树的预测为 `h_b(x)`，随机森林的多数投票可以抽象写为：

\[
\hat y=\arg\max_{c\in\mathcal C}\sum_{b=1}^{B}\mathbf{1}\{h_b(x)=c\}
\]

表中的树数、深度和叶节点范围只是经验起点，必须在训练/验证流程中按数据规模和指标验证，不是绝对阈值。

## Bagging
- 将若干个弱分类器的分类结果进行投票选择，从而组成一个强分类器。
- Bagging 通过降低基学习器的方差改善了泛化误差。
- 对于噪声数据，装袋不太受过拟合的影响。

## Boosting
- 跟 Bagging 类似也是一种把若干个基学习器整合为一个学习器的方法。
- 是一个顺序过程，每个后续模型都会尝试纠正此前模型的错误。后续的模型依赖于之前的模型。
- 与 Bagging 的区别：Boosting 是串联，Bagging 是并联。
- 可以灵活地处理各种类型的数据，无论连续还是离散。
- 使用一些健壮的损失函数，例如 `Huber` 或 `Quantile` 时，对异常值的容忍度非常强。
- 充分考虑每个学习器的权重。
- 一般情况下，对异常样本比较敏感。

## 经验性补写（非截图原文）

- 通过组合多个弱学习器，通常可以取得较高的准确率。
- 善于利用弱学习器进行级联，后一个学习器在前一个学习器基础上继续修正误差。

## GBDT
- 使用 `CART` 中的回归树，无论是分类问题还是回归问题。
- 几乎可用于所有回归问题（线性 / 非线性），亦可用于二分类问题（设定阈值，大于阈值为正例，反之为负例）。
- 不太适合做多分类问题，一般在多分类场景缺乏解释性。

## XGBoost
- 某些具体实现可以学习缺失值的默认分裂方向；这不是所有 GBDT/XGBoost 实现的无条件性质，仍需确认实现和数据处理方案。
- 可以引入阈值限制树的分裂，防止过拟合。
- 分裂依据分开后与未分前的差值增益，不用每个节点排序算增益，减少计算量。
- 可以并行计算。
- XGBoost 属于带正则化的梯度提升树；它可以使用行/列子采样，但不能因此称为“随机森林的特殊 GBDT”。
- 参数过多。
- 预测类别过多时，容易过拟合。
- 适用于回归和分类场景，类别过多的效果可能不太好。

## XGBoost 的核心公式

第 `t` 轮加入基学习器 `f_t` 时，可用二阶近似表示目标：

\[
\mathcal{L}^{(t)}\approx\sum_i\left[g_i f_t(x_i)+\frac{1}{2}h_i f_t(x_i)^2\right]+\Omega(f_t)
\]

常见树复杂度正则项为：

\[
\Omega(f_t)=\gamma T+\frac{1}{2}\lambda\sum_{j=1}^{T}w_j^2
\]

对叶节点 `j`，记梯度和为 `G_j`、Hessian 和为 `H_j`，其简化最优权重为：

\[
w_j^*=-\frac{G_j}{H_j+\lambda}
\]

这些公式说明 XGBoost 同时控制损失下降和树复杂度；它不是“参数越多越强”的无条件最优模型。

### XGBoost 关键超参数

以下范围只是经验起点，必须在训练/验证流程中按数据规模和指标验证，不是绝对阈值。

| 参数 | 作用 | 建议起点 |
|---|---|---|
| `learning_rate` | 每棵树的步长 | 0.01～0.2 |
| `n_estimators` | 最大树数 | 200～2000，配合早停 |
| `max_depth` | 树深度 | 3～8 |
| `min_child_weight` | 子节点最小权重/样本约束 | 1～10 |
| `subsample` | 样本子采样比例 | 0.6～1.0 |
| `colsample_bytree` | 特征子采样比例 | 0.6～1.0 |
| `gamma` | 分裂所需最小增益 | 0～5 起步 |
| `reg_alpha` | L1 正则 | 0～若干对数值 |
| `reg_lambda` | L2 正则 | 1 起步并做敏感性检查 |
| `scale_pos_weight` | 正类权重 | 不平衡时按验证方案调整 |
| `early_stopping_rounds` | 验证集无改进时停止 | 必须配独立验证集 |

### 推荐调参顺序

1. 先用较浅树固定 `max_depth`，设置合理的 `learning_rate` 与较大 `n_estimators`。
2. 调整 `max_depth`、`min_child_weight` 控制单树复杂度。
3. 调整 `subsample`、`colsample_bytree` 降低相关性和过拟合。
4. 最后检查 `gamma`、`reg_alpha`、`reg_lambda` 和类别权重。
5. 使用验证集早停；测试集只做最终报告。

### 边界

- 小样本和高维数据下，XGBoost 很容易把噪声拟合成规则；复杂模型必须和简单 baseline 比较。
- 具体实现的缺失值自动分裂行为不能无条件外推到所有 GBDT 库。
- 特征重要性和高精度都不能直接解释为因果关系。
