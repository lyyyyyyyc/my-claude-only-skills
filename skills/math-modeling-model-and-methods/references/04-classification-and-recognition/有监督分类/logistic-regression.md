# 逻辑回归（Logistic Regression）

> 说明：本文件只整理本次截图中可以明确辨认的内容；看不清的句子未纳入正文。

## 截图中可明确辨认的核心描述
- 对线性预测量 `w^T x+b` 应用 `sigmoid`，把线性得分映射为二分类概率；它不是先拟合普通线性回归再简单相乘。
- 实现简单，广泛应用于工业问题上。
- 分类时计算量非常小，速度很快，存储资源低。
- 多重共线性会使系数方向和大小不稳定；L2 正则化可以缓解数值不稳定，但不能把共线性变成“不是问题”，也不能赋予系数因果含义。

## 经验性补写（非截图原文）

- 便于观察样本的概率分数，结果解释较为直观。

## 适用场景
- 适用于二分类场景，可以算出概率值。
- 适用于根据分类概率排序的领域，例如搜索排名。
- 经过 One-vs-Rest 或 Softmax 扩展后，也可用于多分类。

## 局限与边界
- 当特征空间很大或边界明显非线性时，表现取决于样本量、正则化和特征表示；可能欠拟合，但不能写成必然结论。
- 不能直接表达复杂非线性边界；可以通过交互项、非线性变换或其他模型补足。
- 特征强相关时系数方向和大小可能不稳定，正则化只能缓解，不能自动产生因果解释。
- 类别不平衡时默认 0.5 阈值可能不合适，需要结合代价和验证集调整。

## 核心公式

二分类设 `z=w^T x+b`，则：

\[
p(y=1\mid x)=\sigma(z)=\frac{1}{1+e^{-z}}
\]

交叉熵损失为：

\[
L=-\frac{1}{N}\sum_{i=1}^{N}\left[y_i\ln p_i+(1-y_i)\ln(1-p_i)\right]
\]

多分类 Softmax 为：

\[
p(y=c\mid x)=\frac{\exp(w_c^T x+b_c)}{\sum_{k=1}^{C}\exp(w_k^T x+b_k)}
\]

带正则化时可写为：

\[
L_{reg}=L+\lambda_1\lVert w\rVert_1+\lambda_2\lVert w\rVert_2^2
\]

## 关键超参数与初始搜索

以下范围只是经验起点，必须在训练/验证流程中按数据规模和指标验证，不是绝对阈值。

| 参数 | 作用 | 建议起点 |
|---|---|---|
| `C` | 正则化强度的倒数 | `10^{-3}`～`10^3` 对数搜索 |
| `penalty` | L1、L2 或 Elastic Net | 由特征稀疏性和求解器支持决定 |
| `class_weight` | 类别权重 | 普通；不平衡时尝试 `balanced` |
| `solver` | 优化求解器 | 按样本/特征规模和 penalty 选择 |
| `max_iter` | 最大迭代次数 | 先提高到足以收敛，再检查收敛警告 |
| 分类阈值 | 概率转标签的边界 | 默认 0.5；代价不对称时在验证集调整 |

## 使用注意

- 需要概率时检查校准；逻辑回归的概率也可能因正则化、类别不平衡和分布漂移而失真。
- 交叉验证中，标准化、特征选择和编码必须在训练折拟合。
- 多分类报告 Macro-F1、混淆矩阵和每类 Recall，不要只报告整体 Accuracy。
- 逻辑回归适合作为 baseline；是否优于非线性模型必须由同一验证方案比较。
