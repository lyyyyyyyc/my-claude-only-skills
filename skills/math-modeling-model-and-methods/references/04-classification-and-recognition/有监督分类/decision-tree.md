# 决策树

> 说明：本文件只整理本次截图中可以明确辨认的内容；看不清的句子未纳入正文。

## 截图中可明确辨认的总体特征
- 概念简单，复杂度不高，可解释性强，输出结果易于理解。
- 能够同时处理不同类型的数据，但具体类别特征和缺失值支持依赖实现与编码方式。
- 对特征尺度通常不敏感，也可以通过分裂忽略无关特征；缺失值不能无条件认为“不敏感”。
- 应用范围广，可扩展性强，可以提取数据规则。

## ID3
- 基于信息增益进行分裂。
- 信息增益来度量会偏向于取值较多的属性（有缺失值的会受影响）作为分类属性。
- 属性必须是离散的。

## C4.5
- 基于信息增益率进行分裂。
- 可以完成对连续数值的离散化处理。
- 可以处理属性缺失的情况。
- 构建完成后进行剪枝，避免过拟合问题。

## CART
- 全称分类回归树。
- 分类问题基于基尼指数进行分裂。
- 是一颗二叉树。
- 采取事后剪枝方法防止过拟合。
- 剪枝方法为 `CCP`（代价复杂度）剪枝。

## 适用场景
- 适合需要较高可解释性的场景。

## 分类树的核心公式

节点 `t` 中各类别比例为 `p_{tc}` 时，常用不纯度包括：

\[
G(t)=1-\sum_{c=1}^{C}p_{tc}^2
\]

\[
H(t)=-\sum_{c=1}^{C}p_{tc}\log p_{tc}
\]

若节点按比例 `p(t)` 分裂为左、右子节点，则基尼下降可写成：

\[
\Delta G=p(t)G(t)-p(t_L)G(t_L)-p(t_R)G(t_R)
\]

信息增益、信息增益率和代价复杂度剪枝可分别写为：

\[
IG=H(t)-\sum_{v}p(v\mid t)H(t_v)
\]

\[
GainRatio=\frac{IG}{-\sum_v p(v\mid t)\log p(v\mid t)}
\]

\[
R_\alpha(T)=R(T)+\alpha|\widetilde{T}|
\]

其中 `R(T)` 是经验误分类代价，`|T~|` 是叶节点数，`alpha` 控制复杂度惩罚。不同实现可能使用不同的剪枝细节。

ID3、C4.5 和 CART 的分裂准则不同，不能只写“决策树按信息增益分裂”概括所有实现。

## 关键超参数

以下范围只是经验起点，必须在训练/验证流程中按数据规模和指标验证，不是绝对阈值。

| 参数 | 作用 | 常用初始范围/选择 |
|---|---|---|
| `criterion` | `gini`、`entropy` 等不纯度准则 | 与论文公式保持一致 |
| `max_depth` | 限制树深度 | `None` 或 3～20，需验证 |
| `min_samples_split` | 节点继续分裂所需最少样本 | 2～20 |
| `min_samples_leaf` | 叶节点最少样本 | 1～10 |
| `max_features` | 每次分裂考虑的特征数 | `sqrt`、`log2` 或比例 |
| `ccp_alpha` | 代价复杂度剪枝强度 | 从 0 开始按验证结果增加 |
| `class_weight` | 类别不平衡权重 | 普通或 `balanced` |

## 适用范围与注意事项

- 树模型通常不要求标准化，但仍需要处理明显错误值、ID 列和数据泄漏。
- `max_depth` 太大、`min_samples_leaf` 太小容易过拟合；剪枝参数应在训练/验证流程中选择。
- 单棵树对样本扰动可能敏感；报告树深度、叶节点规模和稳定性。
- 决策路径具有解释性，但“分裂重要”不等于因果重要。
- 连续变量、类别变量和缺失值的具体支持依赖实现；不要把某一库的行为写成所有决策树算法的性质。

## 经验性补写（非截图原文）

- 基于决策树的算法通常都尽可能在处理数据的同时保留解释性。
