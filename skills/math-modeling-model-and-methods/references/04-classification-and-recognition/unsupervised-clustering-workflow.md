# 无监督聚类执行流程

> 本文件负责把“无标签数据的结构发现”推进到可复核的聚类方案。它不把聚类编号直接当真实类别，也不替代预处理和画图 SKILL 的具体执行。

## 1. 先确认聚类目标

先说明聚类是为了：

- 发现样本画像或自然分群；
- 压缩数据、构造后续特征；
- 识别异常/噪声点；
- 生成层级结构或树状图；
- 为后续监督模型、评价或优化提供分组变量。

目标不同，算法和评价方式不同。不要仅因“没有标签”就默认使用 K-means。

## 2. 聚类前的数据检查

记录：

- 样本量 `n`、特征数 `p`、特征类型；
- 缺失值、重复样本、极端值和常数列；
- 特征量纲、相关性和是否存在 ID 列；
- 采用的距离/相似度，以及它是否符合题目含义。

数值距离型方法通常需要先处理量纲差异。缺失值填补、异常值处理、类别编码和标准化交给 `math-modeling-data-preprocessing`；本流程只要求明确“采用了什么处理及其理由”。

## 3. 候选方法与初始参数

### K-means

- 适合：簇近似球形、大小和密度相近、需要质心解释、可以预估 `K`。
- 初始关注：`n_clusters`、`init=k-means++`、`n_init`、`max_iter`、`tol`、`random_state`。
- `K` 可由题意、肘部法、轮廓系数、稳定性和业务解释共同决定；不能只看某一张肘部图。

### DBSCAN

- 适合：未知簇数、复杂形状、需要噪声点识别，且簇的密度差异不是极端大。
- 初始关注：`eps`、`min_samples`、`metric`、邻域搜索算法。
- 通过 k-distance 曲线寻找 `eps` 候选，再结合噪声比例、簇数量和稳定性检查；`MinPts≈p+1` 只能作为经验起点。

### 层次聚类

- 适合：样本量较小、需要树状图、希望后置决定簇数或观察层级关系。
- 初始关注：`linkage`、`metric`、`n_clusters` 或 `distance_threshold`、切割高度。
- 先固定距离和链接方式，再比较切割高度；不要在不同链接方式下直接比较未经说明的簇编号。

### BIRCH

- 适合：样本规模很大、希望先用聚类特征压缩数据，再进行后续聚类。
- 初始关注：`threshold`、`branching_factor` 和后续聚类器参数。
- 它是压缩式近似流程，不能自动保证复杂非球形结构被完整保留；需比较压缩前后的簇画像和稳定性。

## 4. 全量探索与下游建模的范围差异

### 4.1 纯探索性聚类

如果目标只是描述当前这批无标签样本的结构、画像或异常点，允许在全体数据上拟合聚类；此时应明确这是“全量探索”，不能把结果包装成对未来样本的泛化性能。

### 4.2 聚类结果要进入下游预测或测试评估

如果聚类标签、簇距离或簇画像会作为后续预测模型的特征，或需要在测试集上评估下游模型，则应遵守：

1. 只用训练范围拟合预处理、聚类参数和簇结构。
2. 在验证/测试范围只应用已经确定的变换或归属规则。
3. 对不能自然给新样本分配簇的算法（例如 DBSCAN、普通层次聚类），必须明确采用的归属策略，或把聚类限制为训练集探索变量；不能先用全量数据选簇再把标签当作无泄漏特征。
4. 聚类参数、标准化参数、降维参数和异常值规则都必须在测试集之外确定。

字段“数据划分方案”在纯探索任务中可填写“不适用/全量探索”；在下游任务中必须写清训练拟合范围和验证/测试归属方式。

## 5. 建议执行顺序

1. 去除明显 ID、常数列和重复记录，记录处理规则。
2. 完成必要的缺失值、异常值、编码和尺度处理。
3. 用低维投影或其他图形探索工具观察大致形状；图形由画图 SKILL 负责生成。
4. 选择 2～3 个有明确理由的候选算法，而不是无目的地穷举。
5. 对每个候选做参数网格或合理范围的敏感性检查。
6. 报告簇数量、噪声比例、簇规模、簇画像和内部指标。
7. 用多随机种子、重采样或扰动数据检查结果稳定性。
8. 结合业务解释判断簇是否有意义；若没有真实标签，不要把内部指标直接称为“分类准确率”。

## 6. 聚类稳定性最小方案

至少改变一项可能影响结果的因素：

- K-means 的随机初始化或随机种子；
- 样本重采样或轻微扰动；
- 标准化方式、距离度量或异常值处理规则；
- DBSCAN 的 `eps`、`min_samples`；
- 层次聚类的链接方式或切割高度。

比较结果时可报告：簇数变化、噪声比例变化、对象两两共聚率、ARI/NMI（有外部标签时）或不同划分间的调整兰德一致性。不要只看某一次运行得到的簇编号是否“看起来合理”。

## 7. 聚类结果解释

对每个簇至少给出：

- 样本数量及占比；
- 各指标的中心趋势或分布特征；
- 与其他簇相比最明显的差异；
- 典型样本、边界样本和噪声样本；
- 该簇在题目背景中的可能含义和不能推出的结论。

聚类编号本身没有顺序和大小意义；如果需要“高/中/低”等名称，必须依据可解释的指标规则后处理。

## 8. 常见错误

- 把聚类标签直接当成真实类别或因果机制。
- 没有标准化就用欧氏距离，或没有解释为何采用其他距离。
- K-means 只用肘部法决定 `K`。
- DBSCAN 只报告 `eps`，不报告 `min_samples`、噪声比例和 k-distance 依据。
- 层次聚类只画树状图，却不说明链接方式和切割高度。
- 用单一内部指标宣称“聚类最优”。
- 忽略空簇、极小簇、噪声比例过高或簇规模极不平衡。
- 把经验条件写成绝对阈值。
