# 有监督分类执行流程

> 本文件负责把监督分类从“选方法”推进到“可验证的实验方案”。预处理的具体实现交给 `math-modeling-data-preprocessing`，调参执行交给 `model-hyperparameter-tuning`；本文件只规定接口、顺序和不可省略的验证点。

## 1. 输入检查与任务定义

先记录：

- 特征矩阵 `X`、标签 `y`、样本量 `n`、特征数 `p`；
- 二分类/多分类、类别比例和误分类代价；
- 是否需要概率、阈值决策、排序、特征重要性或规则解释；
- 是否存在时间顺序、用户/地区/设备等群组依赖；
- 哪些列是 ID、时间、目标泄漏列或仅用于解释的字段。

不要把唯一标识符直接当普通特征，也不要在看见测试集结果后反复修改方法。

## 2. 数据划分：按任务需要选择方案

并不是所有模型都必须使用三份数据。关键是：凡是会从数据估计统计量、选择特征、选择模型或调超参数的步骤，都不能提前使用最终测试集信息。

### 2.1 只做固定 baseline、没有调参

可以使用：

```text
训练集 → 拟合模型
测试集 → 最终评估
```

这适合只想得到一个固定基线、没有根据验证结果反复选择参数的情况。训练集内部仍可做必要的诊断，但不要把测试集当调参集。

### 2.2 需要调参、模型比较或早停

优先使用以下任一方案：

```text
训练集 → 训练/交叉验证和调参
独立测试集 → 最终一次性评估
```

或：

```text
训练集 → 拟合
验证集 → 选择模型、阈值、早停轮数
测试集 → 最终一次性评估
```

只有在样本量足够、需要单独留出调参信息时才使用训练/验证/测试三分；小样本通常优先使用训练集内的分层交叉验证，并保留独立测试集。

### 2.3 特殊数据结构

- 类别标签不平衡：分类任务使用 `StratifiedKFold` 或分层划分；先确认每个折中都有关键类别。
- 时间数据：按时间顺序划分或使用滚动验证，不要随机打乱未来信息。
- 群组数据：同一用户、地区、设备或实验对象不能同时出现在训练和测试中，必要时使用 GroupKFold。
- 重复测量：同一对象的重复记录应按对象分组，否则模型可能记住对象而不是学习规律。
- 样本极少：报告划分随机种子、交叉验证折数和结果波动，不要只展示一次随机切分。

## 3. 防止预处理与特征工程泄漏

所有会从数据学习参数的操作，都必须在训练数据或训练折上拟合，再应用到验证/测试数据：

- 缺失值均值/中位数/众数填补；
- 异常值阈值、分位数、IQR 或稳健尺度；
- Min-Max、Z-Score、Robust Scaler 的参数；
- 类别编码映射；
- 目标编码、频率编码；
- 特征选择、PCA、降维和相关性筛选；
- 采样、SMOTE 或类别权重的选择；
- 概率校准器和分类阈值。

交叉验证时，预处理应放入同一 pipeline，使每个训练折独立拟合。不能先对全数据标准化、填补或做目标编码后再切分；这会让验证结果偏乐观。

## 4. 建模顺序

建议按以下顺序推进：

1. 先建立最简单的 baseline，例如多数类预测、逻辑回归或浅层决策树。
2. 根据数据结构加入一个或两个候选模型，不要一开始无目的地堆叠所有算法。
3. 在同一数据划分和同一指标体系下比较模型。
4. 再调用超参数调优 SKILL 做搜索；记录搜索空间、随机种子、折数、评分和最佳参数。
5. 如果模型使用早停，验证集必须独立于最终测试集；XGBoost 等模型的 `early_stopping_rounds` 不能用测试集承担。
6. 锁定模型和阈值后，最后只在测试集上报告一次主要结果。

## 5. 概率校准与阈值：两个不同步骤

分类分数、概率和标签是三个不同输出：

- `decision_function`、树模型原始分数和 margin 不一定是概率；
- 概率校准器必须只在训练/验证流程内拟合，校准集不能与最终测试集混用；
- 阈值选择和概率校准是两个不同步骤：校准解决“0.8 是否接近 80% 的发生率”，阈值解决“在什么分界点输出正类”；
- 默认阈值 0.5 不是普遍正确，类别不平衡或误判代价不对称时应根据验证集调整；
- 阈值和校准器都必须在测试集之前锁定，不能看测试集后反向修改。

### 可执行的校准流程

1. 在训练折中拟合基础分类器。
2. 用独立验证集，或用训练集内交叉验证产生的 out-of-fold 预测，拟合校准器；常见选择包括 Platt/sigmoid 和 isotonic，但应根据样本量和过拟合风险选择。
3. 在同一验证流程中检查校准曲线、LogLoss、Brier Score；二分类可检查可靠性，多分类需检查各类概率和整体多分类 LogLoss/Brier 或其他明确的多分类校准指标。
4. 在验证集上独立选择分类阈值；不要把“校准后的 0.5”当作必须使用的阈值。
5. 锁定基础模型、校准器和阈值后，测试集只做一次最终评估。

如果题目只需要类别标签，没必要为了输出概率强行增加校准步骤；如果题目需要风险排序、资源优先级或概率解释，则必须把校准作为验证环节。

## 6. 分类实验最小记录

每次模型实验至少记录：

```text
数据版本 / 划分方式 / 随机种子
预处理拟合范围
模型名称与关键超参数
训练方式与交叉验证方案
主指标与辅助指标
是否调阈值或校准概率
训练/验证/测试结果
混淆矩阵与类别级表现
运行时间、错误和异常说明
```

## 7. 常见失败模式

- 先看测试集指标，再决定特征、模型或阈值。
- 对全数据做标准化、填补、PCA 或目标编码后再交叉验证。
- 类别不平衡时只报告 Accuracy。
- 小样本只做一次随机划分，却把偶然结果写成稳定结论。
- 时间或群组数据随机切分，造成同一对象或未来信息泄漏。
- XGBoost 早停直接使用测试集。
- 使用未经校准的分数，却在论文中写成“预测概率”。
- 只报告最优参数，不报告搜索范围和验证方式。
