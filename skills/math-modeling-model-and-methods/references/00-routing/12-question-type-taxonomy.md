# 十二类问题本质识别

每个子问题必须先判定 `primary type`。具体算法、题型内方法、检验类别使用 `method subtype` 记录；混合问题必须另列有序执行阶段，不能把它们都塞进同一个类别字段。

| 类型 | 判断标准 | 常见输出 |
|---|---|---|
| 预测/回归 | 需要估计连续值、趋势、未来状态或拟合关系 | 连续数值、预测曲线、趋势判断 |
| 分类/判别 | 需要判断对象属于哪一类 | 离散类别、标签、判定结果 |
| 评价/排序 | 需要比较优劣、打分、排名、分级 | 得分、排名、等级、优劣顺序 |
| 优化/决策 | 需要在约束下选择最好方案 | 最优方案、调度、分配、路径、组合 |
| 机理/物理 | 结果由物理、化学、工程机理决定 | 状态量、方程解、机理参数 |
| 聚类/分组 | 没有标签，需要发现自然分组 | 聚类标签、层级划分、群组结构 |
| 关联/因果 | 需要解释变量关系、影响强度或因果证据 | 相关性、影响因子、因果推断 |
| 博弈/策略 | 多方竞争、对抗或策略互动 | 均衡策略、收益、竞争关系 |
| 几何/运动学 | 关注位置、轨迹、角度、覆盖、碰撞、投影 | 坐标、轨迹、几何关系 |
| 统计推断/实验设计 | 需要显著性、置信、抽样或试验条件 | 检验结论、置信区间、抽样方案 |
| 网络科学/图论 | 关注节点、边、路径、流、匹配、连通性 | 路径、流量、匹配、网络指标 |
| 生态系统/环境 | 关注种群、食物网、承载力、碳流、可持续性 | 动态模拟、环境评价、承载力 |

## 混合问题

混合问题必须写清“先做什么，后做什么”，并至少记录：`执行阶段顺序`、`每阶段产出物`、`下一阶段消费什么产出`、`验证责任`。

常见组合：

- 预测 + 优化：预测结果作为优化输入。
- 评价 + 优化：评价得分作为优化目标或约束。
- 聚类 + 分类：聚类标签作为分类训练标签。
- 机理 + 优化：机理模型输出作为优化目标或约束。
- 网络/图论 + 优化：图结构提供可行路径或约束空间，再做决策优化。
