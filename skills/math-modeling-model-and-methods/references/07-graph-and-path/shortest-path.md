>
> 说明：本文件把“最短路径问题”整理成数模里可选方法、可写论文、可解释边界的参考模块。当前重点放在 `Dijkstra`、`Floyd-Warshall` 和 `Bellman-Ford` 三种经典方法，不展开成整套图论教材。

## 这份文档适合什么时候看

- 你已经判断题目和“节点、边、权重、路程、代价、导航、网络路由”等词强相关。
- 你怀疑题目本质是“从一个点走到另一个点，总代价最小”。
- 你需要进一步缩小方法选择空间，判断到底该优先用 `Dijkstra`、`Floyd-Warshall` 还是 `Bellman-Ford`。
- 你后面准备把最短路写进论文、代码或建模说明，想先把基本逻辑和适用边界理顺。

## 一句话先判断它适不适合这题

- **如果题目核心是“路径代价最小”，而不是流量最大、成本流分配或巡回访问，那么最短路径通常就是第一候选。**
- **如果你只关心一个源点到其他点的最短路径，且边权非负，优先考虑 `Dijkstra`。**
- **如果你需要任意两点之间的最短路径矩阵，优先考虑 `Floyd-Warshall`。**
- **如果你关心单源最短路，但图中可能存在负权边，或者需要判断最短路是否不存在，那么 `Bellman-Ford` 应纳入候选。**

## 1. 先把最短路径问题想成什么

最短路径问题的核心不是“走得最少步”，而是：

- 在一个带权图中，
- 从起点到终点，
- 找到总代价最小的一条路径。

这里的“代价”可以是：

- 距离
- 时间
- 运费
- 风险
- 能耗

所以，最短路径本质是在做“路径代价最小化”，而不是简单的边数最少。

## 2. Dijkstra 算法

### 2.1 它适合什么问题

Dijkstra 最适合：

- **单源最短路径问题**

也就是说：

- 已经给定一个源点；
- 想求这个源点到其他所有节点，或者到某个目标节点的最短路径。

它的一个重要前提是：

- **图中边权必须是非负数。**

如果存在负权边，Dijkstra 就不再可靠。

### 2.2 核心思想

Dijkstra 是一个典型的贪心算法。  
它的基本逻辑是：

1. 先把源点到自己的距离设为 `0`，其他点设为 `∞`。
2. 每次从“还没确定最短路”的节点里，挑出当前距离最小的那个点。
3. 用这个点去更新它邻居的最短距离。
4. 一旦某个点被正式选出，就把它标记为已访问。
5. 重复这个过程，直到所有点都处理完，或者目标点已经确定。

它之所以高效，是因为：

- 每一步都把“当前最可靠的最短距离”先固定下来；
- 后面只围绕这个结果继续扩展。

### 2.3 标准步骤

可以整理成下面这条线：

1. 初始化：源点距离为 `0`，其他节点距离为 `∞`。
2. 在未访问节点中，选择距离源点最小的节点。
3. 更新这个节点所有邻居的距离：
   - 如果“经过当前节点”更短，就更新邻居距离。
4. 标记当前节点为已访问。
5. 重复 2-4，直到所有节点都访问完，或目标节点已确定。

### 2.4 一个通俗例子

设图中边权如下：

| 边 | 权重 |
|---|---:|
| A-B | 2 |
| A-D | 5 |
| B-C | 4 |
| B-E | 1 |
| C-F | 3 |
| D-E | 2 |
| E-F | 1 |

我们想求：

- 从 `A` 到 `F` 的最短路径。

#### 初始化

```text
d(A)=0, d(B)=∞, d(C)=∞, d(D)=∞, d(E)=∞, d(F)=∞
```

#### 第一步：从 A 出发

更新邻居：

```text
d(B)=2
d(D)=5
```

#### 第二步：选当前最小未访问节点 B

更新邻居：

```text
d(C)=2+4=6
d(E)=2+1=3
```

#### 第三步：选当前最小未访问节点 E

更新邻居：

```text
d(F)=3+1=4
```

#### 第四步：继续处理 D、C

- 处理 `D` 时，没有更优更新；
- 处理 `C` 时：

```text
d(F)=min(4, 6+3)=4
```

因此最终结果保持不变。

#### 最终结果

- 最短路径：`A → B → E → F`
- 最短距离：`4`

### 2.5 时间复杂度

若采用邻接表加堆优化，时间复杂度通常写为：

```text
O(E \log V)
```

其中：

- `E` 是边数；
- `V` 是节点数。

这也是它在稀疏图中非常常用的原因。

### 2.6 常见应用

- GPS 导航
- 网络路由
- 单源路径规划
- 交通线路最优选择

## 3. Floyd-Warshall 算法

### 3.1 它适合什么问题

Floyd-Warshall 最适合：

- **所有节点对之间的最短路径问题**

也就是说，它不是只求一个源点，而是一次性求：

- 任意两个节点之间的最短路径。

它还能处理：

- 含有负权边的图

但不能处理：

- **负权回路**

如果存在负权回路，那么“最短路径”本身会失去意义。

- 算法复杂度较高，要求最短路径必须存在（不能有负环）。
- 适用于任何图，无论有向无向，边权正负。

### 3.2 核心思想

Floyd-Warshall 是典型的动态规划算法。

它的思路不是“从一个源点往外扩”，而是：

- 逐步尝试把每个节点都当成“中介节点”；
- 看看经过这个中介节点之后，任意两点之间的路径会不会更短；
- 如果更短，就更新距离矩阵。

因此，它更像在做“全局路径表的不断松弛更新”。

### 3.3 标准步骤

可以整理成下面这条线：

1. 初始化距离矩阵：
   - 自己到自己为 `0`
   - 有边的地方填边权
   - 无边则为 `∞`
2. 依次枚举每个节点 `k` 作为中介节点。
3. 对所有节点对 `(i, j)`，检查：

```text
d(i,j) = min(d(i,j), d(i,k) + d(k,j))
```

4. 不断更新，直到所有中介节点都处理完。

### 3.4 它到底在做什么

如果只看一句话，可以理解成：

- **它通过不断加入中介节点，逐步改善任意两点之间的最短路径。**

和 Dijkstra 不同，它不是“单源扩张”，而是“全图同步更新”。

### 3.5 时间复杂度

Floyd-Warshall 的时间复杂度通常写为：

```text
O(V^3)
```

因此它更适合：

- 节点规模不算太大的图；
- 但你确实需要全源最短路矩阵的情形。

### 3.6 常见应用

- 全图最短路径分析
- 网络流量优化
- 交通网络整体分析
- 任意节点对间最短距离预计算

## 3.7 补充：Bellman-Ford

- `Bellman-Ford` 可以求出有负权的图的最短路，可以对最短路不存在的情况进行判断。
- 因此，如果题目仍是单源最短路，但图中可能存在负权边，或者需要显式判断“最短路是否存在”，就应把 `Bellman-Ford` 纳入候选。
- 它更适合：
  - 单源最短路；
  - 图中可能出现负权边；
  - 需要额外判断最短路是否存在的情形。

## 4. Dijkstra 和 Floyd-Warshall 的区别

| 特点 | Dijkstra | Floyd-Warshall |
|---|---|---|
| 适用场景 | 单源最短路径 | 所有节点对最短路径 |
| 边权要求 | 无负权边 | 可有负权边，但不能有负权回路 |
| 算法类型 | 贪心算法 | 动态规划 |
| 时间复杂度 | `O(E log V)` | `O(V^3)` |
| 空间复杂度 | `O(V+E)` 或相关实现规模 | `O(V^2)` |
| 输出结果 | 源点到其他点的最短路径 | 每对节点之间的最短路径 |
| 更适合的图 | 稀疏图、单源查询 | 较小图、全源查询 |

## 5. 什么时候选 Dijkstra

- 只关心一个源点；
- 图中边权非负；
- 图较稀疏；
- 希望运行效率更高。

一句话总结：

- **单源 + 非负权 + 稀疏图，优先 Dijkstra。**

## 6. 什么时候选 Floyd-Warshall

- 需要任意两点之间的最短路径；
- 图中可能存在负权边；
- 节点数量不算太大；
- 接受较高的 `O(V^3)` 复杂度。

一句话总结：

- **全源最短路 + 可能有负权边 + 图不大，优先 Floyd-Warshall。**

## 7. 常见混淆点与误判风险

- 图中一有“路径”就直接上 Dijkstra，但题目其实要求所有节点对结果。
- 图中有负权边却仍误用 Dijkstra。
- 图中有负权边且仍是单源最短路，却忽视了 `Bellman-Ford`。
- 图规模很大却硬用 Floyd-Warshall，导致复杂度过高。
- 把“最短路径问题”误写成“最大流 / 最小费用流”问题。

## 8. 一个论文里可直接使用的表述

如果采用 Dijkstra，可以写：

> 由于题目要求求解单源到其他节点的最短路径，且图中边权均为非负数，因此本文采用 Dijkstra 算法进行求解。该算法通过贪心策略逐步固定当前距离源点最近的未访问节点，并不断更新其邻居节点距离，从而高效得到源点到目标节点的最短路径。

如果采用 Floyd-Warshall，可以写：

> 由于题目要求计算图中任意两点之间的最短路径关系，且图中可能存在负权边，因此本文采用 Floyd-Warshall 算法进行求解。该算法通过动态规划思想，依次引入中介节点更新距离矩阵，从而得到所有节点对之间的最短路径结果。

## 小结

最短路径问题可以概括成一句话：

- **Dijkstra 负责“一个源点出发怎么走最短”，Floyd-Warshall 负责“任意两点之间怎么走最短”。**

如果你的任务是：

- 单源、非负权、稀疏图：优先 Dijkstra；
- 全源、允许负权边、图不大：优先 Floyd-Warshall。
- 单源、可能有负权边、还要判断最短路是否存在：把 `Bellman-Ford` 纳入候选。
