# 模型的检验与分析写作要求

## 这一部分写什么
- 本部分负责检验模型及其结果的精度、稳定性、可靠性、合理性和泛化能力，并解释误差、灵敏度与稳健性证据。
- 本部分固定作为正文第九部分，一级标题写为 `九、模型的检验与分析`。
- 只写实际执行过且有结果支撑的检验。没有真实实验记录时，应标记缺少的证据，不得补造误差、曲线、置信区间或稳健性结论。
- 本部分完成后进入第十部分“模型的评价、改进与推广”；后者引用本部分证据评价优缺点，不再重复完整检验过程。

## 模型检验怎么分
- 模型检验大致可分为两类：
  - 使用前检验
  - 结果检验
- `使用前检验` 指模型在正式使用之前应完成的前置检验，例如一致性检验、准则适配性检验等。
- `结果检验` 指模型建立并求解之后，对结果本身进行的稳定性、可靠性和合理性检查。
- 写作时要注意边界：前置检验通常更自然地写在“模型的建立与求解”部分；第九部分重点汇总结果检验、误差分析、灵敏度分析和稳健性分析。

## 检验章节放置规则
- 若问题一、问题二、问题三使用同一模型或同类模型，可在第九部分统一设置对应小节，在相同口径下比较各问参数变化对输出的影响。
- 若各问分别属于评价、预测、优化或机理分析等差异较大的模型，应在各自模型建立与求解部分完成专项检验，第九部分汇总关键方法、指标和结论，不强行重复同一套分析。
- 灵敏度分析优先用于决定最终结论、参数依赖较强或参数来源不确定的主要模型。其他模型可根据需要使用误差分析、交叉验证、稳定性检验或对比实验。
- 章节位置由模型之间的同质性和证据用途决定，不能为了形式完整让每个模型机械重复相同分析。

## 灵敏度分析
- 灵敏度分析研究模型输出对关键参数或周围条件变化的敏感程度。
- 灵敏度参数应依据以下标准筛选：对目标函数、约束或核心机理是否重要；参数来源或估计是否具有较大不确定性；参数变化是否可能改变主要结论、排序或最优方案。不得把所有参数不加区分地统一上下浮动 `10%`。
- 灵敏度分析按以下六步组织：
  1. 选择关键参数并说明选择原因；
  2. 确定基准值、符合现实的变化范围和步长或水平；
  3. 保持其他参数不变，对每个参数水平逐次重新训练、求解或评价；
  4. 记录关键输出，并绘制参数与结果之间的关系；
  5. 比较变化幅度，识别敏感参数、稳定区间和可能的阈值；
  6. 判断主要趋势、排序、最优方案或最终结论是否改变。
- 单因素分析一次只改变一个参数，适合解释单个参数的方向与影响强度；当参数交互作用不可忽略时，可根据问题规模与数据条件选择正交试验、响应面、网格搜索、蒙特卡洛模拟或 Sobol 指数分析，并说明为什么该方法适合当前问题。
- 可以使用相对灵敏度系数：

\[
S=\frac{\Delta Y/Y}{\Delta X/X},
\]

其中 \(X\) 为参数，\(Y\) 为关键输出。\(|S|\) 越大表示输出对参数越敏感；\(S>0\) 表示同向变化，\(S<0\) 表示反向变化。基准参数或基准输出接近零时，不直接使用该比值，应改用绝对变化、区间、局部斜率或其他稳定指标。

## 稳健性分析
- 稳健性分析用于判断在合理扰动下，主要趋势、排序、可行解和最优方案是否仍然成立。
- 可按题目实际情况扰动：输入数据、样本规模、缺失值或异常值处理方式、权重确定方法、模型初值以及关键假设条件。
- 每次扰动必须说明扰动对象、扰动幅度或替代方案、保持不变的条件和重新求解方式，并比较扰动前后的核心指标。
- 稳健性结论必须落到可观察结果，例如主要排序是否保持、最优方案是否改变、指标变化范围多大；不能只写“模型具有较好稳健性”。
- 可写为：“为检验模型结论的稳健性，本文分别对[输入数据 / 样本规模 / 处理方法 / 权重 / 初值 / 假设]进行[扰动幅度或替代方案]调整，并在其余条件保持一致时重新求解。结果显示，[核心指标]在[范围]内变化，[主要趋势 / 排序 / 最优方案]保持[不变或发生具体变化]，说明模型在[明确条件范围]内具有[相应程度]的稳健性。”

## 误差来源与定量报告
- 误差分析用于识别和估算模型中实际存在的误差，更常见于预测问题或数值计算类问题。
- 误差来源至少从实际存在的环节中识别：原始数据测量误差、缺失值和异常值处理误差、模型简化误差、参数估计误差、数值计算或随机算法误差，以及前一问题结果向后一问题传播的误差。
- 不得罗列与当前模型无关的全部误差类型；每项误差应对应到具体数据、假设、参数、算法步骤或跨问接口。
- 误差结果应尽量量化为平均误差、最大误差、误差范围或置信区间，并写清指标定义、单位、样本范围和计算口径；禁止只用“误差较小”“结果较准确”等定性表述代替证据。
- 存在跨问题传播时，应说明上游输出以参数、输入、约束、初始值或验证基线中的哪种形式进入下游，并评估该误差是否会改变下游结论。
- 可写为：“模型误差主要来自[具体来源]。采用[指标或区间估计方法]量化后，平均误差为[数值与单位]，最大误差为[数值与单位]，误差范围或置信区间为[区间]；该误差对[核心输出或后续问题]的影响表现为[具体变化]，因此[是否改变主要结论]。”

## 误差分析四段式写作模板
- 下面的四段式用于组织已有验证结果，不代表所有题目都必须使用 K 折交叉验证；先根据数据结构选择验证方案，再替换方括号内容。

### 第 1 段：引入验证目标
可写为：“为检验[模型 / 预测结果]在[数据结构或应用场景]下的[精度、稳定性或泛化能力]，本文采用[验证方案]进行检验。选择该方案是因为[数据独立同分布 / 存在时间顺序 / 存在群组结构 / 需要独立测试]。”

### 第 2 段：说明验证方法
- 使用 K 折时，说明 K 的取值、数据如何分折、每次如何训练和验证、重复次数以及误差指标口径；每次训练都不能使用当前验证折的信息。
- 时间序列使用时间顺序划分、滚动验证或扩展窗口；群组数据按组划分；确定性优化、非线性规划、粒子群或遗传算法根据是否调参选择训练 / 验证 / 测试方案，不为形式完整强行使用 K 折。
- 可写为：“按照[时间顺序 / 随机且分层 / 分组]将数据划分为[若干部分]，在每次训练中仅使用训练部分，并在未参与该次训练的验证部分计算[指标]，最后汇总各次结果。”

### 第 3 段：展示验证结果
- 用表格列出各折、各时间窗口或各组的误差，并报告均值、标准差、样本范围和指标单位；只有确实使用交叉验证时才称为“各折结果”。
- 如需使用变异系数，写清定义和分母口径；当平均误差接近零、误差可正负抵消或指标不适合比值表达时，不用 CV 进行判断。
- 配套图表可包括误差分布图、训练 / 验证曲线、残差图或预测值与真实值对比图。图形由画图 SKILL 生成，论文写作 SKILL 负责安排位置并解释它支持的结论。

### 第 4 段：分析与诊断
应回答：误差在不同折、窗口或组之间是否波动明显；残差是否呈现非随机结构；Q-Q 图是否显示明显偏离；残差与拟合值之间是否存在异方差或非线性；误差是否落在题目或业务可接受范围内。若发现问题，应形成“发现误差 -> 判断原因 -> 修改模型或验证方案 -> 重新求解 -> 对比前后结果”的闭环，不能只写“模型效果良好”。

## 灵敏度分析四段式写作模板
- 灵敏度分析的目标是把“参数变化”与“输出变化”建立可解释的对应关系；参数范围、步长、水平数、重复次数和随机种子都必须来自实际实验记录。

### 第 1 段：引入分析对象
可写为：“为检验模型对[参数名称]的敏感程度，本文以[基准值]为中心改变该参数。选择该参数是因为它在[目标函数 / 约束 / 动力学关系 / 业务规则]中承担[具体作用]，可能影响[输出指标]。”

### 第 2 段：说明扰动方法
- 明确基准值、变化范围、步长或参数水平数，以及每个水平是否重新训练、求解和评价。
- 单因素控制变量法适合只研究单个参数影响；若多个参数的交互作用是问题重点，应从正交试验、响应面、网格搜索、蒙特卡洛模拟或 Sobol 指数等方法中选择适合当前问题的实验设计，并在文中说明。
- 可写为：“在保持其他条件不变的情况下，将[参数]从[下限]以[步长]变化至[上限]，每个水平重新[求解 / 训练 / 评价]，记录[输出指标]；共进行[重复次数]次，并固定或报告随机种子。”

### 第 3 段：展示敏感性结果
- 用表格或曲线展示参数水平、输出指标、相对变化量和必要的误差范围；同时报告最大变化幅度、变化方向和是否存在单调、非单调或边际递减现象。
- 当基准输出接近零时，不直接使用相对变化率，应改用绝对变化、区间或其他稳定指标。
- 参数较多时可使用敏感性排序图、热力图或响应面图，但每张图都要对应一个明确结论，不要只堆图。

### 第 4 段：解释与决策
应回答：哪个参数最敏感；模型结构中的哪一项造成这种敏感性；参数变化对应什么实际业务含义；在当前证据下是否可以提出推荐区间。推荐区间必须由实验范围、约束条件和结果稳定性共同支持，不能从一次曲线的极值直接外推。

## 模板使用边界
- 截图中的“Pearson + 互信息”“熵权法 + TOPSIS”“LSTM / ARIMA”“遗传算法”和“CV 阈值”都是可替换示例，不是论文写作的固定答案。
- 预测、时间序列、群组数据和优化问题的验证方式必须服从 `math-modeling-data-preprocessing` 与 `math-modeling-model-and-methods` 的数据划分规则；论文中只准确记录实际执行的方案。
- 误差表、残差图、Q-Q 图、敏感性曲线和对比图由 `math-modeling-plotting` 负责生成；本节负责确定证据用途、插入位置和分析文字。

## 验证方式选择与摘要交接
- 验证方式必须匹配数据结构，不要把 K 折交叉验证当成所有问题的默认方案。
- 独立同分布数据可使用普通或分层 K 折；时间序列应使用时间顺序划分、滚动验证或扩展窗口；群组数据应使用按组划分，避免同一用户、地区或设备同时进入训练和验证。
- 确定性优化、非线性规划、粒子群或遗传算法应根据题目使用训练场景、验证场景和独立测试场景；无调参的简单模型可以采用训练集加测试集，不应为了形式完整强行套 K 折。
- 论文必须写清划分方式、验证对象、重复次数、随机种子（如适用）和最终报告的指标。论文写作 SKILL 负责准确呈现，具体划分和调参交给数据预处理、模型方法和超参数调优 SKILL。
- 摘要只报告验证方式和最关键的验证结果，不展开检验公式和全部折次结果；没有真实验证证据时，不写“结果可靠”或“模型稳健”。

## 误差与灵敏度结果的记录口径
- 误差分析应形成“发现误差 -> 判断原因 -> 提出修改 -> 重新求解 -> 对比前后 -> 解释改善”的闭环。
- 交叉验证误差的离散程度可以记录为：

\[
CV=\frac{s}{|\bar e|},
\]

其中 \(s\) 为各次验证误差的标准差，\(\bar e\) 为平均误差；当平均误差接近 0 时，不应使用 CV 进行判断。
- 灵敏度分析可以记录相对输出变化：

\[
R_Y=\frac{|Y(\theta)-Y(\theta_0)|}{|Y(\theta_0)|}.
\]

- 应明确基准值、变化范围、步长、水平数量、重复运行次数和随机种子，并区分“5 个参数水平”“5 次重采样”和“5 个随机种子运行”。
- `CV<5%`、`VIF>10`、固定 K 值和类似阈值只能作为经验提示，不能写成脱离数据和题目背景的普适规则。

## 不要写什么
- 不要在没有真实检验结果时写“模型有效”“结果可靠”或“模型稳健”。
- 不要把所有参数机械设置为相同扰动比例，也不要对每个模型重复同一套灵敏度分析。
- 不要只展示曲线、热力图或误差表而不解释它们支持什么结论。
- 不要只写“误差较小”，必须给出实际指标、数值、范围或置信区间。
- 不要把训练集拟合效果直接当成泛化能力证据，也不要破坏时间、群组或上下游问题的数据边界。

## 常见扣分点
- 检验方法与数据结构不匹配。
- 参数范围、步长、重复次数或随机种子没有来源。
- 只报告平均误差，不报告波动、范围或最大误差。
- 误差来源与实际数据处理、假设和求解过程没有对应关系。
- 灵敏度分析没有判断排序、最优方案或最终结论是否改变。
- 稳健性分析只给定性评价，没有扰动设置和量化结果。
