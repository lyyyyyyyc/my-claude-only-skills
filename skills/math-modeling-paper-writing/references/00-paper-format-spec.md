## 2. 第一部分：格式规范

### 2.1 正文规范

- 规范1.1：正文用小四字号；中文用宋体；西文（英文、数字）用 `Times New Roman`。
- 规范1.2：每段首行缩进两个中文字符宽度；段落左侧严禁手动加空格，应在样式中自动设置。
- 规范1.3：正文统一使用多倍行距 `1.25`，以避免含公式段落出现行距忽大忽小。
- 规范1.4：正文中的标点一律使用中文标点，不得混用英文逗号、句号、冒号等。
- 规范1.5：列举条目时，小标题要对齐，建议使用 `1. 2. 3.` 或 `(1) (2) (3)`，编号后空一格。
- 规范1.6：优先使用英文括号 `()`，不要使用中文括号 `（）`。
- 规范1.7：文章标题、章标题、小节标题的字号和格式见下表。

| 标题类型 | 格式 | 用途 |
| --- | --- | --- |
| 论文题目 | 四号字，居中，题目与摘要之间空 1.5 行 | 论文总标题 |
| 一级标题 | 四号字，居中 | 章标题，如模型假设、符号说明等 |
| 二级标题 | 小四，左对齐 | 节和小节标题，如 5.1、5.2.2 |

- 规范1.8：标题中文用黑体，西文（英文、数字）用 `Times New Roman`。
- 规范1.9：从摘要页开始编页码。原文给出的做法是：`插入 -> 页码 -> 页边底端 -> 普通数字 2（居中）`，再将页码字体改为 `Times New Roman`。
- 规范1.10：每一级标题后都要先有一段说明性文字，不能标题后直接接下一层标题。
- 规范1.11：表格、图片要妥当排版，避免正文中出现大段空白（“开天窗”）。

### 2.2 公式规范

- 规范2.1：所有公式一律使用 `MathType` 编辑，严禁使用 Word 自带的“插入公式”。
- 规范2.2：所有变量应使用 `Times New Roman` 斜体。
- 规范2.3：所有矩阵、向量应使用正体加粗，且应通过 `MathType -> 样式 -> 矢量矩阵` 设置，不要手动加粗。
- 规范2.4：所有文本、单位、缩写应使用正体不加粗，并通过 `MathType -> 样式 -> 文本` 设置。
- 规范2.5：定义变量时，推荐使用“字母变量 + 文本下标”的方式：
  - 变量本体用斜体。
  - 用于区分语义的英文下标用正体。
  - 下标宜使用 1 到 3 个字母缩写。
  - 不要把多个字母直接连写成容易被误解为乘积的形式。
  - 一般不要用汉语拼音做缩写。
- 规范2.6：正文中的行内分数，优先写成斜线分数形式（如 `a/b`），不要用上下堆叠的水平分数线，以免拉大行距。
- 规范2.7：正文中如果因公式导致行距不统一，应在 `段落 -> 缩进和间距` 中取消“对齐到网格”。
- 错误示范2.8 的核心问题：
  - 单位未用 MathType 编辑，导致字体不统一。
  - 下标中的缩写未用正体。
  - 使用了水平分数线，导致字号变小、行距变大。
  - 整体公式与行距不协调。
- 规范2.9：单独成行的公式应居中；若右侧有公式编号，编号应与公式对齐，并使用英文括号，例如 `(1)`。
- 规范2.10：单独成行的公式可以统一编号，也可以选择性编号；但凡后文要引用的公式，必须编号。
- 规范2.11：
  - 正文段落中多个公式之间使用中文标点。
  - 单独成行公式之后的标点使用英文标点。

### 2.3 表格规范

- 规范3.1：正文和附录中的表格均应为三线表，即无竖线，仅保留三条 `1.5 磅` 横线。
- 规范3.2：所有表格应通栏，与正文同宽。
- 规范3.3：表格应尽量等高，避免因公式等内容导致各行高度忽高忽低。
- 规范3.4：表题应放在表格正上方，且不要离表格过远。
- 规范3.5：表格中的字号和字体与正文一致。
- 规范3.6：较短的表格应尽量完整放在一页内，严禁“表题在上一页、表内容在下一页”。

原文给出的常见表格问题修正表如下：

| 问题 | 解决方法 |
| --- | --- |
| 表格不是通栏 | 选中表格，`右键 -> 自动调整 -> 根据窗口调整表格` |
| 表格标题离表格太远 | 选中表格，`右键 -> 表格属性 -> 表格 -> 文字环绕 -> 无` |
| 表格太宽/过高 | `右键 -> 表格属性 -> 行 -> 行高值选最小值`，并应用表格样式或手动去网格 |

- 规范3.7：跨多页的长表格应放入附录。
- 规范3.8：表格内容要简洁。若三线表已无法承载内容，优先考虑精简内容，而不是把表格画得更复杂。
- 规范3.9：表格应使用 Word 表格对象制作，严禁截图粘贴。
- 规范3.10：表格中的数字小数位要统一，一般保留 `2` 到 `4` 位即可。
- 规范3.11：可以使用粗体强调重要数值。
- 规范3.12：表格中的字号可适当缩小，例如五号字。
- 规范3.13：引用表格或图片时，严禁写“上表”“下表”，必须使用编号，如“如表2所示”。
- 规范3.14：表格编号统一为“表1、表2、表3……”。

### 2.4 图片规范

- 规范4.1：图片应居中。
- 规范4.2：图片标题应放在图片正下方。
- 规范4.3：图片内字号应与正文相同或略小，但不能小到难以辨认。
- 规范4.4：图片编号统一为“图1、图2、图3……”。
- 规范4.5：图片中的 `x`、`y` 轴含义必须说明清楚。
- 规范4.6：同一幅图中的不同曲线应使用图例说明；在 Matlab 中可用 `legend` 生成图例。
- 规则4.7：同一幅图中的不同曲线应采用不同线型、线宽区分，并考虑到黑白打印后仍可辨认。
- 规则4.8：一行只能放一幅图片，严禁多图并排。
- 规则4.9：如果一幅图包含多个子图，必须给子图编号，可用 `(a)(b)(c)(d)` 或 `(a1)(a2)(b1)(b2)`。
- 错误示范4.10 提炼出的常见问题：
  - 子图标题缺编号。
  - 多条曲线线型相同，黑白打印时难区分。
  - 横轴或纵轴范围设置不合理，导致图中出现大段空白或趋势不清晰。
  - 标记点过大，遮挡曲线。
  - 图片四周留白过多。
  - 子图标题放在子图上方而非下方。
  - 图片字体过小，或字体不符合正文规范。
- 规则4.10：图片应服务正文，不宜过大、过多。
- 规则4.11：Matlab 出图后，严禁用图窗中的“另存为”按钮保存图片。原文推荐的高清导出方式如下：

```matlab
set(gcf,'PaperPositionMode','auto');
print('图片名字.png','-dpng','-r600');
```

  - 第一行保证导出图片与当前窗口宽高比一致。
  - 第二行以 `png` 无损格式保存，并导出为 `600 dpi` 高清图。
  - 原文建议图片分辨率不要低于 `300 dpi`。
- 规则4.12：将图片插入 Word 之前，在 `文件 -> 选项 -> 高级 -> 图像大小和质量` 中勾选“不压缩文件中的图像”。
- 规则4.13：将 Word 打印为 PDF 时，在打印机属性中选择高质量打印，避免图片明显降质。
- 技巧4.14：若想把子图标题放在图片下方，可分别生成各子图，再在 Matlab 中借助表格统一排布子图和标题，最后去除表格边框。

### 2.5 参考文献规范

- 规则5.1：参考文献中的所有标点必须使用英文标点。
- 规则5.2：所有英文标点后都要空一格。
- 规则5.3：正文引用参考文献时使用正常大小编号，如 `[1]`，不要用上标。
- 规则5.4：引用必须在正文中有明确对应位置，不能“泛泛引用”。
- 建议5.5：优先引用论文，少引用博客等网络资源。
- 规则5.6：参考文献应采用悬挂缩进。

原文给出的参考文献示例如下：

```text
[1] 金志森. 基于层次分析法对城市内涝风险评估与区划方法研究——以泉州东海组团为例[J]. 城市住宅, 2015(12): 97-101.
[2] 姜启源, 谢金星, 叶俊. 数学模型[M]. 北京: 高等教育出版社, 2011.
[3] 卢佩. 基于类生物视觉特性的目标识别[D]. 成都: 中国科学院研究生院, 2014.
[4] 王小龙. 如何测算出任一副图片中的物体的实际尺寸[EB/OL]. (2017-03-25) [2020-08-12]. https://www.zhihu.com/question/20448353/answer/24885779.
```

- 规则5.8：常用文献类型与缩写：
  - 期刊：`[J]`
  - 专著：`[M]`
  - 毕业论文：`[D]`
  - 网络资源：`[EB/OL]`
- 规则5.8 的细化要求：
  - 期刊必须给出期卷号和页码。
  - 专著、毕业论文必须给出出版地、出版社和年份。
  - 网络资源必须给出发表日期和访问日期，分别用小括号和中括号标示。
- 规则5.9：网络资源引用必须给出完整网址，并注意：
  - 去掉 Word 自动生成的超链接样式。
  - 若网址过长导致断行困难，应允许西文在单词中间换行。
- 规则5.10：参考文献数量以 `5` 到 `10` 个较为合适。
- 规则5.11：使用公开代码时要引用对应网页；使用书中代码时要引用对应书目。

### 2.6 附录规范

- 规则6.1：附录应单独成页；严禁用空格手动翻页。应使用 `段前分页`。
- 规则6.2：附录中的表格仍应为三线表。
- 规则6.3：附录中的代码应使用 `Times New Roman`，并统一为黑色格式。
- 规则6.4：附录中的每一段代码前都应简述其功能。

### 2.7 支撑材料规范

- 规则7.1：支撑材料中的数据文件应与程序放在同一文件夹内，不要引用某台电脑独有的绝对路径。
- 规则7.2：支撑材料中的程序应能直接运行；若每位队员电脑上都能运行，在评委电脑上可运行的概率才更高。
- 规则7.3：
  - 支撑材料文件夹名称应为“支撑材料”。
  - 使用 `WinRAR` 压缩成 `.rar` 文件。
  - 压缩包文件名改为“队号_队员名”的形式，例如 `A01_张三.rar`。
- 规则7.4：上传前要做解压测试：
  - 使用“解压到当前文件夹”时，得到的文件夹应叫“支撑材料”。
  - 使用“解压到 A01_张三”时，解压出的外层文件夹应叫 `A01_张三`，进入后应包含“支撑材料”文件夹。
  - 若第一种方式解压后直接得到的是队号文件夹而不是“支撑材料”，说明命名或打包结构有误。

### 2.8 摘要页规范

- 规则8.1：标题要具体，不能过大、过空。
- 规则8.2：摘要页应单独成页。
- 建议8.3：摘要建议覆盖四要素：
  - 问题
  - 方法
  - 模型
  - 结论
- 建议8.3 的进一步要求：
  - 摘要中应有模型介绍、数据与结论。
  - 若能加入分析、预测或政策建议更好。
- 规则8.4：摘要中的背景不要写太多。
- 规则8.5：摘要中不要写公式，但可以写关键数值结论。
- 规则8.6：摘要中不要举例、不要解释名词、不要引用图片和表格。
- 规则8.7：关键词应为 `3` 到 `5` 个，用分号分隔。
- 规则8.8：关键词要具体，避免使用“拟合、算法、优化、采样”这类过大过虚的词；应写成“多项式拟合、遗传算法、线性规划、蒙特卡洛采样”等更具体的表达。

## 3. 第二部分：Word 样式与使用要点

### 3.1 样式简介

- 原文强调：应充分利用 Word 样式统一字体、字号、缩进、行距、制表符等，而不是手工逐段修格式。
- 样式入口位于 `开始` 选项卡的样式栏；通过右下角按钮可打开样式菜单，对样式进行新建、使用、删除、修改。
- 表格也可以设置样式，但新建时应把样式类型从“段落”改为“表格”。
- 应用表格样式时，应先选中表格，再在 `表格工具 -> 设计 -> 表格样式` 中选择。
- 若样式栏太杂乱，可将“选择要显示的样式”改为“当前文档中的样式”。

### 3.2 原文自建样式清单

| 样式名称 | 用途 | 内容 |
| --- | --- | --- |
| 建模-论文题目 | 格式化总标题 | 四号字居中，段后留空白 |
| 建模-一级标题 | 格式化章标题，包括摘要、问题重述、符号说明等 | 四号字居中 |
| 建模-二级标题 | 格式化小节标题，如 5.1、5.1.1、附件 1 等 | 小四字号居左 |
| 建模-正文 | 格式化正文 | 小四字号；中文宋体；西文 `Times New Roman`；首行缩进 |
| 建模-数学公式 | 格式化数学公式 | 公式居中；标号居右；公式与标号对齐 |
| 建模-图表标题 | 格式化图片和图表标题 | 文字居中 |
| 建模-附件代码 | 格式化附件代码 | 与正文格式相同，但段首不缩进 |
| 建模-参考文献 | 格式化参考文献 | 与正文格式相同，但悬挂缩进 |
| 建模-表格内容 | 格式化表格 | 三线表 |

### 3.3 样式使用注意事项

- 注意1：一、二级标题前后可以适当留白，应在段前、段后参数中设置，而不是手动回车。
- 注意2：数学公式样式的标准用法为三步：
  1. 先在同一行写出“公式 + 编号”，且公式左边、公式与编号之间都不要加空格。
  2. 选中整行，应用“建模-数学公式”样式。
  3. 将光标分别放在公式左侧、编号左侧，各按一次 `Tab`，使公式居中、编号居右。
- 注意3：除“建模-表格样式”外，其余样式都在普通样式栏中选择；表格样式要在表格工具中选。
- 注意4：表格样式不能自动修正表内文字字体，因此表格内容还要按正文规范手动调字体。
- 注意5：若表格标题含公式且对不齐，可尝试用“建模-数学公式”样式处理标题并居中；若仍不理想，可以格式化后删掉公式重新录入，或不要直接对含公式标题套用“图表标题”样式。
- 注意6：严禁用空格或回车做缩进、翻页。

## 4. 排版练习章节提炼

### 4.1 练习组织方式

- 原文附有两套排版练习：
  - 第一套：正确排版文档 + 未排版文档，供边看边改。
  - 第二套：错误标红文档 + 修正版文档，供对照修正。
- 原文建议教练组准备“错误丰富”的综合示范作业，集中训练学生排版能力。

### 4.2 从练习中提炼出的实操规则

- 论文题目使用“建模-论文题目”样式。
- “摘要”使用一级标题样式。
- 正文统一使用“建模-正文”样式，不要手动敲空格控制段前段后间距。
- 关键词行：
  - 先套正文样式。
  - “关键词”三个字可再设为黑体。
  - 关键词数量一般为 3 到 5 个。
  - 关键词之间用分号分隔。
- 摘要页、附录页等需要单独成页的部分，应使用“段前分页”，不要手动空格翻页。
- 三级标题在原练习中通常沿用二级标题样式处理。

### 4.3 公式排版实操三步

1. 删除公式左侧以及公式与编号之间的多余空格。
2. 选中“公式 + 编号”整行，应用“建模-数学公式”样式。
3. 在公式前和编号前分别按一次 `Tab`，完成居中和右对齐。

### 4.4 表格排版实操六步

1. 选中整个表格，在 `表格工具 -> 设计 -> 表格样式` 中应用“建模-表格内容”，先变成三线表。
2. 右键表格，执行“根据窗口调整表格”，使表格通栏。
3. 在 `表格属性 -> 行` 中勾选指定高度，并把行高值设为“最小值”，防止表格过高。
4. 若表格中公式对不齐，到段落设置中取消“对齐到网格”。
5. 若表题离表格太远，在 `表格属性 -> 表格 -> 文字环绕` 中选择“无”。
6. 手动调整表格内文字的字体，并根据内容判断应居中还是左对齐。

### 4.5 附录代码排版实操

- 附录要单独成页。
- 代码前先写“功能：……”说明。
- 代码字体使用 `Times New Roman`。
- 代码颜色统一为黑色。

## 5. 可直接执行的终检清单

### 5.1 页面与标题

- 是否从摘要页开始编页码。
- 摘要页、附录页是否单独成页。
- 论文题目、一级标题、二级标题字号和位置是否符合要求。
- 标题后是否都有一段引导文字。

### 5.2 正文与公式

- 正文字号是否统一为小四。
- 中文是否统一为宋体，西文是否统一为 `Times New Roman`。
- 是否统一首行缩进、行距 `1.25`。
- 是否杜绝英文标点混入正文。
- 公式是否全部由 `MathType` 制作。
- 行内分数是否尽量改为斜线分数。
- 需引用的公式是否都已编号。

### 5.3 表格与图片

- 表格是否全部为三线表、通栏、编号规范。
- 表题是否在表上方，图题是否在图下方。
- 是否杜绝“上表/下图”这种引用方式。
- 图片是否居中、图例清晰、字体可读。
- 多曲线在黑白打印下是否仍能区分。
- 图片是否以高分辨率导出，并关闭 Word 自动压缩。

### 5.4 参考文献、附录与支撑材料

- 参考文献是否统一英文标点、英文标点后空一格、采用悬挂缩进。
- 参考文献条目是否与正文引用一一对应。
- 附录中的代码是否带有功能说明。
- 支撑材料是否使用相对路径并可直接运行。
- 压缩包命名和解压结构是否符合要求。

## 6. 评阅视角与答卷前规划

### 6.1 写好答卷的重要性

- 在数学建模竞赛里，评委实际看到和评分的核心对象是答卷本身；模型再好，若没有被答卷清楚表达，也难以转化为成绩。
- 答卷既是竞赛成果的书面交付物，也是科技写作训练的一部分，因此“会做”与“会写”必须同时成立。

### 6.2 评阅原则

- 可把以下 4 项视为总览级评阅框架：
  - 假设是否合理；
  - 建模是否有创造性；
  - 结果是否合理；
  - 表述是否清晰。
- 这 4 项不是彼此割裂的。更稳妥的写法通常是：先用合理假设支撑模型，再用明确结果和清晰表达把模型价值交代出来。

### 6.3 动笔前的工作规划

- 在正式起草前，先列清楚下面 4 件事：
  - 题目一共要回答哪几个问题；
  - 每个问题最终准备用什么形式呈现结果，例如数值、表格、图形、方案或结论；
  - 每个问题需要给出哪些关键数据；
  - 每个量是一组结果，还是多组对比结果。
- 这一步的作用是先反推写作交付物，再安排建模和结果展示，避免正文写到后面才发现关键数据缺失或展示形式失衡。

### 6.4 写作原则与建模理念

- 总写作原则可统一归纳为 5 个词：
  - 准确：结论、符号、口径、引用都要可靠；
  - 条理：结构和层次清楚，读者能顺着你的逻辑走；
  - 简洁：保留关键步骤，不用冗长文字掩盖逻辑空缺；
  - 创新：创新要服务问题，不是为了显得新而新；
  - 实用：模型和结果要真正面向题目和应用场景。
- 建模理念可额外从 3 个角度统一检查：
  - 应用意识：结果和结论要贴近实际，便于理解和使用；
  - 数学建模意识：必须有数学抽象和模型，不只是经验性描述；
  - 创新意识：可以在模型结构、求解策略、结果检验或推广方式上体现改进，但不要脱离题意炫技。

### 6.5 交付前三关检查

- 交付前至少再过一遍“模型关、结果关、表述关”：
  - 模型关：模型是否正确、合理，并在必要处体现出创新；
  - 结果关：结果是否正确、合理，是否能支撑结论；
  - 表述关：文字是否清楚、分析是否到位、摘要是否足够有力。
