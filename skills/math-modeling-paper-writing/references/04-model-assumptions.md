# 模型假设写作要求

## 章节定位
- 本部分说明为使现实问题能够被数学化描述和求解，本文保留了哪些主要矛盾、忽略了哪些次要因素，以及模型在什么条件和边界内成立。
- 模型假设连接“问题分析”和“模型建立”：前承题意、研究范围与数据条件，后接变量关系、目标函数、约束条件、参数设定和结果解释。
- 默认作为正文第三部分，标题为 `三、模型假设`。
- 每条假设必须有明确依据，服务于后续模型，并能说明它简化了什么问题以及可能带来什么影响。
- 核心原则是在不歪曲问题本质、不违背题意的前提下保留主要矛盾、舍弃次要因素，使现实问题可建、可算、可解释。

## 主要作用
- **明确研究边界**：说明模型考虑与不考虑的因素、适用的时间和空间范围，避免研究范围无限扩张。
- **将现实问题数学化**：通过理想化对象、稳定状态、变量关系或概率分布，把现实过程转化为可表达的数学结构。
- **降低求解复杂度**：忽略影响较弱、发生概率很低或难以观测的因素，使模型能够闭合并可求解。
- **明确数据使用条件**：说明数据来源、代表性、误差范围、时间尺度和可比性。
- **满足模型使用条件**：交代独立性、平稳性、线性、分布形式、参数稳定性等模型前提。

## 写作前先做假设台账
正式写作前先为候选假设建立简表，再筛选进入正文：

| 候选假设 | 来源或证据 | 简化了什么 | 后文对应位置 | 失效风险 |
|---|---|---|---|---|
| [假设内容] | 题面 / 数据 / 机理 / 文献 / 模型条件 | [被忽略或固定的因素] | 变量 / 参数 / 目标 / 约束 / 检验 | [可能造成的偏差] |

- 后文没有实际使用位置的候选假设不进入正文。
- 会改变题目核心要求、掩盖主要矛盾或直接预设结论的候选假设必须删除。
- 若关键假设存在明显风险，应在模型评价、灵敏度分析或局限性部分安排检验或讨论。

## 假设的三类来源
1. **题目明确给出的条件**：保留题面已经规定的状态、范围或边界，但改写成论文语言，不机械照抄题目。
2. **根据题目与研究情境合理推出的条件**：可依据业务流程、常识、数据特征、机理分析、公开资料或权威文献推导，例如在正常运行情境下排除战争、重大灾害等极端冲击。
3. **具体模型或算法成立所需的条件**：包括线性、独立、平稳、无后效性、分布形式、参数稳定性等；这类假设必须由数据检验、机理分析、领域知识、权威文献或题目限定支撑。

## 十类常见假设及边界

### 1. 数据真实性与有效性
- 推荐写法：`假设题目提供及补充收集的数据来源可靠；经过缺失值、异常值和一致性检查后，保留数据能够反映研究对象的主要特征。`
- “数据可靠”不等于“数据绝对无误”。若正文进行了清洗，不得再写“数据集完整且不存在任何错误”。
- 插值、异常值处理、口径统一等是数据处理操作，不应被伪装成模型假设。

### 2. 小概率极端事件排除
- 推荐写法：`假设研究期内不发生足以改变系统运行机制的重大自然灾害、战争、重大事故或系统性风险。`
- 必须明确研究期限和正常情境，不得暗示所有条件永久不变。
- 若题目研究的正是政策突变、灾害、应急调度或极端风险，则不得排除对应事件。

### 3. 主要因素保留、次要因素忽略
- 推荐写法：`根据研究目标，仅考虑[主要因素]对[研究对象]的影响，忽略[次要因素]在研究期内产生的微小扰动。`
- 被忽略的因素必须相对次要；题目明确要求研究的核心因素不能被假设为不变或直接忽略。
- 应说明忽略依据，例如影响量级、研究尺度、数据不可得性或敏感性分析结果。

### 4. 系统平稳性
- 推荐写法：`假设在[明确时间或空间范围]内，[环境、参数或运行状态]近似保持稳定。`
- 长期预测必须说明基准情景、参数范围或结构变化处理，不能笼统假设所有条件永久不变。

### 5. 对象理想化
- 可根据研究尺度将车辆视为质点、管道视为内径均匀的圆柱体、材料视为均匀且各向同性，或忽略研究尺度下影响很小的几何细节。
- 理想化必须保留决定模型行为的主要物理或业务特征，不能为了方便计算而删除关键结构。

### 6. 参数形式与概率分布
- 推荐写法：`假设[参数或随机变量]在[适用范围]内服从[分布或函数形式]。`
- 分布、函数形式或参数稳定性必须有数据检验、机理分析、领域常识、权威文献或题目规定支撑。
- 未检验的数据不得直接假设为正态分布；估计得到的参数也不得默认为绝对精确常数。

### 7. 变量关系
- 推荐写法：`在[明确研究范围]内，假设[变量 A]与[变量 B]近似满足[线性、可加、单调或其他]关系。`
- 变量关系会直接决定模型类型、目标函数或约束形式，应谨慎设定并安排诊断或敏感性分析。

### 8. 行为与决策
- 推荐写法：`假设决策者在已知信息和给定约束下，以[成本最小、收益最大、风险受控或其他目标]作为主要决策准则。`
- 不得对所有行为主体一律假设完全理性；应结合信息可得性、行为偏差和题目场景判断。

### 9. 空间与时间尺度
- 推荐写法：`假设同一统计周期内数据口径一致，并将[一天 / 一月 / 一次任务]视为一个等长决策周期。`
- 必须明确假设适用的粒度。跨周期、跨地区或跨来源数据如果口径不同，应先处理而不是直接宣称可比。

### 10. 独立性或无相互干扰
- 推荐写法：`在[限定条件]下，假设[对象或事件]之间近似相互独立。`
- 独立性通常属于强假设；存在资源竞争、空间冲突、网络传播、共同驱动因素或直接作用时，不得轻易使用。

## 数量与单条写法
- 正文最多写 `6` 条假设，按重要性筛选真正影响模型结构、目标函数、约束条件、数据口径和结果解释的内容；不得为了凑数扩写或拆分同类假设。
- 每条假设控制在约 `40` 个汉字，允许因必要的数学符号或限定条件略有浮动；原则上用一句简洁完整的话表达。
- 相关前提应合并到同一条中，避免超过6条；不要把依据、作用、风险和检验过程展开成多段文字。
- 假设内容必须具体，优先保留研究边界、关键数据条件、变量关系和业务约束；删除空话、重复内容和后文没有落点的假设。

## 正文版式硬规则
- 标题固定为 `三、模型假设`。
- 标题后直接列出从 `1.` 开始的连续编号条目，编号到实际条数为止，且不超过 `6`。
- 不得设置加粗小标题、二级小节、假设分类标题、假设台账或专门的变量/参数说明表。
- 默认不写引言、总结和条目后的展开解释，正文整体采用“标题 + 编号假设”格式，贴近示例截图。

## 推荐章节开头
- 默认省略引言，标题后直接开始编号。只有用户明确要求时，才可写一段简短定位说明：

`为突出研究对象的主要特征并降低次要因素对模型求解的干扰，在不改变问题本质的前提下，结合题目条件、数据特征及后续模型需要，作出如下假设。`

- 不推荐写“为了方便模型建立，使模型更加完备、预测结果更加合理，作出如下假设”。这类开头没有交代简化原则和研究边界。
- 若增加引言，不得影响“最多6条、每条约40字”的正文限制，也不得写空泛套话。

## 单条假设模板
```text
1. 假设[具体内容]。
```

每条优先保留最核心的假设内容；依据、作用、简化因素和潜在偏差只在确有必要时压缩进同一句，不另起段落。

## 不同题型的假设示例
以下示例用于选择思路，不得脱离具体题目原样套用。

### 预测类问题
- 假设清洗后的历史数据能够反映研究对象的主要变化规律。
- 假设预测期内不发生足以改变原有发展机制的重大突发事件。
- 假设历史数据中识别出的主要关系在预测期内具有一定延续性。
- 假设不同来源数据完成口径统一后具有可比性。
- 假设随机扰动的均值为 0，且不造成系统性偏差；该条件应在后文检验。

### 综合评价问题
- 假设所选指标能够从题目要求的维度反映评价对象的主要特征。
- 假设指标标准化后具有可比性。
- 假设各评价对象处于相同或可比的评价环境。
- 假设指标间的信息重复可通过相关性、降维或权重处理控制。
- 不得直接假设“指标体系全面且评价准确”；这等于提前宣布模型正确，应由权重对比、敏感性分析或结果验证支持。

### 优化问题
- 假设决策周期内资源总量、成本口径和主要约束条件已知。
- 假设各项成本按统一口径计算。
- 假设执行过程不存在未建模的额外资源损耗；若损耗不可忽略，应进入约束或成本项。
- 假设同一决策周期内单位成本或收益近似稳定。
- 假设所有决策变量均满足题目规定的可行范围。

### 交通与路径问题
- 假设单次任务周期内道路网络结构保持不变。
- 除题目明确考虑的拥堵因素外，忽略临时交通管制和重大事故。
- 假设车辆按规划路径运行，不发生无法观测的绕行。
- 仅当车辆尺度相对道路尺度可忽略时，才可将车辆视为质点。

### 物理机理问题
- 假设材料在研究尺度下均匀且各向同性。
- 假设系统与外界的非目标能量交换可以忽略，或已经通过边界项表示。
- 假设测量仪器的随机误差处于允许范围内。
- 假设研究区间内相关物理参数近似恒定。
- 仅在有尺度或量级依据时，忽略对主要物理过程影响较小的高阶效应。

### 新能源汽车类问题
- 假设产销量、保有量、能源消费和排放数据来源可靠，统一口径后具有可比性。
- 除政策影响问题外，在基准情景中不考虑战争、重大灾害等极端事件造成的结构性冲击。
- 假设历史数据反映的主要发展机制在预测期内具有一定延续性，政策变化通过单独情景参数刻画。
- 假设同类车辆在相同使用条件下的平均能耗和平均行驶里程具有代表性。
- 生态环境模型中的排放因子采用统一核算口径，并覆盖题目要求的主要排放端。

## 假设与后文的对应关系
模型假设不是孤立清单。完成本节后，应核对每条关键假设在后文是否有实际落点：

| 假设类型 | 后续对应内容 |
|---|---|
| 数据可靠性 | 数据来源、清洗、误差说明与数据局限 |
| 参数恒定 | 模型中的常数参数、适用区间与敏感性分析 |
| 对象理想化 | 几何关系、运动学关系或物理方程 |
| 变量独立 | 概率模型、回归条件或协方差结构 |
| 忽略次要因素 | 变量选择、模型边界与局限性 |
| 线性或可加关系 | 目标函数、约束条件或回归形式 |
| 分布假设 | 参数估计、分布检验与不确定性分析 |
| 极端事件排除 | 适用范围、情景边界与模型局限 |
| 行为假设 | 决策规则、效用函数或目标函数 |
| 时间平稳性 | 预测模型、训练窗口与适用期限 |
| 独立或无干扰 | 分解求解条件、资源约束或空间冲突处理 |

- 后文若检验发现假设不成立或与结果矛盾，必须回到本节修改假设或调整模型，不能保留错误假设继续下结论。
- 后文出现新的关键前提时，应回填本节或在模型首次使用处明确说明，不能让模型依赖隐藏假设。

## 不可取的做法
- 未检查数据就假设不存在任何缺失值、异常值或误差。
- 忽略题目要求研究的核心因素，或把关键政策、约束、资源竞争和空间冲突假设为不存在。
- 使用没有依据的完全理性、完全独立、永久稳定或绝对精确假设。
- 把“插值补全缺失值”“删除异常值”“统一量纲”等数据处理动作写成假设。
- 假设本文模型能够准确预测未来，或假设计算结果天然合理有效。
- 写入后文完全没有使用的假设，或用多条近义句重复“数据真实可靠”。
- 模型检验发现假设与结果矛盾后，仍不修正假设或模型。
- 把符号定义、变量说明、问题分析和算法步骤强塞进模型假设部分。

## 完成前检查
- 是否保留了问题的主要矛盾，没有违背题意或直接预设结论。
- 是否交代了关键研究边界、数据条件和模型成立条件。
- 每条假设是否具体到研究对象、变量、时间范围或业务机制。
- 每条关键假设是否有题面、数据、机理、文献或领域知识支撑。
- 每条假设是否能够映射到后文变量、参数、目标、约束、检验或局限性。
- 是否将强假设的适用范围和可能偏差交代清楚。
- 是否删除了空话、同义重复、未使用假设和数据处理动作。

## 与前后章节衔接
- 本部分承接“问题分析”，之后通常进入“符号说明”。
- 若某条假设直接决定模型结构，后文公式、参数或约束中必须能看出它的作用。
- 若后文使用稳定性、分布、相关性、容量固定、空间固定、无滞存、无后效性等条件，应在本节或模型首次使用处明确交代。

## 完成后专项审查
- 模型假设生成、重写或实质性修改完成后，必须立即暂停当前写作流程并询问用户：“模型假设已经写完，是否需要调用 `bzd-model-assumption-checker` 进行审查？请回答是或否。”即使正在连续写整篇论文，也必须先完成本次询问与可选审查，再进入“符号说明”。
- 若用户明确回答“是”，必须调用 `bzd-model-assumption-checker`，同时提供完整题面、附件说明和刚完成的模型假设，并向用户返回审查结果；不得只给出调用建议，也不得改用其他通用评审 skill 代替。
- 若用户明确回答“否”，不得调用该 skill，可以继续后续写作流程。
- 若用户回答不明确，必须继续询问，直到得到明确的“是”或“否”；在得到明确回答前，不得默认选择、跳过询问或继续生成下一章节。
