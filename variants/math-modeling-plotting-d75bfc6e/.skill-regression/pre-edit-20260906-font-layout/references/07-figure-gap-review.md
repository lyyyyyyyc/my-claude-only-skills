只在用户明确要求“检查论文哪里适合补图”“规划整篇论文图表”“判断某章节是否需要配图”时读取本文件。

# 论文补图规划

## 任务边界

- 本文件输出的是候选补图规划，不是自动改论文功能。
- 先阅读用户提供的论文范围、目录、章节、现有图表、表格和可用数据；未提供全文时，只评价已提供部分。
- 不因章节字数、图文比、页面留白或“顶刊习惯”自动判定缺图。
- 生成图、插入图、修改编号、更新正文引用、改写结论和重新计算数据都需要用户明确授权。

## 判断是否值得补图

一张候选图至少同时满足：

1. 它能比现有文字、公式、表格或图表更清楚地传达趋势、比较、关系、流程、层级、流量或空间结构。
2. 它不会与已有图表重复表达同一信息。
3. 所需数值、单位、逻辑节点和关系能从原文、表格、已有图、已提供计算结果或获授权计算中追溯。
4. 它与章节目标、模型叙述和论文风格一致。

任一条件不满足时，记录原因；不要为了“图文并茂”硬补图。

## 章节到观察目的的提示

| 章节或内容 | 常见观察目的 | 候选表达 |
| --- | --- | --- |
| 问题分析、模型框架 | 结构、约束、模块依赖 | 方法框架图、流程图 |
| 数据来源、预处理 | 数据流、处理步骤、覆盖范围 | 数据流程图、地图、质量概览 |
| 算法或求解过程 | 控制流、迭代、终止条件 | 算法流程图、收敛曲线 |
| 结果分析 | 差异、趋势、关系、空间分布 | 依数据结构转到现有选图 reference |
| 灵敏度与参数扫描 | 参数响应、稳健性、交互作用 | 响应曲线、热图、等高线 |
| 方案比较 | 共同指标下的比较或构成 | 点图、条形图、热图、经过验证的雷达图 |
| 调度与阶段计划 | 时间安排、资源占用、依赖 | 甘特图、时间线、网络图 |
| 指标体系 | 从属关系与权重结构 | 指标层级图、树状图 |

此表只提供入口，不替代数据结构和适用性判断。例如，多方案比较不自动等同于雷达图。

## 证据映射模板

每张候选图在生成前建立以下记录：

| 字段 | 内容 |
| --- | --- |
| 章节与目的 | 该图解决什么阅读问题 |
| 候选图型 | 为什么它比备选图更适合 |
| 数据或逻辑来源 | 原文段落、表格单元格、已有图、模型输出或授权计算 |
| 变量、单位与分母 | 数值含义、统计口径、变换 |
| 必要前提 | 是否需要标准化、地理匹配、统计结果或流程语义 |
| 数据缺口 | 缺少什么，是否足以停止 |
| 建议位置 | 首次解释之后、表格之后或章节结尾等原因 |
| 状态 | 建议 / 待数据 / 已授权待生成 / 已生成待检查 / 已验证 |

原文只有定性结论时，最多建议定性结构图；不能自行赋予数值、比例、排名、显著性或模型优劣幅度。

## 数据不足时的处理

- 缺少数值、单位、分母、时间范围、重复单位或方法依据时，明确列出缺口。
- 原文足以支持结构关系时，可建议定性框架图，并说明它不表示定量强度。
- 原文不足以支持结构或数值时，停止生成，向用户请求材料。
- 估算、插值、标准化、统计检验或模型重算属于独立分析任务；没有授权时不能以“图注注明估算”替代证据。

## 论文插入建议

- 规划阶段只给建议位置、候选图题或图注草稿；不修改正文。
- 获得插入授权后，遵循论文已有图号体系和实际首次引用顺序，更新交叉引用、目录和相关文件名。
- 若新增图位于论文中部，不机械使用“原最后图号加一”；先确认论文采用顺序编号、分章编号还是自动交叉引用。
- 图注说明对象、变量、单位、编码、数据来源和必要的统计信息。最终格式服从用户论文模板。

## 输出格式

输出“补图候选清单”，逐项写明建议与证据，而非宣称已经补图完成。应同时列出“不建议补图”的模块及原因，避免只报成功候选。

## 不要做什么

- 不要自动扫描用户未提供的论文内容。
- 不要用固定字数、图文比或每章图片数量当成自动触发器。
- 不要重复已有图、把纯理论证明硬画成示意图，或把表格已经清楚表达的信息再复制成图。
- 不要自动插图、编号、改正文引用或添加“如图所示”。
