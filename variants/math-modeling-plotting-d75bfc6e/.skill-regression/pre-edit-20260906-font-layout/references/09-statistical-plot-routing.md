只在用户已有统计结果，或明确咨询专业统计图型是否适用时读取本文件。本文件负责图型路由和表达边界，不替代统计建模、假设检验或医学统计技能。

# 统计图路由与表达边界

## 总门槛

- 统计标注必须有真实数据、明确方法和已提供或获授权计算的结果。
- 不因“论文图应更规范”自动添加误差棒、p 值、显著性星号、R2、回归线、置信区间、预测区间或多重比较校正。
- 图注至少能说明中心估计量、样本量 `n` 的独立单位、是否配对、区间或误差类型、比较对象和方法来源。
- p 值、显著性标记和效应大小不是同义词。星号不能用于宣称效应更大、模型更优或结论更重要。

## 误差与区间

- 标准差、标准误、置信区间、预测区间、四分位范围和情景范围表达的含义不同，不能仅通过修改图例文字互换。
- 误差棒是否适用取决于数据生成过程。单次确定性模型输出、已汇总的参数值或没有重复单位的数据，不因为没有误差棒而不合格。
- 使用误差棒或阴影带时，写明计算对象、样本量、重复单位、区间类型和置信水平或相应定义。

## 显著性与统计标注

- 只有已有检验结果时才显示 p 值或星号；明确比较对象、检验方法、配对关系和多重比较校正。
- `ns`、`*`、`**` 等阈值需要在图注说明；处理阈值等号和格式精度，不能显示 `p = 0`。
- 统计检验选择依赖设计、分布、独立性、重复测量、样本量和研究问题。本文件不把“两组用 t 检验、三组用 ANOVA”等简化规则当成自动决策。

## 专业图型路由

### ROC 与 PR 曲线

适用前提：有真实标签、连续预测分数、正类定义和明确评估数据集。

- ROC 适合描述不同阈值下的真阳性率和假阳性率。
- 类别严重不平衡时，同时考虑 PR 曲线及其基线。
- AUC、区间、阈值和模型排序来自已有评估，不从截图估读或套用示例。

### 森林图

适用前提：有多个可比较的效应估计或模型系数及其区间。

- 差值、回归系数等通常以 `0` 为无效应参考；比值型效应通常以 `1` 为参考，必须按参数定义确认。
- 研究权重、合并菱形、异质性统计量只在确有对应分析时展示。
- 森林图可用于广义区间比较，不应把所有这类图描述成 Meta 分析。

### 生存曲线

适用前提：有事件定义、观察时间和删失信息。

- 生存函数常以阶梯线表达；删失标记、风险集表、Log-rank p 值、HR 和区间只在已有分析结果时显示。
- 普通时间趋势、累计比例或模型预测曲线不因“随时间下降”而改画为生存曲线。

### 火山图与曼哈顿图

- 火山图适用于具有变化量和显著性结果的差异分析；阈值线必须与实际坐标变换、校正口径和研究方案一致。
- 曼哈顿图适用于具有位置顺序和关联显著性结果的相应分析；阈值与标签来自当前研究的定义。
- 这两类图具有强专业语义，非对应题型不作为普通“突出差异”的装饰图。

## 不要做什么

- 不要把统计图表达规范当成统计方法选择器。
- 不要把显著性、效应大小、预测性能和实际重要性混成一个结论。
- 不要在缺少重复、时间到事件信息、真实标签或区间估计时强行使用专业图型。
- 不要把未经授权的重算、插补、标准化或模型拟合藏在绘图步骤中。
