
# 公开版本验证范围

公开集合：797 个不同技能包，其中 669 个默认技能和 128 个可选版本。
日期：2026-11-10。

本次实测结果：

| 检查 | 结果 |
| --- | --- |
| 格式、正文及文件哈希 | 797 个包、6497 个文件，0 个错误 |
| 工作树安全扫描 | 47 个已逐项复核的示例结果，0 个未复核结果 |
| Windows PowerShell 5.1 隔离安装 | 初次安装 651 个；补充 Nature 后 Installed=18、Updated=0、Unchanged=651、Skipped=0 |
| 私人内容定向检查 | 3 个排除包与已识别的账号、身份标记均不在公开集合 |
| Nature 源码验证 | 18 个包匹配固定上游提交，170 个 Python 文件通过语法解析 |
| Nature 回归测试 | 124 个测试通过，按模块隔离避免上游测试的全局 mock 相互污染 |
| Nature Downloader 保护 | 本机文件哈希与更新前备份一致，未更新或加入此次导出 |

- 所有导出文件必须匹配清单中的 SHA-256，正文必须匹配原迁移记录。
- 验证脚本检查 YAML、名称、目录和文件清单。它不执行技能内部脚本。
- 安全扫描采用 gitleaks，文档及测试示例误报按完整文件哈希、规则与行号绑定。
- 公开历史从清理后的版本开始，原始私人历史保留在私有备份仓库。
- 源机器绝对路径不在公开清单中，公开版本不要使用 validate.py 的 --check-source 选项。
- 安装器会保留未受它管理或有本地修改的已有技能，冲突时跳过并报告。

这些检查不替代逐项业务验收。云端尚需配置技能使用的 MCP、API Key、账户和运行依赖。
